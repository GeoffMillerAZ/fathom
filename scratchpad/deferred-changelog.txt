## wave F1

**`fathom review --format github` + `--out` (VB-22, VB-23).** `--format
github` renders one deterministic Markdown PR comment per review: changed
symbols with resolved callers and their resolution tier, call-site
completeness, governing rules with cited lines, a `fathom verify` line
whenever the diff touches a `docs/plans/*.md` row's anchored symbol,
affected tests and the test gap, and a coverage block when a profile is
supplied — every finding line carries a stable claim id, no model prose on
this path. `--out FILE` writes the report (any format) to a file instead of
stdout, for a CI step to hand to a comment-upsert step. `docs/adoption/
github-action.md` documents a GitHub Action that posts/updates that comment
in place (keyed on the `<!-- fathom-review -->` marker) and reports a
`fathom / review` status check that can be required under a Ruleset
(`docs/adoption/github-rulesets.md`).
