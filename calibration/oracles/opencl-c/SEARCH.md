# OpenCL C oracle and grammar source search

Checked 2026-10-26. This records sources searched, measured grammar failures and untried semantic alternatives. The native grammar-gate refusal proposal is recorded separately; no semantic-tool ceiling is claimed. The assessment distinguishes complete native grammar screens, the historical raw-AST capability probe and the replay of the existing clang pipeline. No support level or ceiling is claimed. [Bounded public-search receipts](search-receipts.json) record the exact queries/URLs, bounds, HTTP status, recomputed response SHA-256 and aggregate counts without publishing response identities or result filenames.
