# OpenCL C oracle and grammar source search

Checked 2026-10-26. This records sources searched and untried alternatives, not a ceiling. The assessment distinguishes complete native grammar screens, the historical raw-AST capability probe and the replay of the existing clang pipeline. No support level or ceiling is claimed.
