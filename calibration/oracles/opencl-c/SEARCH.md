# OpenCL C oracle and grammar source search

Checked 2026-10-26. This records sources searched and untried alternatives, not a ceiling. Only the pinned grammar comparison and Clang capability probe in the assessment were run.

| Source family | Source searched | Result and status |
|---|---|---|
| Own toolchain | [Clang OpenCL support](https://clang.llvm.org/docs/OpenCLSupport.html), [AST dump](https://clang.llvm.org/docs/IntroductionToTheClangAST.html), installed Clang 21 help and pinned OpenCL headers | CL3.0 JSON AST probe run at the exact binary/header hashes in pins.json. Tier B reconstructed SPIR64 context. Runtime options and declaration origins still need an adapter. |
| Native runtime | [Khronos clBuildProgram](https://registry.khronos.org/OpenCL/specs/unified/refpages/man/html/clBuildProgram.html), [CTS](https://github.com/KhronosGroup/OpenCL-CTS/tree/16b197d191903abad0047e6bcb113167b589ecb4) | Compiler supplied by an implementation, not a single Khronos frontend. CTS has no external .cl population at this pin. Runtime/device route untried here. |
| SCIP list | [SCIP README at d556dd3](https://github.com/scip-code/scip/blob/d556dd3c24b3c1787e0b62cd31f25188300e3098/README.md), [scip-clang v0.4.0](https://github.com/sourcegraph/scip-clang/tree/1860adf8deab7870fed2199eadc190e3965a92ff) | Publishes C/C++/CUDA scope. OpenCL is not named. A compilation-database entry with -x cl remains untried, rather than ruled out. Embedded LLVM pin is 2078da43e25a4623cab2d0d60decddf709aaea28. |
| LSIF list and producer | [Sourcegraph LSIF indexer list](https://lsif.dev/), [archived lsif-clang](https://github.com/sourcegraph/lsif-clang/tree/22cb393a281f08403d17ed4c6dae323bf11a2c8e) | The archived Sourcegraph-maintained indexer list names C++/C/Obj-C for the Clang route and contains no OpenCL-specific entry. The archived producer points to SCIP. This is a search result, not an incompatibility test. |
| GitHub indexer search | GitHub repository queries scip-opencl and OpenCL LSIF | No matching OpenCL-specific indexer returned. Search misses do not establish absence. |
| Language servers | GitHub queries OpenCL language server, opencl lsp and opencl-language-server; [Galarius server at c3b8b8c](https://github.com/Galarius/opencl-language-server/tree/c3b8b8c6e6b9a6d269cb040d9cd03387802ad3d4) | MIT.
