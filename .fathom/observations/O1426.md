### O1426 — A pack readout rule's untrusted flag is false by construction; the pin is the trust

- **Symptom:** none. RO-34 loads a pinned pack's `readouts` rules without a sha256 trust entry, unlike `.fathom/readouts.toml` (RO-33).
- **Reasoning:** adoption is the binding (fathom-dir design section 7.2): the repository pins the module, `techpack.Discover` reads only those pins, and the rule must carry a passing fixture. A pack bump changes the pin, which review sees in go.mod or cue.mod.
- **Gap:** a pack rule loads only under `[readouts] mode = rich` in the hook (observe never loads packs), so observe rows never show pack rules. Doctor's readouts row names each pack's served and withheld rules in every mode.
- **Status:** open
- **Impact:** a user who wants pack rules observed before rich must set rich for a trial.
