### O1491 — Contract keys have no persisted reader, so ADR-077's rank (2) reads only log templates, which Go files never carry

- **Symptom:** RS-1's second evidence tier ("a contract key or log template on the edited symbol") is empty on every Go path.
- **Evidence:** `internal/docindex/linkpass.go` `ResolveContractKey` returns false for every key until SG-2; ADR-050 §6's `contract_keys` and `system_links` tables are not built; `ServiceRefsFor` loads a service's whole route table (an I48 whole-table read on the request path). TL-4 log templates exist only for Python, Java, JS/TS and PHP loggers.
- **Root cause:** the system graph's persistence slice has not landed (table freeze).
- **Fix:** `editedFileFacts` reads the edited file's observation names through the indexed `SymbolNamesForSource` and keeps log templates and key-shaped names; contract keys join the tier when a per-file key reader exists.
- **Status:** open.
- **Impact:** tier (2) ranks only on repositories whose code carries logger templates.
