- **Symptom:** PHP call_precision .6924 (call_recall 1) against scip-php 71a5b117, unchanged by wave ld
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect php -subject <guzzle|monolog> -tool-oracle <php-parser definitions-only dump> -scip <scip-php index> -unmatched`, guzzle 7b2f29fe (7.9.3) and monolog 10d85740 (3.9.0), PHP 8.5.11; each pair's written site read: 1,726 are a method call on a variable receiver (`$request->getUri()`, `$e->getMessage()`; 1,123 monolog, 603 guzzle) the index records no occurrence for when the receiver is vendor-typed, builtin-typed or untyped; the other 143 mix a variable receiver with `$this->`, `self::`/`static::`, a function absent from phpstorm-stubs (`zend_monitor_custom_event`, `func_get_args`) or an enum's builtin `from`/`tryFrom`/`cases`; `oracle_only` is 0
