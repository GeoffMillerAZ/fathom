### O495 — a match.sniff on `.cue` makes every .cue file the sniff does not match "ambiguous", and ingest's gate then excludes it

- **Symptom:** the first timoni manifest claimed `.cue` by a content sniff (`values:`, `bundle:`, `runtime:`, `timoni:` at the head of a file); ingest stopped reading every other CUE file
- **Evidence:**
  - **Tool:** `go test ./internal/fusion` on the wave-fx clone, fathom 6e491d46 plus the uncommitted dialect
  - **Expected:** a .cue file no Timoni signal claims reads as before (the CUE extractor, tag cue)
  - **Actual:** TestIngest_ExtractorEpoch_CUEDepthChangeForcesReExtraction, TestPolyglot_E2E, TestIngest_CUEModuleAncestorTagged, TestIngest_CUEPlain_NoModuleAncestor and TestEnrichCUEEdges_Fixture failed (no CUEDefinition observed); my first ingest test passed only because its plain file happened to contain `values: {`
  - **Repro:** add a `sniff` on `.cue` to any dialect manifest and ingest a repository with a CUE schema that does not match it
- **Root cause:** connector.ClassifyDialect answers `ambiguous` for an extension that has a claimant (a sniff) but no plain owner when the sniff misses, and gateDialectFile excludes `ambiguous` (ExcludedAmbiguous) for every dialect-owned extension, whatever extractor `p.exts` holds for it
- **Fix:** the timoni manifest has basenames and globs only, no sniff; "a values.cue only inside a module" is timoniDispatch's rule (a timoni.cue ancestor), and TestIngest_TimoniDialect pins that a plain .cue is read (schema/other.cue)
- **Status:** fixed (wave fx, item timoni)
- **Impact:** none shipped; any future dialect that wants a content sniff over an extension another extractor owns hits the same exclusion, which the gate's `ambiguous` rule should say in its doc comment
