### O887: `tests select --safe` counts a line-shifted method as changed, and the error interface's dispatch then selects 3,066 tests in 62 packages for a cmd/fathom-only diff

- **Symptom:** wave rf1 (delivery), `fathom tests select --safe --since origin/main` on a scratch ingest of 4fa213f5. The diff touched cmd/fathom only (edithook*.go, prompthook.go, their tests) and three plan files. The selection was 3,066 tests in 62 packages, among them cmd/contextbenchscore, internal/store and pkg/client, which cannot import package main
- **Evidence:** 2,423 of the selected tests carry "reaches fathom::cmd/fathom/pinSkip.pinSkip.Error via interface dispatch", and 568 carry `catFileBatch.close`. Neither method changed. Both sit below a header comment in cmd/fathom/edithook_pin.go that grew by two lines, so their spans moved. pinSkip implements `error`, so every test that calls `Error()` on any error reaches it through the iface-dispatch edge
- **Root cause (suspected):** a symbol whose span moved without a content change reads as a changed symbol, and `--safe` follows interface-dispatch edges from `error.Error` with no bound
- **Fix:** the first half shipped before this entry was worked: TQ-29 (d91e174a) counts a Go symbol as changed only when its own text changed, so two comment lines above `pinSkip.Error` select no changed symbol (measured in a scratch commit with a scratch ingest, `tests select --safe --since HEAD~1`: 1 test in 1 package before and after this fix, the one test reading the file's source). The second half: under `--safe`, a test that reaches a changed symbol only through a dispatch into error's `Error`, `fmt.Stringer`'s `String` or `fmt.GoStringer`'s `GoString` is not selected; one line counts those tests and names the method, `--json` lists them under `stdlib_dispatch_only`, and `--stdlib-dispatch` selects them (`impact.SplitStdlibDispatch`). An edit of `pinSkip.Error`'s body: 624 tests in 1 package before, 1 after, 623 counted as reaching it only through `error.Error`
- **Impact:** the contract "run what tests select prints before a whole-package run" turned into a near-full-repository `-race` run on a machine with 1 GiB of swap left
- **Status:** fixed (wave fix1, item tsel)
