### O536 — Dart's L3 ceiling beyond the dialect: a method, getter or field on a typed receiver, and a reference outside any definition

- **Symptom:** 33 + 23 + 18 Dart file-edge pairs (17 + 11 + 12 only these) are a member access on a value whose type another file defines (`emit.isDone`, `response.statusCode`, `AsyncState.initial().copyWith(...)`, `super.onChange(...)`); 2 are the arguments of a top-level `@GenerateMocks([...])` annotation
- **Evidence:**
  - **Tool:** the scratch classifier at fathom cd4c1e9e; mocks.dart:11-25 (`MockSpec<ConnectionMessageQueueOut>` on the lines above a function)
  - **Expected:** the first is an edge to the file that defines the receiver's type; the second an edge from the file
  - **Actual:** a member name after a `.` is `@ref.not` on purpose (precision), and fileresolve draws an edge from the innermost definition enclosing the reference, an annotation above a function belongs to none
  - **Repro:** http/test/http_retry_test.dart:19
- **Root cause:** the first needs a receiver's type (typed edges, not file-resolved ones); the second is the definition's range starting at its signature, not at its leading annotations
- **Fix:** none this wave: typed edges come from the SCIP import (item scip) not the dialect; for the second, a tags query cannot extend a capture over sibling annotation nodes, so the file resolver would have to fall back to a file-level edge when no definition encloses a reference
- **Status:** open
- **Impact:** the written Dart L3 ceiling: .7844 recall with the typed-receiver classes (about 65 pairs) unreachable without types; L3 reads excellent regardless (bar .50)
