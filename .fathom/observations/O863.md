### O863 — K29 re-reads C under K25 ruling 3: scip-clang names a file-local symbol alike in every translation unit, and C's L3 falls from excellent to unmet

- **Symptom:** c.json, read at 085a1b86 before ruling 3 (L4, every level excellent), re-read under the current harness at f2b852ab (wave lf5, K29) reads file_edge_recall .2455 (3,998 of 16,283 truth pairs), under L3's good floor of .25, so level_met falls from L4 to L2. Nothing in the C dialect or the resolver changed. Only the truth grew, from 7,501 to 16,283 pairs.
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect c -scip <index> -scip-defs -tool-oracle preproc.json` on libuv v1.53.0 and curl 8.22.0 (scip-clang 0.4.0 indexes rebuilt from the pinned compile databases, 477 and 495 entries), then a scratch classifier of the index's multiply-defined symbols. The classifier is a Go program over third_party/scip in worker scratch and is never committed.
  - **Actual:** `scip_file_edges_every_definer` is 8,613 on libuv and 176 on curl. On libuv the pairs only a later definer draws are file-local test callbacks and state that scip-clang names alike in every file defining them, each with the same signature hash:

    | symbol | definers | later-definer pairs |
    |---|---|---|
    | `close_cb(74ef0d3a3c5968a2).` | 73 | 5,184 |
    | `close_cb_called.` | 66 | 4,225 |
    | `connect_cb(…).` | 46 | 2,025 |
    | `alloc_cb(…).` | 42 | 1,681 |
    | `timer_cb(…).` | 34 | 1,089 |

    Others follow the same pattern: `client.`, `server.`, `loop.`, `write_cb(…).` and more. Every libuv test file reaches every other. curl's 176 pairs are mostly a header's declaration to its definition (`Curl_cfree` in curl_setup.h and easy.c) and docs/examples' `payload_text`. Owner ruling L2 (LB-F473) leaves nothing out, because C has no namespace.
  - **Prototype (nothing committed):** a harness switch that reads a reference inside a document defining the symbol as that document's own copy (O751 step 2, applied to scip-clang) reads file_edge_recall .5667 and precision .9948 on the same indexes, with every level excellent (duplicate_narrowed 9,228, every_definer 127).
  - **Repro:** the c measuring commands of `calibration/oracles/scip-clang/README.md` with an indexbench built at f2b852ab. The prototype changes the `default:` case of ScoreSCIPWith's definer switch.
- **Root cause:** a `static` function or variable has internal linkage, so each translation unit's copy is its own. scip-clang 0.4.0 still gives every copy one symbol, and ruling 3 resolves a reference to every definer. This is the shape O806 named second for C++ (Catch2's `CATCH2_INTERNAL_TEST_0`, doctest's `DOCTEST_ANON_FUNC_2`) and the shape O751 step 2 narrows for rust-analyzer's per-target copies.
- **Fix:** owner ruling M3 (K19), committed alone at 9b2e7439 with the C holdout and its criterion (LB-F487): a reference to a file-local function or object (internal linkage, C11 6.2.2p3) resolves to the copy in its own translation unit, the referring document or a header its includes reach by the preprocessor oracle, never another unit's same-named copy; an external-linkage symbol keeps ruling 3. Linkage is the compiler AST's (clang-ast-defs `internal_linkage`, tier A), not the written `static`. The rule is scoped to dialect c.
- **Status:** closed (wave lf6, owner ruling M3). The holdout libevent/libevent release-2.1.13-stable, read once at 9b2e7439, passes its criterion: file_edge_recall .523 (638 of 1,220) and file_edge_precision .9984 (LB-F488, O907). c.json, re-read at 9b2e7439, reads file_edge_recall .5615 (3,998 of 7,120) and precision .9948, with 9,162 pairs left out (`scip_file_edges_internal_linkage`). L3 is excellent and level_met is L4, so LB-Q-c is closed (LB-F489). The 174 pairs ruling 3 still draws to a later definer are O908. C++ has the same shape on spdlog's Catch2 tests (O909) and keeps ruling 3 until it has its own ruling.
- **Impact:**
  - C's L3 reads unmet until a ruling.
  - The C++ readings carry the same shape: ruling 3 draws 3,029 pairs to a later definer on fmt, json and spdlog. Most of these are macro-written test functions named alike in every translation unit. Owner ruling L2 left C++'s L3 excellent anyway.
