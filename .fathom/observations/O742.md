### O742 — blast_radius kind:"delete" reads "proven zero" for a canonical key whose callers are file-resolved or syntax calls, and find_callers says "no direct callers" beside a typed_callers list

- **Symptom:** given the canonical key `find_symbol` and `symbol_context` hand out, `blast_radius` kind:"delete" answers "0 referents ... proven zero (heuristic edges checked)" for a Python function with four callers, and `find_callers` answers "no direct callers ... found" with an empty `callers` while its own `typed_callers` lists the four
- **Evidence:**
  - **Tool:** blast_radius kind:"delete", find_callers (found measuring O741; flask 3.1.3 scratch store, deployed binary 70afc4a9 and a build of 361e3113 alike)
  - **Expected:** `blast_radius {kind: "delete", symbol: "flask::src/flask/helpers.get_debug_flag"}` names its 4 callers (app.Flask.debug, cli.ScriptInfo.load_app, cli.run_command, sansio/app.App.make_config), as the bare name `get_debug_flag` does and as kind:"rename" on the key does (5 call sites)
  - **Actual:** the key reads 0 referents, "proven zero"; the bare name reads 4 (tier heuristic). `find_callers` on the key, with or without include_heuristic, reads `callers: []` and "no direct callers" beside `typed_callers` of 4 `file-resolved` edges. A module symbol (K18) is the extreme case: its only callers are its importers' file-resolved edges, so `flask::src/flask/signals.<module>` (5 importers) reads "0 referents, proven zero"
  - **Repro:** ingest flask 3.1.3; `blast_radius {service: flask, kind: delete, symbol: flask::src/flask/helpers.get_debug_flag}`
- **Root cause (read, not fixed):** `safeDeleteCheckAnswer` (internal/mcp/safe_delete.go) unions `backend.FindCallers` (a syntax `Calls` match by bare name or key suffix, and a dialect's `Calls` hold the bare callee text, so a canonical key matches none) with `resolvedCallersOnly` (typed edges of resolved confidence; `file-resolved` is heuristic, core/edge_confidence.go), so a file-resolved caller is in neither set. find_callers' `callers` and summary come from the same two reads, while `typed_callers` reads every typed edge
- **Fix:** none here (outside wave h2's query-layer files). Count file-resolved typed callers in delete's referents at their heuristic tier, and let find_callers' summary read `typed_callers` when `callers` is empty
- **Status:** open
- **Impact:** a delete-safety answer that says "proven zero" for a live function in every dialect resolved by the file resolver (Python, JS/TS, Ruby, ...); an agent following it deletes called code
