### O1458 — `tests select --safe` picked 1157 tests for a one-package change because a new error type's `Is` method was reached from every `errors.Is` call

- **Symptom:** a change confined to one package, four new files that add an error type with an `Is(error) bool` method, made `fathom tests select --since <base> --safe` rank 1157 tests. Tests in commands that never import the package were listed as reaching `RecordedError.Is`. Before the commit, the same command selected 0 tests and reported 0 changed symbols, because the new files were untracked. One report, 2026-09-29 (theme T23 in docs/bench/readings/feedback/adopter-triage-2026-10-20.md).
- **Evidence:**
  - **Reports:** agentic-kit O4, with the commit, the base, the scratch-store repro and the reasons line that names `RecordedError.Is`.
  - **Related record:** O887 (fixed, wave fix1) is the same over-fan through a standard-library interface: `error.Error` dispatch selected 3,066 tests for a cmd/fathom-only diff. Its fix counts a symbol as changed only when its own text changed (TQ-29). It also names and counts dispatch-only tests, and `--skip-stdlib-dispatch` (382ebe995) leaves them out, for exactly three methods: `error.Error`, `fmt.Stringer.String` and `fmt.GoStringer.GoString` (cmd/fathom/tests_select.go). An `Is(error) bool` or `As(any) bool` method that `errors.Is`/`errors.As` reach is not among them.
  - **Not probed:** this wave did not reproduce agentic-kit O4 on a scratch ingest.
- **Root cause:** suspected, not reproduced. It is O887's class through a fourth standard-library method: `errors.Is` dispatches to any `Is(error) bool`, and the graph links every `errors.Is` call site to every implementer, whether or not the error values can reach it. O887's fix lists only Error, String and GoString. A git-range diff also cannot see untracked files, so `--since` before the commit saw no change and said nothing.
- **Fix:** proposed, not built. Reproduce first on a fresh scratch ingest of the agentic-kit commit the report names. If dispatch is the cause, add the `Is`/`As` methods that `errors.Is`/`errors.As` reach to O887's stdlib-dispatch set, so they are counted and can be skipped. Better, count such a dispatch only when the test's package imports the implementer's package. Have `--since` warn when the tree holds untracked source files.
- **Status:** open
- **Impact:** a "safe" selection that runs the whole repository's tests saves nothing. One that silently selects 0 for untracked files is not safe.
