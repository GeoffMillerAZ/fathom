### O852 — Cost of wave lf5's CSS and SCSS changes: CSS under the bar, SCSS's new dispatch disclosed as previously skipped (K27)

- **Symptom:** K26/K28 bound a change's ingest cost at +15% wall and +20% store against origin/main, per change and summed per language over the wave; the item changes CSS's extraction (references, a module symbol, wildcard imports; LB-F459) and dispatches SCSS for the first time (LB-F465).
- **Evidence:**
  - **Method:** scratch ingests (`fathom ingest --store <scratch> --path <repo>`), three rounds, the two binaries alternating, one at a time under the wave's ingest lock: base built at 2ad46bd1 (origin/main 9e21be2b plus design 1.8, documents only), new at the item's tree (bbb6caf6 plus the dart-sass oracle, which ingest never runs). Medians of three.
  - **gitea v28.1.0 `web_src/css`** (92 CSS files, the CSS change alone): store 3,899,392 to 4,231,168 bytes (+8.5%), wall 0.43 to 0.46 s (+7.0%); observations 3,963 to 4,055 (one module symbol per sheet), typed edges 0 to 188 (an `@import` between module symbols, a name an imported sheet declares).
  - **fathom** (the repository itself, 37 CSS files, no SCSS): store 164,462,592 to 164,655,104 bytes (+0.12%); wall 129.1 to 71.9 s, the rounds ranging 61 to 134 s on both binaries: this machine's load under the wave, not a measurement of the change.
  - **twbs/bootstrap v5.3.8** (122 `.scss`, 47 `.css`): store 2,609,152 to 4,452,352 bytes (+70.6%), wall 1.25 to 1.57 s (+25.6%); observations 1,649 to 4,976, typed edges 785 to 1,011. The base reads no `.scss` (the language was refused and undispatched), so its output for the measured scope is empty.
- **Root cause:** CSS's cost is its module symbols and the edges they carry. SCSS's is the language's first extraction.
- **Fix:** none needed for CSS (under the bar per change and summed). SCSS falls under K27: a cost read against a baseline that did no work is disclosed as previously skipped, never counted as a regression, and no repository exists where SCSS extraction already worked; the gain is 122 stylesheets indexed (3,327 definitions on bootstrap) at L1 good and L3 excellent. An owner ruling may still read it under K26.
- **Status:** closed (disclosed)
- **Impact:** a CSS-only tree's store grows by its sheets' module symbols (+8.5% on gitea); a SCSS tree is indexed where it was skipped.
