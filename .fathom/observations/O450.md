### O450 — Python's call_precision .8751 is the oracle's ceiling: all 1,661 fathom-only pairs are calls the source writes, and no pair is a dialect error

- **Symptom:** Python L2 reads call_precision .8751 (11,635 of 13,296 pairs) against .90, and LB-Q-python-rest asked whether the 1,661 fathom-only pairs hold any dialect error to fix.
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect python -subject <clone> -scip <index> -unmatched <x.json>` over fastapi 864b569cf8 (306 fathom-only pairs) and flask 22d924701a (1,355), scip-python 0.6.6 run by calibration/oracles/scip-python/run.sh in each subject's dependency environment, fathom 5f41217d and 3cde84c9 (the counts are identical).
  - **Method:** each pair (path, caller, callee) located by `ast` to a call node of that callee inside a scope of that caller (decorators belong to the decorated definition, a module-level assignment and an annotated class attribute to the variable, as LB-F65 says): 1,661 of 1,661 found, so every pair is a call the source writes. Each then classified by what scip-python's occurrences hold at the callee's own range (a Go dump of the index) and by the receiver the call is written on.
  - **Actual:** (fastapi, flask, total) scip-python writes no occurrence at the callee: receiver an unannotated parameter (pytest fixtures in tests/; 5 in non-test code) 24, 556, 580; receiver a local it cannot type 171, 289, 460; receiver an imported module or name it did not resolve 8, 318, 326; receiver a call result, subscript, operator or literal 19, 48, 67; receiver a module-level name, an annotated parameter, self or other 24, 74, 98 (1,531 in all). It resolves the callee to another symbol (`os.path.dirname` to `ntpath/join`, so the harness's written-name check drops it) 9, 31, 40. It names the callee a local 0, 3, 3. It names the callee but the harness holds no pair for it: a called parameter (`call_next`, `fn`, `func`; a parameter symbol is no callable name) 13, 18, 31; the last attribute statement of a class body (`tags: set[str] = set()`), where the attribute's fallback range, which runs to the end of the line, is not nested in the class's own enclosing range, so the call is given to the class 37, 6, 43 (the 71 oracle-only pairs are these and 28 more of the same shape); no definition range encloses the call (the implementation of an @overload function: scip-python gives only the first overload a definition occurrence, and the later two are references) 1, 12, 13. The classes sum to 1,661.
  - **Arithmetic:** .90 needs fathom-only at or below about 1,329 of 13,296. The pairs the oracle names but does not match (40 + 3 + 87 = 130) would read .8849 if all matched; the 1,531 it writes nothing at cannot match; so no extractor change reaches .90, and dropping a call to raise the figure is refused.
  - **Experiment (not committed):** flask's package is in `src/`, which is not on scip-python's import path (run.sh uninstalls the subject, and `import flask` in tests/ resolves to nothing, so every `flask.X` and every fixture built from it is untyped). `PYTHONPATH=<flask>/src` before `scip-python index` takes flask's fathom-only pairs from 1,355 to 757 (call_fathom_in_truth 1,603 to 2,201), and Python reads call_precision .9201 and call_recall .9942, L2 excellent, with file_edge_recall .5119 and import_resolution .951 (L3 still excellent), no extractor change.
  - **Repro:** the commands above; the experiment is `PYTHONPATH=$PWD/src PATH=<venv>/bin:$PATH VIRTUAL_ENV=<venv> scip-python index --cwd $PWD --project-name flask --output <out>` in a flask checkout, then `lang-oracle`.

The dialect records every call the source writes.
