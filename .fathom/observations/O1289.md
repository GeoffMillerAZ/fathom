### O1289 — non-Go test entries: 6 -> 43 on a pytest repo, 0 -> 53 on a vitest repo (TQ-27)

- **Symptom:** before TQ-27 the one test-entry rule (`repofacts.IsTestEntry`) read only a `Test` name prefix, so pytest's `test_*` functions, JUnit `@Test` and xUnit `[Fact]` methods, PHPUnit `test*` methods and Rust `#[test]` functions were not tests, and a jest, vitest or mocha `it` block was not even a symbol: its calls belonged to the file's `<module>`.
- **Evidence:**
  - **Tool:** `internal/repofacts/convention.go` (`IsTestEntry`, packs.json `entry_prefixes`, `entry_attributes`, `entry_calls`), `internal/extractor` (JavaScript and TypeScript `@definition.test`, kind `titled`; Rust `@signature.lead`)
  - **Measured:** scratch ingests under `w-tq/` of shallow clones, base 4823561d against this branch, counting symbols `IsTestEntry` accepts and the tests `impact.BlastRadius` names from every non-test file. pallets/itsdangerous (672971d): 6 -> 43 entries (the 6 `Test*` classes, then all 37 `def test*` functions and methods, 43 of 43 by grep), 0 -> 13 reached by the blast radius. unjs/ufo (f06c800, vitest): 0 -> 53 entries (every `describe`, `it` and `test` block in a test file, each a `JSTest` symbol named by its quoted titles, `"sum" "adds"`), 0 -> 52 reached.
  - **Repro:** `TestNonGoTestEntriesPytestJestJUnitXUnitPHPUnitRust` (internal/analysis/impact)
- **Root cause:** the rule took a name and a path only, and the JavaScript and TypeScript queries named no call as a definition.
- **Fix:** TQ-27. The rule also reads the signature; the core `Test` prefix stays for every test file (TestDelegatesAnswerAsBeforeTheCut), each pack adds its runner's entries. A test block's title is quoted so `describe("sum")` never reads as the function `sum` a call resolves to.
- **Limits, recorded:** (a) `tests select`, `test_impact` and `symbol_context`'s tests list walk callgraph's own `Test` prefix, not this rule, so they do not name these entries yet: that wiring is TQ-28's row. (b) A Rust `#[cfg(test)] mod tests` inside `src/*.rs` is in no file the role classifier calls a test, so its `#[test]` functions are not entries, by the row's own clause. (c) vitest's `*.test-d.ts` type tests are not test files to the classifier (3 blocks in ufo). (d) Python methods reach their code through `self`, so 13 of itsdangerous's 43 entries reach a production symbol in the graph. (e) The core prefix still reads a Java import of `org.junit.jupiter.api.Test` as `Test`, as before; no walk reaches an import.
- **Status:** fixed (wave adopt1, item tq); limit (a) open under TQ-28
