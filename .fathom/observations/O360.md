### O360 — C++ L2 call precision 0.3208: what the 3,110 fathom-only and 115 oracle-only pairs were

- **Symptom:** docs/bench/readings/lang/cpp.json (2026-10-01, scip-clang 0.4.0, tier A) read call_precision 0.3208 (1,469 of 4,579 fathom pairs in the truth) and call_recall 0.9274 on fmtlib/fmt 12.2.0 and nlohmann/json v3.12.0; L2 unmet.
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect cpp -unmatched` per subject, each fathom-only pair's written call sites in its caller's lines read against the build's own compiler (`calibration/oracles/clang-calls`, Apple clang 21.0.0 `-ast-dump=json` per compilation database entry) and the preproc oracle's active lines; gabime/spdlog v1.17.0 added as the third subject (baseline 778 fathom-only, 213 oracle-only, measured with the base harness at 32afe369).
  - **Expected:** a fathom pair the index does not hold is a call fathom invented.
  - **Actual:** fathom-only pairs by class, fmt / json / spdlog:

    | class | fmt | json | spdlog |
    |---|---|---|---|
    | template-dependent call: no callee before instantiation (CXXDependentScopeMemberExpr, UnresolvedMemberExpr, UnresolvedLookupExpr, DependentScopeDeclRefExpr, CXXUnresolvedConstructExpr) | 593 | 818 | 108 |
    | caller written by a macro: gtest TEST(suite, name) is suite_name_Test::TestBody to the index | 521 | 0 | 0 |
    | call the compiler resolves that the index does not reference (member or function template specialization, overloaded or constexpr helper, local class method) | 334 | 208 | 517 |
    | constructor call written `T(` (the index references the class or nothing) | 132 | 2 | 29 |
    | calls on lines the build discards inside a kept definition (#ifdef _WIN32, C++20 branches) | 96 | 5 | 45 |
    | caller in code scip-clang 0.4.0 does not index (formatter<T> specializations, members of basic_json) | 95 | 120 | 37 |
    | no compiler call at the written name: a lowercase macro expands it (putc_unlocked) or it sits in a type (decltype, noexcept, an array bound) | 70 | 43 | 6 |
    | call through a variable, field or lambda | 17 | 13 | 11 |
    | extractor error: functional cast (unsigned(t), short(4), a typedef of a builtin) | 16 | 0 | 1 |
    | extractor error: no call written in the caller (keyword-named definitions `if`/`switch`, `noexcept(...)`, `Factory::template create` read as `templatecreate`) | 8 | 19 | 24 |
    | total | 1,882 | 1,228 | 778 |

    Operator calls and namespace-qualified callees were no class of their own: the last-segment rule (design 1.4) already matches `ns::f`, and an overloaded operator is no call either side writes as `name(`. Oracle-only (fmt 99, json 16, spdlog 213) were led by references scip-clang writes at a function's declaration (`int close(int fd);` in fmt's posix-mock.h, every member declaration of spdlog's headers), calls attributed to a namespace because an export or inline macro (SPDLOG_INLINE, SPDLOG_API) broke the definition around them, member initializers scip-clang names as methods in a class template (`: loc(std::localeconv())` in json's serializer), and a base-class constructor in a member initializer list (`: flag_formatter(padinfo)`), which the dialect does not capture.
  - **Repro:** the commands in calibration/oracles/clang-calls/README.md and calibration/corpus.d/cpp.yaml, then `indexbench lang-oracle ... -tool-oracle <preproc.json> -tool-oracle <clang-calls.json> -unmatched <file>`.
- **Root cause:** the index holds a template's pattern only, references no call to a specialization and skips some code; a lexical extractor cannot know a dependent call has no callee; and the C++ dialect itself recorded casts, keywords and `::template` names as calls (LB-F117).
- **Fix:** LB-F116 (the compiler as tier-A call-site oracle, every class counted and disclosed in the reading), LB-F117 (the dialect's own errors). Reading: call_precision 0.9517 (3,682 of 3,869), call_recall 0.9268 (3,682 of 3,973), L2 excellent on three subjects.
- **Status:** fixed (L2); remaining classes named in LB-Q-cpp-rest: fathom-only 187 (104 no compiler call at the written name, 27 resolved calls the index attributes to another caller, 26 misparsed callers, 13 gtest bodies, 12 functional casts through a project typedef, 5 other), oracle-only 291 (led by spdlog's macro-broken definitions).
- **Impact:** L2 measured honestly for C++ for the first time; the same oracle can serve C (libuv's TEST_IMPL) when item cinc opts in.
