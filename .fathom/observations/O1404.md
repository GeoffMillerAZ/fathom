### O1404 — Tech pack discovery reads Go and CUE pins only, so this repository's own kits are not discovered yet

- **Symptom:** `techpack.Discover` on this repository finds no pack: app-kit and agentic-kit live as in-tree mirrors under `third_party/` with a `.vendor-commit` pin, and ADR-070 removed their `require` lines from `go.mod`.
- **Evidence:** design `docs/design/fathom-dir.md` section 7.2 source 3 (amendment A1) names in-tree mirrors as a discovery source; plan row FD-11 names only the Go and CUE pins, and wave fd4 built exactly that.
- **Root cause:** A1 landed in the design after FD-11's row text was written; no plan row carries source 3.
- **Fix:** none in this change; a row for source 3 (a committed mirror directory with a pin file, read offline) is needed before FD-23 (consumer #1) can discover app-kit's pack here.
- **Status:** open
- **Impact:** until then a kit's header and fixtures in `third_party/app-kit/fathom-pack/` change nothing in this repository.
