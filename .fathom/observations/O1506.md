### O1506 — on an adopter's Unity project with a Go toolchain, the Go typed pass processed 21 of 31 Go packages, with 0 reported failures

- **Symptom:** on an adopter's Unity project with a Go toolchain, the Go typed pass processed 21 of 31 Go packages, with 0 reported failures
- **Evidence:**
  - **Tool:** fathom ingest (Go typed pass)
  - **Expected:** the typed pass processes every Go package the syntax pass indexed, or names each one it skips and why
  - **Actual:** 21/31 packages processed, 0 failed, 861 typed edges (673 direct, 70 interface dispatch, 118 unresolved), identical on v0.18.0 and v0.22.0; the 10 skipped packages are not named in the ingest output the adopter read, so their typed edges are silently absent (I38)
  - **Repro:** fathom ingest of a repository with several Go modules or build-tagged packages; compare the typed pass's processed count with the package count
- **Root cause:** a package the load returned with no connector-allowed compiled file went to `PackagesSkipped`, which no surface read, so seen minus processed was never explained: the synthesized `<pkg>.test` mains and test-only plain packages (harmless), but also build-constrained packages, directories whose only Go file has a name Go ignores, and every package made only of cgo files (its compiled files are build-cache copies, so it read as connector-ignored and lost its typed edges). Go files under a `_` or `.` directory segment (the connector already prunes testdata and vendor), files no go.mod governs, and a tree with no module at all never reached the load and were in neither number; foreign nested modules were named on stderr only.
- **Fix:** `docs/plans/efficiency-wave.md` EW-81 (`typedSkipReason`: a closed reason set, counts that sum to packages seen, cgo-only packages resolved from GoFiles, TypedEdgeEpoch 8), EW-82 (`unloadedGoDirs`: directories no load covers and nested modules not loaded, also with no module at all) and EW-83 (`fathom ingest` text and `--json`, the MCP `ingest` tool, docs), in the lane typed pull request (branch claude/typed-skips-20261026).
- **Status:** fixed (v0.24.0, main 938893258); EW-81, EW-82 and EW-83 verify against the indexed main.
- **Impact:** the adopter's next ingest names each of the ten (on the hypothesis that they are 10 test mains, the count by reason settles it); every stored Go service re-runs the typed pass once under epoch 8, and cgo-only packages gain their typed edges. File-level build constraints inside a processed package remain unreported (a follow-up).
