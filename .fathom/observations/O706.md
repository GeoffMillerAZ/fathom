### O706 — verbSubverbs listed the subverbs of 16 of 31 dispatching verbs

- **Symptom:** `fathom fleet --help` named no subcommands, nor did help for arm, assess, capabilities, certify, config, coverage, decide, obligations, plugin, purge, refactor, report, tests or trace; and subverb help keyed on that list would have left `fathom fleet reconcile --help` to the subverb's own parser (flags on stderr, exit 1), the only place `--rebaseline` is described
- **Evidence:** h1 help-flags, 2026-10-09: an AST read of every verb's handler (`subverbLiterals`, cmd/fathom/verbhelp_proof_test.go) found 31 verbs routing on `args[0]` (a switch, an if-chain, or `sub := args[0]`); verbSubverbs carried 16
- **Root cause:** verbSubverbs was hand-written for the verbs whose summary read like a dispatcher; the if-chain dispatchers (`if len(args) > 0 && args[0] == "x"`) and verbs that also run with flags alone were never listed, and nothing compared the list with the handlers
- **Fix:** every dispatching verb's subverbs are listed, and `TestVerbSubverbsMatchDispatch` pins each list to the literals its handler routes on; a parent that also runs alone shows `[<subcommand>]` (CL-8)
- **Status:** fixed (h1 help-flags)
- **Impact:** an agent learning a verb from `--help` never saw half the CLI's subcommands
