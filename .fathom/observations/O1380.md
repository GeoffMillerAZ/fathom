### O1380 — An orientation anchor's symbol is checked lexically, not against the index

- **Symptom:** `fathom config audit` resolves `path#Symbol` by finding the symbol as a whole identifier in the file, so a symbol that survives only in a comment or string still resolves.
- **Evidence:** internal/custodian/orientation.go (`anchorProblem`); the audit runs offline with no daemon.
- **Root cause:** the audit must stay mechanical file reads (the config custodian's contract), so it cannot ask the index for a definition.
- **Fix:** when a daemon is reachable, upgrade the check to `find_symbol` and name comment-only hits; until then the lexical read is the floor.
- **Status:** open
- **Impact:** a renamed symbol is named; a symbol deleted but still mentioned in text is not.
