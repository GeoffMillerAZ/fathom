### O1417 — no solc older than 0.8.37 runs on this machine, so a file with an exact old pragma has no tier-A truth

- **Symptom:** 17 of transmissions11/solmate's 41 files (`pragma solidity 0.8.10;`, 16 of them under `src/test`, and one importing them) are rejected by solc 0.8.37 (`Source file requires different compiler version`). The oracle has no AST for them, so the reading measures the 24 files that compile (`-only`) and names the rest.
- **Evidence:**
  - **Tool:** solc 0.8.10 `solc-macosx-amd64-v0.8.10+commit.fc410830` (sha256 a79fff23 matches soliditylang's list): `bad CPU type in executable`; the 0.8.37 release is a universal binary, the older ones x86_64 only and Rosetta is absent
  - **Expected:** compile each file with its own pragma's version
  - **Actual:** only 0.8.37 runs; OpenZeppelin v5.6.1 (338 files), forge-std v1.17.0 (32) and solady v0.1.26 (107) compile in full
- **Root cause:** no older arm64 solc build is published; solc-js (wasm) carries old versions but is not installed in this item's toolcache.
- **Fix:** TODO, a solc-js install under the toolcache, run per exact pragma, would give the 17 files a truth; deferred, the tier-A reading already holds on 469 compiled files.
- **Status:** open
