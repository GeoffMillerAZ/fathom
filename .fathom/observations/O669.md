### O669 — `fathom --help` and `-h` exited 1 and there was no `--version`

- **Symptom:** `fathom --help` printed `unknown subcommand` on stderr and exited 1; `fathom --version` did the same
- **Evidence:** the K11 reading (`k11-clikit.md` s2), v0.10.0
- **Root cause:** `runWithStdin` looked up `args[0]` as a verb name only
- **Fix:** `--help`, `-h`, `-help` print the verb list on stdout, `--version` and `-version` print `fathom version`'s line, all exit 0; a bare `fathom` and an unknown verb keep usage on stderr and exit 1 (CL-1, `TestRootHelpAndVersionExitZero`)
- **Status:** fixed
- **Impact:** every first-time user and package-manager smoke test
