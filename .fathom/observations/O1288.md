### O1288 — fix1 shipped `tests select --safe` less safe: a stdlib-dispatch-only test was dropped by default

- **Symptom:** after fix1 (5556bd2d, O887's second half), `fathom tests select --safe` left out every test whose only reach to a changed symbol is a dispatch into error's `Error`, `fmt.Stringer`'s `String` or `fmt.GoStringer`'s `GoString`, unless `--stdlib-dispatch` was passed. TQ-M6's method line says "`--safe` is never shipped less safe", and fix1's own audit fixture shows the miss: TestQ builds QErr, calls `err.Error()`, and was dropped for an edit of `QErr.Error`'s body.
- **Evidence:**
  - **Tool:** `cmd/fathom/tests_select.go` (`runTestsSelect`), `internal/analysis/impact/stdlibdispatch.go` (`SplitStdlibDispatch`)
  - **Expected:** `--safe` selects every test that statically reaches a changed symbol; the noise is counted, and dropping it is an opt-in
  - **Actual:** dropped by default; TQ-30's test had been changed to pass `--stdlib-dispatch` to keep its original assertion
  - **Repro:** `TestTestsSelectSafeSelectsDispatchOnlyTestsByDefault`, `TestTestsSelectSafeDispatchNeedsConstruction` (cmd/fathom), both red at 4823561d
- **Root cause:** O887's fix chose the narrower selection as the default to stop a near-full-package `-race` run, trading recall for cost without the method's consent.
- **Fix:** `--safe` selects them again and the count line stays ("N of these tests reach the change only through error.Error dispatch; --skip-stdlib-dispatch leaves them out"); `--json` `stdlib_dispatch_only` carries `selected`; the opt-in `--skip-stdlib-dispatch` drops them. Re-measured on a scratch ingest of 382ebe99 with `pinSkip.Error`'s body edited, `tests select --safe --since HEAD`: 626 tests selected in 1 package (cmd/fathom), 625 counted as reaching it only through `error.Error`; with `--skip-stdlib-dispatch` 1 test. fix1 measured 624 and 1 on its own base; cmd/fathom has grown 2 tests since.
- **Impact:** the wave guide's "run what `tests select --safe` prints" is a full-recall contract again; a worker who wants the cheap run says so with the flag.
- **Status:** fixed (wave adopt1, item tq)
