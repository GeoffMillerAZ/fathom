- **Symptom:** `sym_precision` .9999 on Azure/azure-policy: 3 dialect-only `variable_decl` definitions, all in samples/Compute/deploy-dsc-extension/azurepolicy.json
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect azure-policy -unmatched`, fathom d8216dd4
  - **Expected:** parameters are declared under `properties.parameters` (the definition schema); the oracle reads those

- **Fix:** none; the 3 of 55,714 stay disclosed (the dialect reads what is written). Separately `then.details.type` (an audit-if-not-exists lookup type) is a resource-type reference the brief's `field: type` rule does not name, so it is not emitted
- **Status:** open
- **Impact:** negligible on L1; a `details.type` reference is absent from the policy_ref emission
