### O1245 — A pkg/client test built the TypeSafe adapter itself, so the hexagonal import pin was red before it existed

- **Symptom:** `TestOnlyDecideImportsProviderAdapters` (KS-9) failed on its first run against main: `pkg/client/decision_test.go imports .../foundations/decision/typesafe`.
- **Evidence:** wave dmp1, rails worker, 2026-10-18. `TestWithDecision_TypeSafeFake` called `typesafe.NewTypeSafe` directly and handed the adapter to `Client.WithDecision`, skipping `decide.Open`, its gate and its degrade fallback.
- **Root cause:** the test predates ADR-073 decision 2 (only `internal/decide` imports an adapter package), and it said it proved `decide.Open`'s typesafe branch while it never called `decide.Open`.
- **Fix:** the test opens the port through `decide.Open` (a chmod 600 key file, the fake's loopback base URL, an isolated kill file), as the daemon does. The pin now holds with test files included.
- **Status:** resolved
- **Impact:** the plan's premise, that nothing outside `internal/decide` imports an adapter, was false in a test file. Without the fix, the pin could only have shipped by excluding tests.
