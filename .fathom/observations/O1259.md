### O1259 — `fathom tests select` has no daemon path, so the CLI cannot meet MOD-X2's 2 s trigger on this repository

- **Symptom:** each `fathom tests select --since <ref>` run opens the store in process, lists every symbol, rebuilds the call graph and runs `git diff`: 4.4 to 5.1 s per one-file edit on fathom itself (10 edits, RO-M13's context series). The daemon's `blast_radius` over the same edits answered in 24 to 39 ms.
- **Evidence:**
  - **Tool:** fathom tests select (CLI) against a scratch store at 0201a1d1
  - **Expected:** MOD-X2's trigger, "tests select reads p95 under 2 s on this repository", is reachable by the verb it names
  - **Actual:** p50 4,692 ms, worst 5,053 ms; `runTestsSelect` (cmd/fathom/tests_select.go) calls `store.Open` and `callgraph.BuildBoth` on every run
  - **Repro:** docs/bench/readings/readouts/seam-tests-select-speed.md, `cli.sh`
- **Root cause:** the verb predates the daemon's memoized graph and was never routed through it.
