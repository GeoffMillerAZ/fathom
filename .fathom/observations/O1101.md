### O1101 — `task ui:css` dies with "appkit: signal: killed" on macOS 27: the pinned Tailwind binary's code signature is invalid

- **Symptom:** `bash scripts/ui-css.sh --check` printed `appkit gen: wrote ...theme.css` then `appkit: signal: killed`, identically before and after the DS-4 prune; the CSS proof could not run.
- **Evidence:**
  - **Tool:** scripts/ui-css.sh (`appkit css`, app-kit's internal/tailwind `Run`)
  - **Expected:** the checksum-pinned Tailwind v4.3.0 standalone binary builds app.css
  - **Actual:** `~/Library/Caches/app-kit/tailwindcss/v4.3.0/tailwindcss-macos-arm64` (sha256 matches the pin) exits 137 even for `--help`; `codesign --verify` reports `invalid signature (code or signature have been modified)`. A copy re-signed ad hoc (`codesign --force -s - <copy>`) runs, and ui-css.sh with only its `"${APPKIT_BIN}" css` line replaced by that copy reads `ui-css: generated CSS is current` on both trees.
  - **Repro:** macOS 27.0.1 arm64: run the cached binary with `--help`; echo $? prints 137.
- **Root cause:** the upstream standalone build ships a linker-signed ad hoc signature its appended payload invalidates; macOS 27 kills such an executable on exec. Not memory, ulimit, the script's timeout or the tenancy wrapper, and not in scripts/ui-css.sh: app-kit verifies the cached file's sha256 on every call, so the binary cannot be re-signed in place.
- **Fix:** upstream in app-kit's internal/tailwind: after the checksum verify on darwin, run an ad hoc re-signed copy (or verify, re-sign, and pin the re-signed digest). Not done from fathom (the mirror is never edited).
- **Fix (upstream, merged):** app-kit PR #12, merged as a312217 (squash): after the sha256 check on darwin, `Resolve` returns an ad hoc signed sibling copy (`<asset>.signed`, made once, re-verified) when `codesign --verify` rejects the pinned file; the pinned bytes are never modified so the checksum still verifies every call; a signing failure names the binary and the command. A copy, not in-place signing, because in-place signing would fail the next call's sha256 verify.
- **Status:** upstream fixed; fathom sync HELD. app-kit main moved 206 commits past fathom's pin d34067a (6691 files): the new tree needs modules absent from fathom's go.mod (charm.land/bubbletea/v2, teatest/v2, modelcontextprotocol/go-sdk), so `kit-closure` cannot compute, and it bumps Tailwind v4.3.0 to v4.3.3 (CSS may change). Close when a deliberate pin bump to a312217 or later lands.
