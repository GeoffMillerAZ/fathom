### O1116 — Source-revision importer test depends on TMPDIR being outside a Git work tree

- **Symptom:** Source-revision importer test depends on TMPDIR being outside a Git work tree
- **Evidence:**
  - **Tool:** go test -race ./internal/findings/external
  - **Expected:** Not-a-repository fixture stays outside Git or explicitly owns its discovery boundary under workspace-only scratch policy

  - **Repro:** mkdir -p workspace/tmp; GOWORK=off TMPDIR=$PWD/workspace/tmp go test -race ./internal/findings/external -run TestImportAnchorsHashAtSourceRevision; rerun without TMPDIR passes
