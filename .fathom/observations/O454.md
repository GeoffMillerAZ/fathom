### O454 — the Python harness gives the last attribute of a class body's calls to the class when the producer writes no enclosing range for attributes

- **Symptom:** 43 of Python's 71 oracle-only pairs and 43 of its fathom-only pairs are one shape: `tags: set[str] = set()` as the last statement of a class body (`Item -> set` in the truth, `tags -> set` from fathom).
- **Evidence:**
  - **Tool:** `ScoreSCIPWith` (internal/langbench/scip.go) traced for docs_src/sql_databases/tutorial002.py: scip-python writes `HeroBase#age.` with no enclosing range; the D5 fallback gives it `[line, 0, line, 1<<30]`, and `innermostDef` keeps the class when `contains(class.enc, attr.enc)` is false.
  - **Expected:** `age -> Field` as `name -> Field` is (the same statement shape, one line earlier).
  - **Actual:** the class's range ends at column 59 of its last line, the fallback attribute range at column 2^30, so the attribute is not nested in the class and the class keeps the call; the pair is scored against the class while fathom (rightly, per LB-F65) says the attribute.
  - **Repro:** the trace in O450's method on sql_databases/tutorial002.py.
- **Root cause:** the fallback range's end column in `ScoreSCIPWith`'s D5 branch; internal/langbench belongs to wave le item tsjs, so it is left.
- **Fix:** none here; capping the fallback range at its line's length (or comparing by line when the producer wrote no range) would match 43 pairs and take Python to .8751 + 43/13,296, .8784.
- **Status:** open
- **Impact:** 43 pairs; small beside O450's ceiling.
