### O1309 — lang-oracle scores every reference-bearing tool-oracle file against all of fathom's pairs

- **Symptom:** a dialect measured with two `-tool-oracle` files that both carry `references` reads `ref_precision` .5 and `ref_fathom` exactly twice the truth, with every pair found.
- **Evidence:**
  - **Tool:** `indexbench lang-oracle` (`cmd/indexbench/langoracle.go`, the `tf.References` branch)
  - **Expected:** one file's references are scored against the pairs of the same kinds, or the counts of several files are merged before the precision is taken
  - **Actual:** each file adds all of fathom's pairs (`m.CallPairs(nodes, files)`) to `ref_fathom` and only its own truth to `ref_fathom_in_truth`
  - **Repro:** circleci, 2026-10-19: a compiler file (workflow to job, tier A) plus a source-walk file (job to command, tier C) gave ref_fathom 50, ref_truth 25, ref_precision .5; merged into one file the same pairs read 75 of 74 found
- **Root cause:** the pair counts are per file and the dialect's pairs are not split by the file's kinds.
- **Fix:** the circleci oracle writes one reference file (tier C, the lowest of its two sources) and the definitions in the other. Not fixed in the harness (not this item's file).
- **Status:** open
