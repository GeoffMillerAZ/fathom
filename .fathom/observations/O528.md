### O528 — the harness's D5 line span is not contained in an enclosing range that ends on the same line, so a call on a method's or class's last statement stays with the method in the truth once an attribute there maps (O454, generalized)

- **Symptom:** with Python's attributes mapped (O526), call_precision .9201 -> .9179 and call_recall .9942 -> .9936: 47 new fathom-only pairs (fastapi 33, flask 14), 26 of them the same call the truth gives the enclosing method or class.
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect python -unmatched` before (S1 only) and after (lx-python), fastapi 864b569 + flask 22d9247, each new fathom-only pair located on fathom's node and the index's definitions.
  - **Actual:** 38 of the 47 are on an attribute scip-python defines at that line: the attribute statement is its enclosing definition's last (`self.app = request_response(self.get_route_handler())`, the last line of APIRoute.__init__; a Pydantic model's last field `password: Annotated[str, Doc(...)]`), so the truth's innermostDef (internal/langbench/scip_clangcalls.go) refuses the attribute: its D5 span ends at column 1<<30 on a line the method's enclosing_range ends on at column 61, so `contains(method, attribute)` is false and the method, read first, stays innermost. The extractor gives the call to the attribute, as it does on every other line where the truth agrees. 9 are attributes scip-python defines elsewhere: `self.model = ...` in a subclass whose base sets it (the reference resolves to the inherited `HTTPBase#model.`), a class nested in a function (its symbols are locals to scip-python).
- **Root cause:** D5 (langbench) builds a mapped definition's span from fathom's whole lines (`[line, 0, end, 1<<30]`); containment then depends on the outer range's end column whenever both end on the same line. O454 recorded the class-body case; mapping attributes makes it common in `__init__` methods.
- **Fix (integrator, internal/langbench, outside this item's files):** in innermostDef, compare a D5 (line-span) definition with its candidates by lines alone (an inner line span whose lines lie within the outer's is inside it), or give D5's end column as the outer line's length. Not applied here: the extractor's attribution is the one the truth gives on every line but the last, and is never bent to the quirk.
- **Status:** open (harness)
- **Impact:** Python call_precision reads about .002 low; Rust's LB-F82 lost pairs the same way. L2 stays excellent.
