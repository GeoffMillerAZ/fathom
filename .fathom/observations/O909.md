### O909 — C++ shares M3's shape: spdlog's Catch2 tests and json's doctest tests are namespace-scope statics that scip-clang names alike; anonymous-namespace members are already per file

- **Symptom:** O863 recorded that ruling 3 draws about 3,029 C++ pairs to a later definer on fmt, json and spdlog. The brief asked whether M3's case covers them. cpp's rule was not changed this wave.
- **Evidence:**
  - **Tool:** an uncommitted scratch switch, built in a scratch worktree at 9b2e7439 and deleted afterwards. ClangLinkage was set for cpp, and a namespace-scope symbol (`ns/name.`, `ns/name(hash).`, no type descriptor) counted as file scope. clang-ast-defs also walked namespaces, reporting `static` at namespace scope and every member of an unnamed namespace. Both variants were measured on the same rebuilt indexes and oracle files, cpp.json's subjects with its `-only` globs plus the yaml-cpp holdout. clang-calls and ctags were not run, because only L3 is compared.
  - **Actual (committed harness, then the switch; truth pairs, file_edge_recall, file_edge_precision):**

    | subject | every_definer | left out by the switch | truth | recall | precision |
    |---|---|---|---|---|---|
    | fmt 12.2.0 | 47 -> 47 | 0 | 253 -> 253 | .5929 -> .5929 | 1 -> 1 |
    | nlohmann/json v3.12.0 | 2,505 -> 6 | 2,570 | 219 -> 219 | .9224 -> .9224 | .9951 -> .9951 |
    | spdlog v1.17.0 | 489 -> 21 | 496 | 942 -> 446 | .4299 -> .9081 | .8333 -> .8333 |
    | yaml-cpp 0.9.0 (holdout) | 7 -> 7 | 0 | 492 -> 492 | .6016 -> .6016 | .9933 -> .9933 |

    Pooled over cpp.json's three subjects, the truth falls from 1,414 to 918 pairs and file_edge_recall rises from .5354 to .8246 (757 agreeing pairs). Precision does not move.
  - **What the pairs are:** they are macro-written namespace-scope `static` functions and objects. Catch2's `CATCH2_INTERNAL_TEST_N` is defined in up to 23 of spdlog's test files, and doctest's `DOCTEST_ANON_FUNC_N` and `DOCTEST_ANON_VAR_N` in up to 50 of json's. json's tests lie outside its measured scope (`-only include/**`), so its 2,570 pairs never reach the truth.
  - **Anonymous namespaces:** none of the four indexes defines an anonymous-namespace member in two documents. scip-clang 0.4.0 names each one `` `$anonymous_namespace_<file>`/ ``, a symbol per file, so ruling 3 never drew them.
- **Root cause:** O863's, in C++: a namespace-scope `static` has internal linkage ([basic.link]/3.1). scip-clang names every unit's copy alike when the macro writes the same name (the `__COUNTER__` value repeats per file).
- **Fix:** none this wave. C++'s internal linkage also covers namespace-scope `const` objects ([basic.link]/3.2), which the switch did not read. The rule needs its own owner ruling and a C++ holdout whose tests write such statics: yaml-cpp's gtest tests do not.
- **Status:** open (owner ruling).
- **Impact:** under such a rule, cpp.json's file_edge_recall would move from .5354 to .8246 (spdlog .4299 to .9081). cpp's L3 is held to good by precision (W3) and its L4 by def_mapping, so the grade would not move on recall alone.
