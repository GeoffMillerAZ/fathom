### O367 — C L4 is classified: the index's definitions and references that fathom has no symbol for, by descriptor class

- **Symptom:** C L4 (typed_recall .1512, def_mapping .332) is classified: the index's definitions and references that fathom has no symbol for, by descriptor class
- **Evidence:**
  - **Tool:** a scratch Go test over the scip-clang 0.4.0 indexes of libuv v1.53.0 and curl 8.22.0 (descriptor classes read from the symbol string, an enumerator told from a global variable by the character before its name; fathom's definitions from the c dialect, mapped as the harness does, same file and name within 2 lines), wave cx item cinc
  - **Expected:** the miss is named, so L4's gap is a list of extractor follow-ups, not one number
  - **Actual (definitions, scip_defs: libuv 9,251, mapped 3,260; curl 11,713, mapped 3,718; the harness's own counts are 3,254 and 3,707, the scratch classifier's mapping is a few definitions more generous):** function 4,183 / 3,283, mapped 3,065 / 3,225 (libuv's 1,118 unmapped include 603 macro-generated TEST_IMPL definitions; curl's 56); type 460 / 753, mapped 195 / 493 (195 and 116 sit in files outside the measured set, mostly headers the router sent to C++, O365); global variable 1,942 / 426, none mapped (no extractor emits variables); field of a struct 1,054 / 2,556, none mapped; enumerator 324 / 1,858, none mapped; macro 793 / 2,140, none mapped (the macros scip-clang names by location are not matched to fathom's macro symbols); file symbol 495 / 697, none mapped (a file is no definition). Files outside the measured set hold 1,010 / 1,306 of them (headers routed to C++, tests, examples)
  - **Actual (references by target class, libuv / curl):** function 103,582 / 80,812, target mapped 38,403 / 27,384 (37% / 34%); type 32,012 / 25,370, 2,401 / 15,910 mapped; macro 22,018 / 21,083, none mapped; enumerator 10,108 / 350,679, none; field 11,320 / 15,227, none; global variable 6,506 / 14,004, none; local or parameter 65,379 / 67,358, none (a local is no fathom symbol by design)
  - **Repro:** the scratch test is kept in the wave's scratch (cmd/indexbench zz_l4_test.go in w-cx-cinc/out/zz-scratch); the index and subject commands are in calibration/oracles/scip-clang/README.md
- **Root cause:** L4 counts every definition and reference of the index; the dialect extracts functions, types and macros only
- **Fix:** none here; L4 at .85/.95 needs symbols for a struct's fields, enumerators, global variables and macros matched by the harness to the index's location-named macros (item calls' stretch, or a follow-up row), and a lexical match for the macro-generated definitions
- **Status:** open
- **Impact:** typed_recall and def_mapping cannot reach their bars while fields (3,610), enumerators (2,182), global variables (2,368) and macros (2,933) have no symbol; functions alone are 98% mapped on curl and 73% on libuv
