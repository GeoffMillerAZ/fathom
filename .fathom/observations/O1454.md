### O1454 — localize scores every file that mentions a concern term equally, so documents that repeat the vocabulary outrank the source that implements it

- **Symptom:** `localize {concern: …}` ranks design documents, catalogs, history, retained artifacts and fixture data above the source file that implements the concern. Sometimes it leaves the source out of the candidate list. Generic terms use up the budget before explicit identifiers and paths in the concern are tried. Adopters filed 10 reports between 2026-09-24 and 2026-10-01 (theme T12 in docs/bench/readings/feedback/adopter-triage-2026-10-20.md).
- **Evidence:**
  - **Reports:** adopter repository A O2, O4, O7, O9 (an unrelated CLI error or migration data ranked above the defining source; explicit constructor and route names were ignored "after generic terms used the budget"). app-kit O47, O50, O52, O53, O55, O57 (docs, catalog, history and retained hashes ranked above the implementation; concrete paths and methods named in the concern were ignored).
  - **Code:** for each concern term or literal, `runLocalize` (internal/mcp/localize_tool.go, the `localizeSeedLiteral, localizeSeedTerm` case) greps the whole tree with `searchRun`. It gives every file with a hit the same `upsert` score (3.0 for a term, 5.0 for a literal), sorted by path. It weighs neither the file's class (source against docs, fixtures or retained artifacts, which search's own receipt already classifies) nor the term's rarity. A document that uses many of the concern's words therefore outscores the one source file that uses the rare word.
- **Root cause:** a flat per-term score with no file-class or rarity weight, and seeds tried in order of appearance, so generic words come before specific ones.
- **Fix:** proposed, not built. Weight a term's hit by 1/(files it hits). Weight a file by class: source above test above docs, fixtures and retained artifacts. Seed identifiers and repo paths named in the concern before free terms. Measure the change on the existing localize fixtures (SU-14's two-hop case) before any default changes. localize is not on the default eight-tool surface (O615), so this reaches extended-surface callers only.
- **Status:** open
- **Impact:** the tool meant to find "which file" ranks prose above code. Callers who tried it went back to grep.
