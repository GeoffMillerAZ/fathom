### O1257 — every daemon restart and one-shot `fathom ingest` read every file: the stat gate's file_stats seam was never wired

- **Symptom:** a second one-shot `fathom ingest` of this repository with nothing changed read all 5,960 discovered files (hash-gated, 0 extracted); a restarted daemon did the same on its first ingest of each service.
- **Evidence:** wave stat1's stat worker, 2026-10-19. `WithStatSource` and `WithStatSink` (internal/fusion/stream.go) had no product caller; pass 1 vouched only from the pipeline's in-memory `statMemo`, which dies with the process. RT-76 already wrote `file_stats` at the final commit, but its rows could not vouch: no epoch (O9), no sniff verdict, and mtime/inode from an lstat taken after the read, so a write between read and commit would have been vouched with the old hash.
- **Root cause:** RT-102 shipped the seam and left the storage side for RT-180.
- **Fix:** `Pipeline.WithStoreStats` installs a `WithStatSource` that reads the service's `file_stats`; serve-http and the CLI ingest call it. The final commit is the only write: a vouching row carries pass 1's stat (taken before the read) and its hash tagged `<epoch>:<flags>:<hash>` (`statRowHash`), since the table freeze allows no epoch or sniff column. A bare hash (racily clean file, pre-change row) or another epoch never vouches; the stored-fingerprint check still guards every skip. `TestStatGateReadsFileStatsAcrossRestart` (internal/fusion) and `TestCLIIngestReadsOnlyStatChangedFilesAcrossRuns` (cmd/fathom).
- **Measurement:** scratch store, this repository at origin/main (5,962 discovered), second and later no-op `fathom ingest`, warm page cache. Before: 5,960 files read, extract pass 0.205–1.103 s, wall 1.40–2.93 s (4 runs). After: 0 read (`stat-skipped: 5960`), extract pass 0.051 s, wall 1.31–1.58 s (4 runs). Wall time is now process start, discovery, the doc-index pass (0.26–0.45 s) and the commit; a cold page cache would widen the gap, unmeasured here.
- **Status:** resolved (wave stat1, stat; RT-180).
- **Impact:** every restart cost one full read of every indexed service; a repeat CLI ingest cost one full read of the repository.
