### O708 — a test reached the real claude binary: TestCmdSmoke_All_JSON ran the operator's installed CLI

- **Symptom:** a cmd/fathom test that drove the doctor's claude probe resolved `claude` on the operator's PATH and executed it (the test binary's TestMain stubbed only `claudeLoadEnv.version`, not the PATH lookup the compile path and other probes use)
- **Evidence:** `probeClaudeVersion` and `claudecli.New`/`codexcli.New` with an empty Bin fall back to `exec.LookPath`; `FATHOM_CLAUDE_BIN`/`FATHOM_CODEX_BIN` inherited from the operator's shell pointed past any stub; internal/semantic imports claudecli and had no TestMain at all
- **Root cause:** isolation covered HOME, state and the daemon URL (ADR-047) but not the executables a test can start; each test stubbed its own seam
- **Fix:** `testisolate.IsolateAndRun` prepends a stub dir to PATH with a refusing stub per model CLI (exit 97, logged to `FATHOM_TEST_STUB_LOG`) and unsets the two bin overrides; internal/semantic runs under it; a registry test requires it of every package touching a model CLI (TQ-22, TQ-23)
- **Status:** fixed (wave h1)
- **Impact:** a test run could spend model budget or hang on a real CLI
