### O1378 — find_symbol exact tier returns every same-name definition, prompt hook kept only the first

- **Symptom:** `fetchSymbolFile` resolved a name to `Symbols[0].FilePath` and dropped the count, line and kind, so a name defined twice resolved silently to one file.
- **Fix:** `fetchSymbolDef` carries file, line, kind and count; the definitions line reads `N definitions` for a count over one. File resolution for obligations is unchanged.
- **Status:** fixed for the definitions line (wave ro3, RO-46); obligations still serves the first file only.
- **Impact:** the definitions line never names one of several definitions as the answer.
