### O532 — the scip-dart file-edge truth drew an edge for every reuse of a `local N` number: 577 of 1,194 Dart truth edges were not references

- **Symptom:** Dart file_edge_recall read .3534 (422 of 1,194) while the dialect drew every reference the corpus had; a classifier over the 772 missing edges found no occurrence behind 577 of them
- **Evidence:**
  - **Tool:** a scratch classifier over the eight scip-dart indexes (w-lx-dart, not committed) and `lang-oracle -unmatched` (wave lh-pkc's file-edge writer, scratch only), bloc-v9.2.1 and http-v1.5.0, fathom f5864ac1
  - **Expected:** a file edge needs a reference in one document to a symbol defined in another
  - **Actual:** scip-dart numbers `local N` symbols per document from 0 (SCIP scopes a local symbol to its own document); `internal/langbench/scip.go` kept one `definedIn` map across documents, so any document's reference to its own `local 3` was an edge to the first document that defined a private member as `local 3`
  - **Repro:** TestScoreSCIPDartLocalSymbolsAreDocumentScoped
- **Root cause:** the harness read a document-scoped symbol as a global one; the product import (internal/scip) already keys locals by document (scopedSymbolKey), the oracle truth did not
- **Fix:** `documentScopedLocal` in internal/langbench/scip_dart.go, one condition at the FileEdges site in scip.go (LB-F245). The same shape is open for rust-analyzer, whose `local N` symbols the harness also reads through `PrivateMembers`: item rust should check `file_edges_truth` for collisions the same way (the `definedIn` map is only fed local symbols when a producer's private members are read from source)
- **Status:** fixed (LB-F245); Rust unchecked
- **Impact:** Dart's file_edge_truth is 617, not 1,194; recall .3534 became .684 with no extractor change, and a reading of any producer that numbers locals per document and has `PrivateMembers` set would carry the same false edges
