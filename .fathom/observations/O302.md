### O302 — tests select picks a package under a separate nested module

- **Symptom:** tests select picks a package under a separate nested module
- **Evidence:**
  - **Tool:** fathom tests select (cmd/fathom/tests_select.go runTestsSelect)
  - **Expected:** only packages the repo-root module can run
  - **Actual:** it named ./calibration/oracles/lefthook-dump, a separate module with its own go.mod that cannot run from the root (about 10 such modules under calibration/oracles/*)
  - **Repro:** a diff touching a file under a directory holding a nested go.mod: TestTestsSelectSkipsNestedModules
- **Root cause:** the selection kept every package a reached test lives in without asking which module owns its directory
- **Fix:** EW-38: `inRootModule` drops nodes under a nested go.mod right after `ListAllSymbols`
- **Status:** fixed — EW-38 (79baf35a)
- **Impact:** a printed `go test` invocation that cannot run from the repository root
