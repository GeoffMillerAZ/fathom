### O731 — React's components, props and same-file JSX edges were not symbols or edges

- **Symptom:** `find_symbol Button` in a React app found a JSFunc (or nothing, for a forwardRef, memo or styled binding), no prop was a symbol, and a component rendered in its own file had no caller
- **Evidence:** step 0 of wave c3 item react, `indexbench lang-react -baseline-kinds` at f88d354d's dialects against react-docgen-typescript with the TypeScript checker (opentelemetry-demo 3.1.0 `src/frontend`, bulletproof-react 9506629e `apps/react-vite`, three next.js v16.3.6 examples; 468 components and props): sym_recall .297 (139 found as a function or class), sym_precision .5092, call_recall .0773 (hook calls only; a JSX element was no call), file_edge_recall .6855 (an imported component's JSX reference only)
- **Root cause:** the TS/JS dialects had no React kinds; a binding to a call (forwardRef, memo, styled) is no definition by their scope rule; references keep only import-bound names, so a same-file JSX use drew nothing
- **Fix:** LB-F377 (React kinds and JSX calls in both dialects), LB-F379 (`indexbench lang-react`): sym_recall .9658, sym_precision 1, call_recall .9828, call_precision 1, file_edge_recall .9505, file_edge_precision 1 at ff65b7f7
- **Status:** closed (wave c3, item react)
- **Impact:** every React codebase an agent navigates: who renders a component, a component's props, the hooks it calls
