### O1069 — MCP verify_plan with plan_path answered total:0 and no error for any path

- **Symptom:** verify_plan with `plan_path` and no `plan_markdown` returned `summary.total: 0` and no error for a relative, an absolute and a nonexistent path alike; plan_markdown worked.
- **Evidence:**
  - **Tool:** MCP verify_plan
  - **Expected:** the named plan verified, or an error naming the accepted form
  - **Actual:** an empty plan reported as an answer
  - **Repro:** internal/mcp/verify_plan_path_test.go
- **Root cause:** plan_path was read only as the self-skip comparison's file name; with no markdown the handler fell through to the structured-tasks branch with no tasks.
- **Fix:** plan_path names a file under the service's indexed root and is read when no plan_markdown or tasks come with it; an absolute, escaping, symlinked-out or missing path, or a service with no recorded root, is an error naming the accepted form; a plan read this way has its lexical oracles read from that tree.
- **Status:** fixed (wave fic, item verify)
