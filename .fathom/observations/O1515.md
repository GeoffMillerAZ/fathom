### O1515 — The Stop-hook claim check said the final message claimed passing tests while the last test run failed, but the last run of those tests passed.

- **Symptom:** The Stop-hook claim check said the final message claimed passing tests while the last test run failed, but the last run of those tests passed.
- **Evidence:**
  - **Tool:** claude-code test-run and Stop claim-check hooks
  - **Expected:** After two setup-failed go test invocations at 543e182, a third run of the same tests (go test -run 'TestReleaseMatchesNewestChangelogHeading|TestVersionMatchesNewestReleasedChangelogBlock' ./cmd/fathom ./internal/buildinfo) printed ok for both packages, so the claim check reads that pass as the latest run.
  - **Actual:** The PostToolUse test-run hook recorded only the two failed runs (no Go files in '.', and bare package paths resolved as std, both setup failed with no test run) and recorded nothing for the passing run, so the Stop hook reported the claim as contradicted at 543e182. A setup failure, where no test ran, also counts as a failed run of the claimed tests.
  - **Repro:** At one HEAD: go test -run X . (no Go files); go test -run X cmd/fathom (setup failed); go test -run X ./cmd/fathom (ok); end the turn saying the tests pass.
