### O804 — Kotlin's 1,646 false-positive file edges, classed: 1,593 same-package, 53 one library import, none of the other suspected classes

- **Symptom:** Kotlin L3 reads file_edge_precision .7993 (6,555 of 8,201 fathom edges, bar .90) against the kotlin-psi import dump (tier B) on square/okhttp parent-5.4.0 and JetBrains/Exposed 1.3.0; wave lf4 item fileedge measured which classes the fathom-only edges fall in before any fix.
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect kotlin -subject <clone> -tool-oracle out/kotlin-<subject>.json -unmatched <file>` at fathom fb7d9f3f, then each `file_edges.fathom_only` pair joined to both files' `package` line and the referring file's `import` lines (alias, star), and the target symbol `fathom_only_via` names.
  - **Actual:**

    | class | Exposed | okhttp | all |
    |---|---|---|---|
    | same-package pair (both files declare one package) | 629 | 964 | 1,593 |
    | a library import binding a same-named subject directory's import symbol (O520: `import okio.Sink` to okhttp-testing-support's `okhttp3/okio/LoggingFilesystem.kt`) | 0 | 53 | 53 |
    | same-name type across packages | 0 | 0 | 0 |

  - **Repro:** the commands in calibration/oracles/kotlin-psi/README.md, `-unmatched` on each subject, and a join of each pair's `package`/`import` lines.
- **Root cause:** the 53 are the namespace-dir member-import fallback taking an import symbol (`okio.Sink`, declared by the target file for its own import) as a member of the directory `okio`: fixed in memberImport (LB-F431). The 1,593 are real references the import-statement truth cannot hold: Kotlin reaches every non-private top-level name of a file's own package with no import (O519).
- **Fix:** LB-F431 (an import symbol is never a member import's binding) and LB-F432 (O521's `Class.Companion.member`) in the resolver; the truth side is LB-F433 (a same-package-aware truth, K19), read once on a holdout.
- **Status:** closed (classified; the product classes fixed by LB-F431 and LB-F432, the truth class by LB-F433)
- **Impact:** with LB-F431 and LB-F432 alone, precision reads .8067 and import_resolution .9999: every fathom-only edge left is a same-package pair, so no resolver change can reach .90 on the import-statement truth.
