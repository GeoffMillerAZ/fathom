### O1113 — a repository's `.fathom/config.toml` can open a decision provider that spends the user's ambient API key, and nothing kills the port

- **Symptom:** a cloned repository whose committed `.fathom/config.toml` sets `[decide] provider` (with `transport` and its opt-in `sites`) opens a remote decision provider in every session there, paid with whatever key the user's environment already exports; the user never opted in, and no user-owned switch closes the port.
- **Evidence:**
  - **Tool:** `internal/config`'s layered load and `decide.Open`
  - **Expected:** a provider that spends money or sends features off the machine opens only on the user's own consent, and one user-owned kill closes it whatever any repository says (ADR-073, I66).
  - **Actual:** `decide.provider` and `decide.transport` are `ScopeBehaviour` (`internal/config/scope.go:80`, `:86`; the class means "either layer may set it; the project layer wins", `:27`), and `decide.sites` admits an opt-in site only from the repository (`:85`, JF-4). The key fields are user-only (`:72-74`), but with none set, `KeySource` falls back to the transport's well-known variable (`internal/config/decidekey.go:64-75`, `:105`: `OPENROUTER_API_KEY`, `OPENAI_API_KEY`, else `TYPESAFE_API_KEY`), which developers export for other tools. `decide.Open` switches on `cfg.Provider` with no check of which layer set it (`internal/decide/decide.go:192-208`). No kill exists: no `FATHOM_DECIDE`, no kill file and no `[decide] enabled` anywhere under `internal/` or `cmd/`.
  - **Repro:** read from the code, not run against a paid endpoint (the spend hold): a repository `.fathom/config.toml` with `[decide] provider = "typesafe"`, `transport = "openrouter"` and an opt-in site; `OPENROUTER_API_KEY` exported; no `[decide]` block in `~/.fathom/config.toml`. The composed config carries the project layer's provider and the default key source, and `decide.Open` builds the remote adapter.
- **Root cause:** the provider was classed as a behaviour choice like a threshold, so the repository layer may set it, while the key source defaults to an ambient variable; the two together turn a committed file into consent to spend. The port has no kill because provider `none` was its only off state, and a repository can override that.
- **Fix:** `docs/plans/decision-port.md` KS-1 to KS-7 (ADR-073, I66): `FATHOM_DECIDE=off` and `~/.fathom/decide.off` close the port first (KS-1, KS-2); `[decide] enabled`, `allow_repo_provider` (default false), `session_sites` and `deny_sites` join the schema (KS-3); a provider only the repository named never opens and the well-known key variable is read only when the user layer named the provider (KS-4); session sites and deny (KS-5); one precedence with `kill_source` and `consent_layer` recorded (KS-6); doctor names the closing source and calls nothing (KS-7). They ride readouts wave ro1 first.
- **Status:** open (fix rows KS-1 to KS-7)
