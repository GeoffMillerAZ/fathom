### O674 — what a Go member pass must change besides goextract (learned building K17, wave lf2)

- **Symptom:** naming a struct's fields and an interface's own methods as symbols moved readers that took every `GoMethod` for a concrete method and every symbol for a call target
- **Evidence:** the tests that failed first on the (reverted) member pass, branch lf2-go 5b49d977: `TestGoMembersAreNeverSyntaxTargets` (the syntax pass bound `c.Timeout` to the field and made `r.Run` ambiguous wherever a field or interface method shares a method's name); `TestFindSymbol_Interface_MembersAreNotImplementers` and its symbolnav and certify twins (another interface listed as an implementation); `TestIndexOracleGoldens` (l0 blast_radius precision 1.0 to .6364: interface methods counted as functions); `TestPayloadReplay` (fauxtown ledger outline and blast_radius 7 to 13 symbols, repo_map 564 to 909 bytes, pack_context 1 to 3 items); `blast_radius` kind rename reads the syntax graph, where a field has no caller; fixture counts (fauxtown payment 7 to 14 symbols) and the console palette's ranking
- **Root cause:** before K17 no Go member was a node, so none of these readers had to tell one apart
- **Fix:** none on main (the pass is reverted, O673); the branch commit carries each fix: callgraph leaves members out of its suffix indexes and constructor-scoped lookup, and a field reference out of every callees view; the method-set implementation readers skip an interface; the L0 oracle counts an interface method Unadjudicated; rename reads the served graph for a field; `TypedEdgeEpoch` 5; field references join Go's named-target file-edge set (L3 file_edge_recall .7034 to .8758)
- **Status:** open (a checklist for the next member pass, with O673)
- **Impact:** none until a member pass lands
