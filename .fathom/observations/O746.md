- **Root cause:** fathom defines callables and types; scip-typescript defines every named binding the checker gives a global symbol: the file module, module-level variables, members and every object literal's property. typed_recall's gap is the module symbol's absence (a reference no fathom definition encloses has no From) and, after it, variables and members; def_mapping's is the same three plus 12,437 + 4,209 object-literal properties, 44% of TypeScript's denominator and 26% of webpack's.
- **Fix:** the cheapest first (wave lf3, item tsjs): the module symbol (K18, the manifest switch), then module-level variables and members, each through the cost gate; object-literal properties are a definition per property of every object literal in every expression, which no cost gate admits (O747).
- **Status:** open (the table drives LB-F381..LB-F386)
- **Impact:** L4 excellent for TypeScript and JavaScript is reachable on typed_recall; def_mapping .85 is not without object-literal properties.
