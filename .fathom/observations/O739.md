### O739 — a back-quoted phrase in a flag's usage becomes its type name in help

- **Symptom:** `fathom serve-http --help` printed `-managed fathom daemon stop|pause` for the bool flag --managed: flag.UnquoteUsage takes the first back-quoted span of a usage string as the type token, bool or not
- **Evidence:** `servehttp_config.go` --managed usage held `fathom daemon stop|pause` in back quotes; TestHelpShapesAgree (the `^  -\S+( \S+)?$` flag-line shape) failed on it once static help went through PrintDefaults. The wave h2 critic widened the test from five sampled verbs to every verb and subcommand and found 15 more, all on delegated help: `fathom verify --help` printed `-row verify --row ID --json`, and ingest --respect-gitignore, init, doctor and harness hooks --harness, harness matrix --url, tests coverage and select --profile, tests ingest --manifest, config propose --patch, refactor status --conserve-since, fleet remedy --dir, and module compile, eval and doctor printed the same kind of type token
- **Root cause:** usage prose used back quotes as code formatting; PrintDefaults reads them as a type name
- **Fix:** the span is single-quoted in each handler and in serve-http's static list (the pin keeps them equal); a deliberate back-quoted type name stays (tests --profile prints `-profile [layer=]path`); TestHelpShapesAgree holds the shape for every verb and subcommand, delegated and static
- **Status:** fixed
- **Impact:** every verb's help; a future usage whose first back-quoted span is more than one word fails the shape test
