### O739 — a back-quoted phrase in a flag's usage becomes its type name in help

- **Symptom:** `fathom serve-http --help` printed `-managed fathom daemon stop|pause` for the bool flag --managed: flag.UnquoteUsage takes the first back-quoted span of a usage string as the type token, bool or not
- **Evidence:** `servehttp_config.go` --managed usage held `fathom daemon stop|pause` in back quotes; TestHelpShapesAgree (the `^  -\S+( \S+)?$` flag-line shape) failed on it once static help went through PrintDefaults
- **Root cause:** usage prose used back quotes as code formatting; PrintDefaults reads them as a type name
- **Fix:** the span is single-quoted in the handler and in its static list (the pin keeps them equal); TestHelpShapesAgree holds the shape for delegated and static help
- **Status:** fixed
- **Impact:** every verb's help; a future usage with back quotes prints a surprising type token and fails the shape test
