### O1149 — `fathom obligations` lists rules the `obligations` tool withholds: the verb never applies IV-7 or the stale-section withhold

- **Symptom:** for a file whose governing rules cite a source file that no longer exists (IV-7) or a section the compiling layer reports stale (O1105, O1122), the MCP `obligations` tool withholds each rule and counts it in `layer_coverage.stale_withheld`, while `fathom obligations` (and `/explain`, which draws the same value) lists every one as served. The verb documents its default output as the list an agent is served; on such a file it is not.
- **Evidence:**
  - **Tool:** CLI `fathom obligations` (`cmdObligations` → `servingExplanation`, `cmd/fathom/console_explain.go`) beside MCP `obligations` (`renderObligationReceipt`, `internal/mcp/semantic_tools.go`)
  - **Expected:** the verb withholds and counts exactly what the tool withholds, through the one predicate (`staleRuleTest`), so OC-32's "the default output is the served list" holds.
  - **Actual:** `servingExplanation` folds `semantic.ExplainObligations`' served rules straight into `AgentSees`; it reads the obligations coverage for disclosure only and never judges a rule. The console fixture's rules cite a `CLAUDE.md` its faux corpus lacks, so the tool serves none of them and the verb serves them all.
  - **Repro:** integ commit 74703506 loosened `TestObligationsVerb_DefaultIsWhatServingServes` (`cmd/fathom/console_knowledge_test.go`) to accept the tool's `stale_withheld` count in place of list equality.
- **Root cause:** IV-7 and O1122 added the withhold inside the MCP receipt renderer; the verb's builder re-applies the tool's enrichments by hand, so a new serve-time rule reached one surface only.
- **Fix (proposed shape):** test first: the parity test back to strict list equality over a corpus that holds the rules' source file, plus a case where the source is gone and both sides withhold and count it. Then export the withhold from `internal/mcp` as one function the receipt and `servingExplanation` both call.
- **Status:** open
