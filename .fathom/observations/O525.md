### O525 — S1 (LB-F239) at 7cc6c2ce11b58ae2a7c9f1d029795b1152982888 (branch lx-python-s1 in the wave-lx python item's clone): a reference to a parameter or type parameter is a parameter-target, out of typed_recall, never an edge

- **Symptom:** typed_recall counted every reference to a parameter as a typed edge fathom failed to keep: Python read .4775 (14,417 of 30,193), 13,099 of the 15,776 misses a read of a parameter (`self` above all). def_mapping already leaves parameters out (`langbench.scipBareName`), LB-F55 made the same cut for locals, O115 calls a parameter finer than fathom's granularity.
- **Evidence:**
  - **Tool:** a scratch decode of each producer's index (`w-lx-python/tools/scipdump`, never committed): scip-python 0.6.6 over fastapi 864b569 + flask 22d9247 (run.sh, LB-F207's environment), scip-dart 1.7.0 over bloc 9.2.1 (the dart item's index), rust-analyzer 0.0.0 (03fcb77246 2026-09-27) over a 3-line probe crate.
  - **Shapes:** scip-python writes a parameter as a `(name)` descriptor with no enclosing_range (0 of 6,588: fastapi 4,693, flask 1,895) and no SymbolInformation kind (every kind Unspecified). rust-analyzer writes every parameter as `local N` with kind Parameter, SelfParameter or TypeParameter, each with an enclosing_range (a type parameter's covers its bounds, `T: Clone`). scip-dart writes 326 of bloc's 374 Parameter symbols as `local N` and its named parameters as `(name)` descriptors whose enclosing_range covers the type annotation or field formal (64 of 5,565 references sit inside one).
  - **Found on the way:** a `local N` parameter sits on its function's own line, so the position join mapped it to that function and every read of it minted a fn -> fn edge (the O115 self-loop, in the shape descriptorIsParameterLike could not see). The guard now refuses it too (isParameterDefinition). The Rust and Dart readings' Direct counts lose those self-loops.
  - **Actual (Python, scratch re-measure, same environment as the reading):** typed_recall .4775 -> .8434 (scip_edges 30,193 -> 17,094; scip_edges_param_target 13,099; scip_edges_typed 14,417 unchanged); L1-L3 unchanged.
- **Root cause:** internal/scip.fromIndex counted a reference to an unmapped parameter under "unmapped-endpoint" (typed_recall's denominator), and refused only the descriptor shape from the position join.
- **Fix:** S1 (LB-F239), commit 7cc6c2ce, alone: `Skipped["parameter-target"]` ahead of "local-target" for a target the index defines as a parameter (descriptor, or a local of kind Parameter/SelfParameter/TypeParameter); such a definition is never position-joined; a reference inside an unmapped parameter's enclosing_range climbs to the declaring function as LB-F55's locals do (source side: the data shows it for scip-dart and rust-analyzer, never for scip-python). langbench discloses `scip_edges_param_target` (only when non-zero). Design amendment: docs/design/language-breadth.md §1.2 typed_recall row and §1.4 (typed edges: parameter targets).
