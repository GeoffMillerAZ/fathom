### O404 — a TCC wedge during the gate reads as product failures: stranger-check's typed_edges FAIL, and a shared GOCACHE poisoned so `go list` says the main module has no internal/dlog

- **Symptom:** `task validate` failed repeatedly on stranger-check with a typed_edges doctor FAIL ("go/packages returned 0 packages", "JSON decoding failed: unexpected EOF"), and later every scratch ingest reported "12/408 package(s) failed typed loading ... could not import .../internal/dlog (invalid package name: \"\")"
- **Evidence:**
  - **Tool:** `task validate`, `fathom ingest --store <scratch> --path .`, `go list -e -f '{{.Name}} {{.Error}}' ./internal/dlog` on wave iac's clone, 2026-10-02
  - **Expected:** an EPERM from the filesystem surfaces as an EPERM and is gone once reads work again
  - **Actual:** with the GOCACHE every wave on the machine shared `go list ./internal/dlog` answers "main module (github.com/geoffmilleraz/fathom) does not contain package" every time while the directory reads fine; the same command with a fresh GOCACHE answers `dlog <nil>`
  - **Repro:** compare the two `go list` calls above with GOCACHE set to the shared cache and to an empty directory
- **Root cause:** environmental (macOS TCC verdict on the external volume); a denied directory read during a go command appears to have left a cached "no package" answer in the shared build cache, and the doctor row cannot tell a cut-short go list from a broken module
- **Fix:** none in code; re-run after `tccutil reset SystemPolicyRemovableVolumes com.mitchellh.ghostty`, and run the typed pass on a private GOCACHE (or clean the shared one) once it is poisoned
- **Status:** open
- **Impact:** a wedged gate looks like a typed-pass regression, and a poisoned cache keeps failing after the wedge clears, for every wave sharing it
