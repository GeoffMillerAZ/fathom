### O435 — the route resolver's repository fallback joins every same-named service of the repository, not the nearest project's

- **Symptom:** a route in one sandbox's config joins the same-named compose service of every other sandbox: envoyproxy/examples draws 5 pairs the oracle does not hold, wmde/wikibase-suite draws 8 (Traefik xref_precision .7241, L3 unmet)
- **Evidence:**
  - **Tool:** `indexbench lang-routes` (LB-F98) over the proxy oracles' `-routes-out`, wave ox, fathom 44205772 plus the LB-F168 `-only` fix; oracles at tier A (envoy, calibration/oracles/envoy/README.md "The route rule") and tier C (traefik, a Kubernetes Service in the union)
  - **Expected:** `dynamic-config-fs/configs/cds.yaml`'s cluster `example_proxy_cluster` (host `service1`) joins `dynamic-config-fs/docker-compose.yaml`, the compose project of the directory above it; wikibase-suite's `config/traefik-dynamic.yml` joins its root `docker-compose.yml`
  - **Actual:** the route also joins `service1` in cache/, dynamic-config-cp/, front-proxy/, jaeger-tracing/ and route-mirror/ compose files (5 extra pairs), and wikibase-suite's `wikibase`, `wdqs`, `wdqs-frontend` and `quickstatements` also join `development/tests/*/docker-compose.override.yml` (8 extra pairs of 12 drawn for 4 in the truth)
  - **Repro:** `indexbench lang-routes -dialect traefik -subject <wmde/wikibase-suite at de53feab> -tool-oracle <traefik oracle defs, refs, routes> -only config/traefik-dynamic.yml` (route_truth 4, route_fathom 12, route_truth_found 4)
- **Root cause:** `ResolveRouteRefs` keeps the nearest declarations "in the referring file, else its directory, else the repository" (internal/fusion/routeref.go); a route file in a directory with no compose file skips straight to every declaration in the repository, and one key means one join per provider node, so each unrelated sandbox's service is a provider. The oracle's rule walks ancestor directories first (a compose project is a directory) and uses the repository only for a single declaration
- **Fix:** none here (internal/fusion is wave ic's): after the directory step, try each ancestor directory before the repository. Re-measure with the traefik and envoy `-routes-out`; the traefik row's trigger names it
- **Status:** open
- **Impact:** over-linking inflates blast radius from a route to every same-named service of the repository; Traefik L3 cannot be met (xref_precision .7241, bar .90), Envoy L3 stays good (xref_precision .9398, bar for excellent .95)
