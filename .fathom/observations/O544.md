### O544 — Ruby L2 missed 1,110 of 8,463 tier-C call pairs: a bare identifier (`helper`, `params`) was never a call, because the engine ran no locals analysis

- **Symptom:** Ruby read call_recall .8688 against the grammar's own tags.scm and locals.scm (tier C) on sinatra v4.2.1 + jekyll v4.4.1. Each of the 1,110 missed pairs was an identifier with no receiver and no arguments.
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect ruby -tool-oracle <ts-tags calls> -tool-oracle <ruby-require imports> -unmatched` (wave lx, fathom f5864ac1)
  - **Expected:** a bare identifier that no local binds is a method call on self (upstream's `(#is-not? local)` pattern)
  - **Actual:** the dialect took only call nodes' method names and constants (PROVENANCE.md: a local read could not be told from a call)
  - **Repro:** the commands in calibration/oracles/ts-tags/README.md (Ruby)
- **Root cause:** tsengine evaluates text predicates only, so `(#is-not? local)` had no evaluator and the dialect left the shape out
- **Fix:** LB-F254/LB-F255. A dialect's manifest names a locals query (`queries.locals`), and the engine's locals rule (tsextract_locals.go) keeps a candidate of a pattern set `(#set! is-not "local")` only where no local binds it. Ruby's locals.scm adds the scope gates and bindings upstream's lacks. call_recall .9944, call_precision .9942. The 96 pairs left are classified in the reading: 24 rescue variables and 2 singleton-method locals are the oracle's, and the definers, `def obj.x` and `super` are the dialect's shapes.
- **Status:** fixed
- **Impact:** Ruby's call graph gains every implicit-receiver call (readers, helpers, DSL methods), +9% extraction CPU on sinatra; tier C still caps L2 at good
