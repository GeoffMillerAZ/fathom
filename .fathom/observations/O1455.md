### O1455 — Tools silently accept argument names they do not have, and localize's schema hides its "exactly one seed" rule

- **Symptom:** a caller passes a field the tool does not define (`max_callers`, `max_callees`, `name` to `references`). The tool runs as if the field were absent and says nothing, so the caller believes its bound or scope applied. Separately, `localize`'s schema lists `stack_trace`, `failing_test`, `error` and `concern` as four optional fields, yet the handler refuses any call that sets more than one. Adopters filed 9 reports between 2026-09-18 and 2026-09-27 (theme T13 in docs/bench/readings/feedback/adopter-triage-2026-10-20.md). app-kit O101 and adopter repository A O10 are counted under T01, because both calls also stalled.
- **Evidence:**
  - **Reports:** app-kit O101 (`symbol_context` with `max_callers: 3, max_callees: 6`, neither in the contract, then the call stalled), O37 (a `references` parameter mismatch "caused an accidental fleet expansion"), O41 (`repo_map` with unsupported arguments "returned unrelated symbols"), O1 (literal doc paths refused). Adopter repository A O5 and O8 (the localize schema "permits combined seeds but runtime rejects them") and A O10 ("MCP parameter name not discoverable in tool metadata").
  - **Probe, 2026-10-20, deployed binary 909ea5c2e:** `find_symbol {service: agentic-kit, name: main, bogus_arg: 3}` answered normally, with no warning.
  - **Code:** localize's schema (internal/mcp/localize_tool.go) says "Required: service." The handler refuses with `localize: exactly one of stack_trace, failing_test, error, concern is required, got %d`.
  - **Already fixed:** pack_context's sentence-as-concern case (app-kit O28, O43, O51, adopter repository A O1). Since e05e04f53 (2026-09-18) the field reads "Concern ID … a short identifier", and a sentence is refused with a message naming the form.
- **Root cause:** argument decoding ignores unknown fields, and the localize schema states its fields as independent options while the handler requires exactly one of them.
- **Fix:** proposed, not built (small). Refuse unknown argument names with `-32602` naming the accepted fields, or, if refusal is too strict for older callers, answer with an `ignored_arguments` list. State "exactly one of" in localize's description and as a `oneOf` in its schema.
- **Status:** open
- **Impact:** a silent ignore turns a caller's mistake into a wrong or unbounded answer that looks deliberate.
