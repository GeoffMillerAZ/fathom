### O773 — gate-lease_test.sh raced under load: a 1 s holder lapsed before the waiter reached the flock

- **Symptom:** `scripts/gate-lease_test.sh` failed "the waiter did not name the holder" in wave c3's gate run 1 and passed on rerun
- **Evidence:** stub A held the lease with `sleep 1`; when B's start (bash + perl) took over 1 s on a loaded machine, A had released, B took the lock at once and printed no waiting line. Reproduced deterministically by inserting `sleep 1.5` before B's launch in the old script (fails, rc 1); the same delay in the new script passes. A parallel `yes` burner did not reproduce it on its own: old script 20/20 at 1x, 6x and 8x ncpu (10 cpus), because the scheduler stays fair to a short-lived starter
- **Root cause:** the test bounded the holder by time, not by the event it asserts
- **Fix:** A's stub blocks on a fifo (`mkfifo`) after recording its start; the test releases it only when b.err holds the waiting line (polled, 600 x 0.05 s hang guard, never a latency bound). B has no hold. Every other assertion kept. Row RT-186
- **Status:** fixed. New script 20/20 under a 10-process `yes` burner (ncpu, killed by trap) and 20/20 at 80 processes
- **Impact:** the pre-push gate no longer fails on a loaded machine for a reason unrelated to the change
