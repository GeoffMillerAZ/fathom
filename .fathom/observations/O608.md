### O608 — Go's typed_recall cannot be graded on fathom's own go/types edges, and scip-go writes some parameters as `Func:name.` terms

- **Symptom:** the brief asked whether typed_recall can be graded against the native typed pass instead of the SCIP import, and whether scip-go's parameter shapes reach the S1 rule
- **Evidence:**
  - **Tool:** `indexbench lang-oracle` notes (goNativeCoverage; wave lf1) and a debug listing of unmapped definitions
  - **Expected:** the native pass draws the import's edges between mapped definitions
  - **Actual:** of cli/cli's 25,299 unique (from, to) pairs the import stores between mapped definitions the native pass draws 15,337 (.6062: 10,718 direct, 3,779 only as an instantiation fact, 624 only as a dispatch edge, 195 only as a function value); it stores no reference to a type or a variable. cobra reads .6906. scip-go writes most parameters and locals as `local N` (the local rule, LB-F55, 73,271 references) and 21 definitions, a function literal's parameters in a package initializer, as `` `pkg`/Options:c. ``, a shape neither rule reached
  - **Repro:** as O603
- **Root cause:** the native pass is a call graph; the meta-descriptor term is a scope-local definition scip-go does not write as `local N`
- **Fix:** the native coverage is disclosed beside the graded figure, which stays the SCIP import's (design §1.7, LB-F300); `GoScopedTerm` makes the meta-descriptor term a parameter (S1), 21 references out of typed_recall
- **Status:** fixed for the parameter shape; the native grade is refused (design does not allow it: .606 is not an L4 bar), trigger: the typed pass stores a type or variable reference as an edge
- **Impact:** typed_recall .5805 stays the import's
