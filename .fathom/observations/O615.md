### O615 — the prompt hook names localize as the opening move for an issue-shaped prompt, but the default eight-tool agent surface does not serve localize

- **Symptom:** the prompt hook names localize as the opening move for an issue-shaped prompt, but the default eight-tool agent surface does not serve localize
- **Evidence:**
  - **Tool:** fathom prompt-hook
  - **Expected:** a routing line names a tool the session can call
  - **Actual:** localize is served on /rpc/extended only (internal/mcp/surface.go, law 4); a session registered on /rpc/agent is told to call a tool it does not have
  - **Repro:** paste a stack trace into a session registered on /rpc/agent; the hook line reads 'this prompt is issue-shaped ...; localize is the opening move'
- **Root cause:** `routeLineFor` (cmd/fathom/prompthook.go) routes every issue-shaped prompt to localize deterministically (SR-44), and it reads no surface: it cannot know which endpoint the session registered. ADR-053 kept localize off the default eight (40 calls in about 98k), and ADR-062 keeps it there (law 4), so TL-1 widened what the hook routes (V8 and PHP frames, error payloads) without widening who can follow the route.
- **Fix:** none in TL-1 (filed by its brief, reserved id O615; `fathom observe` minted O613 and the entry was moved to the reserved id). Options for the owner: the hook line names localize only when the session's registration serves it, or names the extended surface ("localize, on /rpc/extended"); or localize earns a default slot from a measured share of incident-path calls (ADR-062's delivery reality, docs/design/telemetry-links.md section 6).
- **Status:** fixed (2026-10-19, wave cert1): `routeLineFor` reads the session's fathom registration locally (`registeredPromptSurface`, cmd/fathom/prompthook.go: the project's `.mcp.json`, then `harness.ClaudeUserConfigFile`'s local and user scopes, each under 1 MiB, skipped once the deadline is spent). `/rpc/extended`, `/rpc/companion` or `/rpc` keeps the localize line; `/rpc/agent` names `search` then `symbol_context`; unknown or unreadable names that move and adds that localize does it in one call on `/rpc/extended`. The surface is unchanged (ADR-053, ADR-062 law 4). Test: `TestPromptHookRoutesAnIssuePromptToAToolTheSurfaceServes`. The hedged POST /route line can still name an off-surface verb: O1267.
- **Impact:** the incident path (TL-1, TL-5) serves hook-routed sessions that registered /rpc/extended and extended sessions only; a default-surface session gets a dead pointer on every pasted trace or payload.
