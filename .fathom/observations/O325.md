### O325 — OC-55 verified only through a false syntax edge: the closure call index() in custodian.Propose resolved by bare name to consoleSearchCache.index

- **Symptom:** OC-55 verified only through a false syntax edge: the closure call index() in custodian.Propose resolved by bare name to consoleSearchCache.index
- **Evidence:**
  - **Tool:** fathom verify --strict (edge_wired; callgraph.BuildBoth syntax fallback)
  - **Expected:** edge_wired for OC-55 (TestConsoleSearch_PlanAndRowResultsOpenTheirPages reaches projectSearchDocs) proven by a real call path, or refused
  - **Actual:** the only path was TestConsoleSearch_PlanAndRowResultsOpenTheirPages -> newConsoleFixture -> ... -> run -> cmdConfigPropose -> custodian.Propose -> consoleSearchCache.index -> gatherSearchDocs -> projectSearchDocs; custodian.Propose calls a local closure named index, and the syntax graph bound that call to the only symbol named index. Wave tl added a second (calibration/oracles/gradle/main.go type index), the bare name became ambiguous, the edge vanished and OC-55 failed under verify --strict on the integrated tree
  - **Repro:** fresh scratch ingest of tl-integ before the OC-55 repoint, then fathom verify --strict --store <scratch> --service fathom --plan docs/plans/observatory-console.md; callgraph.CallPath from the test to projectSearchDocs on a pre-wave store shows the custodian.Propose hop
- **Root cause:** the syntax graph's bare-name fallback binds a call to whichever symbol alone carries that name, a local closure call included; the static path from an HTTP-level console test to a page's builder runs through the registry's func-value Build field, which no typed edge follows, so the row had no real path and rode the false one
- **Fix:** OC-55's reachable_from now names TestProjectSearchDocs_PlansAndRowsLinkToTheirPages, which calls projectSearchDocs directly and asserts the plan and row hrefs and the row page's parser (wave tl integration); the HTTP test still runs the same path at runtime. The resolver half (a call to a name bound locally in the caller, a closure or a func-typed variable, should not fall back to a package-level or method symbol) is not taken here
- **Status:** open
- **Impact:** any row whose edge_wired proof crosses a bare-name fallback can flip when an unrelated symbol of the same name lands anywhere in the service; OC-55 is the one seen
