### O1427 — Pack readout fixtures live in the rule's own `test` entries, not in `fixtures/*.cue`

- **Symptom:** FD-12's `RunFixtures` reads guards, generated and formats fixtures from `fixtures/*.cue`; a readout rule already carries its fixtures (`test`, with input, expect, trip), and `internal/readout` is the only package that can run them (techpack cannot import readout).
- **Fix:** `RunFixtures` gains a `readouts` section that holds each rule to carrying at least one `test` (`readouts <id>: no fixture`); `internal/readout` runs them through RO-33's `prepare`. `#Pack.readouts` is `#Readout`, `readouts.#Rule` with `test` optional, so a bare rule is withheld and named instead of invalidating the whole pack.
- **Status:** closed
- **Impact:** `fathom rules fixtures` first read fixture presence only and counted each `test` entry passed unrun, a kit's CI false green; the ro6 audit routes it through `readout.RunPackFixtures`, which runs the section through the loader and counts per rule.
