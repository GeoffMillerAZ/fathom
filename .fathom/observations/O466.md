### O466 — C#'s remaining fathom-only pairs after wave ld, classified: 5,272 of 7,498 are calls of a generic method with explicit type arguments

- **Symptom:** C# call_precision .794 against scip-dotnet (28,902 of 36,400 pairs; was .7776, 28,902 of 37,167) after the dialect names a generic callee without its type arguments and drops nameof
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect csharp -unmatched`, then a per-pair read of the source and the SCIP document (each pair counted once, in this precedence; the classes are heuristics over the written site, not oracle statements): (B) 5,272 a call written with explicit type arguments in the caller's span, scip-dotnet writes no occurrence for the method name (verified oracle deficiency, O271); (I) 754 only in a `#if` region the indexed framework does not compile; (D) 517 a bare name that is no method of the repository (a delegate-typed parameter or local, a local function) and (D2) 176 a delegate-typed property or field of the repository invoked (`_handler.ShouldHandle(args)`), SCIP recording a reference to the member, not a callable; (F) 185 O465; (E) 407 and (C) 187 not root-caused one by one: samples sit among extension methods from packages (`ShouldBe`, `Select`, `ToList`), overloads sharing a name whose enclosing span the oracle mapped to another overload, and framework members (`HashSet.Remove`)
  - **Expected:** the .90 bar (call_precision and call_recall)
  - **Actual:** with B, I, D, D2 and F counted out (6,904 pairs) the same 28,902 would read .980 of 29,496; the dialect never drops a real call to get there
  - **Repro:** `indexbench lang-oracle` per calibration/oracles/scip-dotnet/README.md, then `-unmatched`
- **Root cause:** the oracle cannot see these sites (O271, O465, delegate invocations, `#if`); not a dialect error. The 879 `unresolved per pair` of the 2026-10-01 note are the E, C and F classes here
- **Fix:** open: the oracle-blind cut (O464) or an oracle that indexes generic-method calls (the Roslyn semantic model)
- **Status:** open
- **Impact:** C# L2 stays unmet at .794 and L2's threshold needs O464 or a semantic oracle
