### O826 — `search kind:"docs"` is not available on the shared daemon, so a worker's "docs search before ADR.md" step fails

- **Symptom:** the wave contract (docs/guides/agent-waves.md, EW-10) tells a worker to ask docs search before opening ADR.md whole; on 2026-10-10 the MCP `search` call with `{"service": "fathom", "kind": "docs", "pattern": "ADR-051 coverage decision"}` answered `search: kind "docs" is not available on this backend`.
- **Evidence:**
  - **Tool:** the `search` MCP tool on the shared daemon (default eight-tool surface), wave h5 worker `joins`.
  - **Actual:** an error, not hits; the worker fell back to `grep -n '^## ADR-051' ADR.md` and a bounded `sed` range.
  - **Expected:** docs hits naming `ADR.md:<start>-<end>` and the heading path, as the guide documents.
  - **Repro:** `search {"service":"fathom","kind":"docs","pattern":"ADR-051 coverage decision","limit":6}` against the deployed daemon.
- **Root cause:** not diagnosed; the message says the backend lacks the docs kind, so either the default surface's search handler is not wired to the doc index, or the deployed binary predates it.
- **Fix:** none here.
- **Status:** open
- **Impact:** every worker brief's EW-10 step silently degrades to grep; the bounded read still works, the routing does not.
