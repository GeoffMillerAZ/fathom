### O1267 — the prompt hook's hedged POST /route line can name a tool the default surface does not serve

- **Symptom:** for a prompt that is not lexically issue-shaped, `routeLine` (cmd/fathom/prompthook.go) prints the verb the decider returns, and route's candidate set (cmd/fathom/route.go) includes `localize`, `find_callers`, `references` and `staleness_report`, none of which `/rpc/agent` serves.
- **Evidence:** route.go's verb table lists them; O615's fix covers only `routeLineFor`'s deterministic issue path (wave cert1, `registeredPromptSurface`).
- **Root cause:** the decider's candidate set is the extended surface's, and the hook line does not check the session's registration for that path.
- **Fix:** none yet. Options: map an off-surface verb to its default-surface move with `registeredPromptSurface`, or narrow route's candidates to the registered surface.
- **Status:** open
- **Impact:** a default-surface session can get a hedged pointer to a tool it cannot call.
