### O1114 — the prompt hook turned the word "ADRs" into `internal/review/adrrules.go` and injected six unrelated rules: a substring symbol match is taken as a file

- **Symptom:** the owner's prompt "make sure we have ADRs that callout ..." made the UserPromptSubmit hook name `internal/review/adrrules.go` and inject six rules that govern it (review-kit findings and evidence-plane rules), none of which the prompt was about.
- **Evidence:**
  - **Tool:** `fathom prompt-hook` (`cmd/fathom/promptcandidates.go`, `cmd/fathom/prompthook.go`)
  - **Expected:** a prose word names nothing; the hook injects rules only for a token that names a file, a package or a symbol exactly.
  - **Actual:** "ADRs" passes `looksLikeSymbol` (`cmd/fathom/promptcandidates.go:282`, `:140`) because `hasInternalCapital` (`:337`) sees a lowercase `s` and capitals after the first rune, the shape of a plural acronym as much as of `registerTool`. `fetchSymbolFile` (`cmd/fathom/prompthook.go:363`) then asks `find_symbol`, whose ladder is exact, then case-insensitive, then substring, and takes `Symbols[0]`'s file (`:399-402`) without reading `matched_via`. `find_symbol {name: "ADRs"}` on this repository returns `matched_via: "substring"` with `ADRSection` (`internal/review/adrrules.go:156`) first, so the file is added and its obligations served.
  - **Repro:** `find_symbol` with `service: fathom`, `name: ADRs` answers `"matched_via":"substring"`, first symbol `ADRSection` in `internal/review/adrrules.go`; any prompt containing the word "ADRs" injects that file's rules.
- **Root cause:** the hook treats every `find_symbol` hit as a resolution, but only the exact tier names what the prompt said; the substring tier is a suggestion. A loose lexical shape (internal capital) admits plural acronyms of four or more characters (ADRs, APIs, URLs, SDKs) as symbol candidates.
- **Fix (proposed shape):** resolve a prompt token only when it is path-like (a file or package token that `workingTreeNames` confirms) or an exact symbol: `fetchSymbolFile` returns ok=false unless `matched_via` is `exact` (a case-insensitive hit only when backticked or called), never on a substring or stem match. Second, cheaper guard: `looksLikeSymbol` rejects an all-capitals stem with a trailing lowercase `s` unless backticked. Test first: a prompt with "ADRs" and "APIs" yields no resolved file, and `` `ADRSection` `` still does.
- **Status:** fixed (wave fx4): `fetchSymbolFile` takes a hit only when `matched_via` is `exact`, or `case_insensitive` when the candidate was backticked or called (`promptCandidate.marked`); substring and stem hits resolve nothing. `looksLikeSymbol` rejects an all-capitals stem with a trailing lowercase s (`isPluralAcronym`) unless marked. Tests: `prompthook_o1114_test.go`. No prompt-hook precision bench exists under testdata/contextbench or scenariobench, so none was run.
