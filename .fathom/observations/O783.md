### O783 — `tests select --safe` missed a test that reads a sibling package's source by literal path

- **Symptom:** an edit under internal/store did not select `internal/scope`'s `TestSuppressionCoversOptionalStoreCapabilities`, which globs `../store/*.go` and parses it with go/parser, never importing internal/store; it failed wave h3's gate run 1
- **Root cause:** `--safe` walks the call graph from changed symbols; a read of source by path is no edge. TQ-21 closed the `//go:embed` case only
- **Fix (TQ-24):** `srcReadChangedSymbols` (cmd/fathom/tests_select_srcread.go) parses the repo's `_test.go` files, constant-folds the path argument of os.ReadFile/Open/ReadDir, filepath.Glob, fs.Glob, parser.ParseFile/ParseDir, resolves it against the test's package directory and matches the diff. A helper is a seed for the impact walk; a Test function that reads is added to the selection directly (the walk skips Test-named seeds)
- **Evidence:** `docs/bench/readings/test-intelligence/srcread-selection.md` (TQ-25): 905 reads, 78 literal in 72 functions, 41 outside their package, 827 dynamic; internal/store diff selects 828 tests before, 830 after, the missed test included
- **Ceiling:** a dynamic path is ignored (disclosed on stderr); mostly TempDir reads that depend on no repository file
- **Status:** fixed (TQ-24, TQ-25)
