### O1379 — A schema package another schema imports needs a second embedded copy and a mirror test

- **Symptom:** `#Pack` (schema/techpack) had to move `#Concern`/`#Check` out of schema/project so project could import techpack without a cycle, and internal/projectdir now holds a fourth verbatim schema mirror.
- **Evidence:** `TestEmbeddedSchemasMatchSource` lists the mirrors by hand; a new schema package that is not added there drifts silently.
- **Root cause:** Go embeds only files under the package's directory, so every CUE package a Go loader needs is copied.
- **Fix:** none now; derive the mirror list from `schemas/` in the test when a fifth copy lands.
- **Status:** open
- **Impact:** none today; the mirror test covers all six copies.
