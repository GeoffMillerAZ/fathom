### O1366 — the whole-tree memory canary lives in the gate's verify ingest, peak 2208 MiB measured

- **Symptom:** since wave fix3 (O1339) nothing ingested this whole tree under the managed 4 GiB budget, so a typed-pass memory regression (wave h5 caught one there) had no gate home.
- **Evidence:**
  - **Tool:** `lefthook.yml` pre-push `verify` step, its single scratch ingest of HEAD
  - **Measured (this repository, 2026-10-19, darwin, `/usr/bin/time -l`):** peak resident set 2315976704 bytes = 2208 MiB, 351 s wall, with `FATHOM_TENANCY_BUDGET=4GiB`
- **Root cause:** the stranger check was the only whole-tree ingest under the budget, and it now wires a fixture fleet.
- **Fix:** the verify step runs its one ingest with `FATHOM_TENANCY_BUDGET=4GiB` and `/usr/bin/time` (`-l` darwin, `-v` linux) inside the gate lease, prints the peak in MiB, and exits 1 naming the measured MiB when it exceeds 4096. No extra ingest. A missing `/usr/bin/time` or unparsable reading skips the check (fail-open). A CLI ingest has no hard cap (the budget gates the typed pass; the Go GC hint is daemon-only), so the instrument reads RSS rather than relying on a refusal.
- **Status:** fixed (wave fix4, item gate)
- **Impact:** a memory regression over 4 GiB on the whole tree fails the push gate.
