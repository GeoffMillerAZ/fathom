### O1479 — A use of a functional Tailwind utility names nothing: `@apply tab-4` does not reach `@utility tab-*`

- **Symptom:** a functional utility (`@utility tab-*`) is a symbol named `tab-` (the grammar ends the name before the star), and a use of it (`@apply tab-4`) is a call of `tab-4`; the call resolves to no definition.
- **Evidence:** calibration/oracles/tailwind reports such a pair as (owner, `tab-`) when the compiler parses `tab-4` to the functional root `tab`; fathom's pair is (owner, `tab-4`), a recall miss the harness would count. It is a counter in the oracle's disclosures (`apply_pairs_functional_utility`); no calibration or holdout subject has one (0 pairs), so the readings do not measure it.
- **Root cause:** name-equality resolution has no prefix rule, and the variant only strips variants and the importance flag from a candidate (`call_names: tailwind-candidate`).
- **Fix:** none yet. A resolver that tries the hyphen-cut prefixes of a candidate against the closure's `name-` utilities would close it; that is a strategy, not a query.
- **Status:** open
- **Impact:** `@apply` of a custom functional utility draws no usage edge; static utilities, theme variables and variant-prefixed candidates do.
