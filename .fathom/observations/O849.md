### O849 — CSS reads L3 under W2 against lightningcss; the holdout's one residual is the withdrawn `@nest` rule, which the oracle does not walk

- **Symptom:** LB-Q-css stood at L1 good: no CSS oracle reported a rule's end line, §1.2's L2 (calls) had no measure for a stylesheet, and neither subject held an in-repo `@import` (LB-Q-css-rest). Design 1.8's W2 made lightningcss tier A for what a browser parser attests and graded `var()` and `animation-name` as name references within the import closure.
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect css -tool-oracle <lightningcss_oracle.cjs output>` (calibration/oracles/lightningcss, lightningcss 1.33.0), under the rule committed alone in faf54be1 (`cmd/indexbench/langoracle_css.go`), with the dialect's references and module symbol (a3853038, 29ca8af1).
  - **css.json** at faf54be1 on normalize.css v2.1.3, pico v2.1.1 (`css/`) and gitea v28.1.0 (`web_src/css`, the tuning subject with in-repo `@import`, pinned in b519b4f5 before the rule): L1 good (sym_recall 1, sym_precision 1, kind_agreement 1, 137,732 definitions; range_agreement not measured), L2 excellent (call_recall 1, call_precision 1, 45,956 pairs; 1,365 a side outside their closure), L3 excellent (import_resolution 1, 88 of 88; file edges 1 and 1, 88).
  - **Holdout** (`calibration/corpus.d/css-holdout-2.yaml`, argyleink/open-props v1.6.0, 5e21d4a1, MIT, pinned with the rule) read once at 107f6f11: L1 good (sym_recall 1, sym_precision .9754, 2,059 of 2,111), L2 excellent (.9167 and .9167, 429 of 468; 371 and 372 outside), L3 excellent (42 of 42; file edges 1 and 1).
  - **The holdout's misses:** all in `docsite/index.css` and `docsite/syntax-highlight.css`, which write `@nest <selector> & { ... }`, the rule of an early CSS Nesting draft that the published Nesting module withdrew. tree-sitter-css reads its block's rules and custom properties (41 selectors, mostly `&`, and 11 custom properties, dialect-only); lightningcss parses it as a `nesting` rule, which `lightningcss_oracle.cjs` does not walk, so the declarations inside are given to the enclosing rule (39 pairs each way).
  - **Found on the tuning subjects, before the rule:** the selector pattern was an alternation of selector node types, and the query engine emits an alternation's matches grouped by alternative, so `:where(a:not([role=button])), [role=link]` gave its references to `[role=link]`; a wildcard over `selectors`' children keeps source order (29ca8af1, testdata/references.css).
- **Root cause:** the oracle script's rule walk lists the group rules it descends into (`media`, `supports`, `container`, `layer-block`, `starting-style`, `scope`, `moz-document`) and not `nesting`.
- **Fix:** none after the holdout (K19). Walking `nesting` rules (their `style` rule) is a change to the oracle, which needs a new holdout before it is read.
- **Status:** open (the residual is recorded on LB-Q-css-rest)
- **Impact:** CSS reaches its L3 target (LB-Q-css): ingest stores each `var()` and animation name as a reference, an `@import` as an edge between the sheets' module symbols, and a name an imported sheet declares as a file-resolved edge to it. Only sheets written with the withdrawn `@nest` read differently from the oracle.
