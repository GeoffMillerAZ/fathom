### O1381 — `#Pack` rejects `orientation` with a bottom field, so its error text is CUE's

- **Symptom:** a kit pack carrying `orientation` fails validation with CUE's "field not allowed" wording, which names no reason.
- **Evidence:** `orientation?: _|_` in schema/techpack/schema.cue; `TestValidatePackAcceptsKitSectionsAndRefusesRepositoryKeys`.
- **Root cause:** a schema cannot attach a message to a refusal.
- **Fix:** when the kit-pack loader lands, wrap `ValidatePack` errors for the five repository-only keys with "a kit advises, only the repository governs".
- **Status:** open
- **Impact:** the refusal is correct and the message is terse.
