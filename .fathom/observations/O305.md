### O305 — tests select --safe selects 561 tests (cmd/fathom 250 s under -race) for a change to one verb handler, because every test that calls the CLI dispatcher run() statically reaches every verb

- **Symptom:** tests select --safe selects 561 tests (cmd/fathom 250 s under -race) for a change to one verb handler, because every test that calls the CLI dispatcher run() statically reaches every verb
- **Evidence:**
  - **Tool:** fathom tests select --safe --since origin/main --store $FATHOM_CACHE_ROOT/verify.sqlite --service fathom (wave hd, worker hd-lines, scratch ingest of 024074c1)
  - **Expected:** the tests that exercise the changed verb: TestCmdPlansLinesReportsAndNeverActs and the internal/worklines tests
  - **Actual:** 561 tests: 553 in cmd/fathom, among them TestClaimAdd_MintsHumanAuthoredClaim, which calls run([]string{"claim", ...}) and reaches cmdPlans and cmdPlansLines only through the verb switch; the diff changed cmd/fathom/plans_lines.go, a two-line doc comment in cmd/fathom/plans.go and internal/worklines. Seeding is file-granular too (impact.TestGapOn seeds every symbol defined in a changed file), so the comment edit also listed planRow, frontierRow and blockedDep as changed symbols no test reaches
  - **Repro:** change any verb handler under cmd/fathom, scratch-ingest, run tests select --safe --since <base>; count tests that call run( and reach the verb only through the dispatcher
- **Root cause:** two widenings, read in this session: `impact.TestGapOn` (internal/analysis/impact/testgap.go) seeds every symbol defined in a changed file, not the changed lines; and `run`'s verb switch is a static edge to every `cmd*` handler, so a test that enters through `run` reaches every verb. Which of the two drove most of the 561 was not measured. O162 is the interface-dispatch widening; this one needs no interface
- **Fix:** none yet; candidates: seed by changed line ranges, or name per-package counts and the dispatcher-only reaches separately so a worker can run the direct ones
- **Status:** open
- **Impact:** a worker following the EW-11 rule runs most of cmd/fathom (250 s under -race here) for a leaf change, so the selection is no narrower than the package run it was meant to replace
