### O309 — the tag-only pre-push skip trusted a stale remote-tracking ref of ANY remote

- **Symptom:** a tag-only push to one remote skipped validate and verify because a stale remote-tracking ref of a different remote held the tag's commit
- **Evidence:**
  - **Tool:** scripts/prepush-refs.sh decide (the O303 fix)
  - **Expected:** a push skips the gate only when the remote being pushed to holds the commit
  - **Actual:** `git for-each-ref --contains <commit> refs/remotes` matched refs/remotes/other/x, so a tag on a commit origin lacks skipped the full gate
  - **Repro:** scripts/prepush-refs_test.sh (a stale refs/remotes/other/x, a tag pushed to origin)
- **Root cause:** decide took no remote name and searched every refs/remotes ref; the stale-ref window is the same one the skip already tolerates for the right remote, widened to every remote
- **Fix:** decide takes the remote name (lefthook `{1}`, git's pre-push $1) and checks only refs/remotes/<remote>/; no name, an empty one or one with a slash keeps the full gate (EW-44)
- **Status:** fixed (EW-44)
- **Impact:** a tag push to a remote that lacks the commit could skip the gate; follow-up to O303
