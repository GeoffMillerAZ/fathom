### O1001 — `tests select --safe` picks the whole suite when a change adds an `error` type or shifts an unchanged method's lines

- **Symptom:** `fathom tests select --safe --since 99aa205a` on war2's fixes branch (a new `gitro.BlobAt` with two error types, the importer, `read_source` `ref`, `version --json`, `store.ClearMachineLocal`, one `sqliteReadOnlyDSN` branch) selected 3,312 tests across about 65 packages, so the "select before a whole-package run" step narrowed nothing.
- **Evidence:** in `--json`'s `ranked_tests[].reaches`, 3,091 tests reach `gitro.EntryError.Error`, `gitro.SizeError.Error` and `store.ConformanceError.Error`; 1,631 reach `store.SQLiteStore` and 1,535 `SQLiteStore.Close`. `ConformanceError.Error` and `SQLiteStore.Close` did not change: lines were inserted above them (a new reason constant in conformance.go, `FormatVersion` in sqlite.go). The two new `Error` methods are reached by every test whose code calls `err.Error()` through the `error` interface.
- **Root cause:** read in wave hon1. `tests select` seeded every symbol defined in a changed file (not only moved ones), and its reach followed every stored interface-dispatch edge, so every test that calls `err.Error()` reached every first-party `Error` method.
- **Fix:** wave hon1, TQ-29 (a symbol counts only when its own text changed since `--since`, read through `gitro.BlobAt`) and TQ-30 (selection-only rapid type analysis: a dispatch edge counts for a test only when its binary constructs the type). TQ-M6 reads 3,314 -> 1,850 tests (67 -> 13 packages) on this diff, 0 of 5 mutation failures missed (`docs/bench/readings/test-intelligence/safe-selection-precision.md`).
- **Status:** fixed (wave hon1, item select)
- **Impact:** the worker ran the ten packages it touches by hand (all green); a worker trusting the selection would run the full suite once per wave item.
