### O851 — SCSS: universal-ctags is deficient as its L1 oracle, and L2 has no rule for Sass, so scss.json reads L1 with L3 excellent

- **Symptom:** the queue names universal-ctags (tier B) for SCSS L1 and Dart Sass's loads (tier A) for L3. Read against ctags 6.2.1 at the dialect of bbb6caf6 (a scratch reading, never committed), bootstrap v5.3.8 + primer/css v22.3.2 score sym_recall .8999 and sym_precision .735 (3,289 of 3,655 and 4,475), L1 unmet; against Dart Sass's own parser the same dialect scores 1 and 1 (4,214 definitions, scss.json).
- **Evidence:**
  - **ctags-only (366):** numbers tagged as classes or variables (`25rem` from `0 0 0 .25rem`, `5`, `0`, `1`: 107); a class cut at an interpolation (`btn-` for `.btn-#{$color}`: 32); the rest ctags' line attribution.
  - **dialect-only (1,186):** custom properties (782; ctags has no SCSS kind for them, but its variable kind puts the dialect's `variable` canonical in the intersection), a class after a `+` combinator (`> .btn-check:checked + .btn` tags only `btn-check`), the variables of a two-variable `@each` (`@each $color, $value in` tags neither), and names kept with their interpolation (770 hold `#{`).
  - **L2:** §1.2's L2 is call_recall and call_precision over (enclosing symbol, callee) pairs. W2 (design 1.8) defines CSS's L2 as `var()` and `animation-name` name references within the import closure; no ruling defines it for Sass, whose references are `@include`, function calls and `$variable` reads under `@use` namespaces and `@import`'s globals. The dialect records `@include` and calls as references; no oracle grades them.
- **Root cause:** ctags' SCSS parser reads tokens, not Sass's grammar (as its CSS parser, O798); Sass's L2 is an owner's definition, not the harness's.
- **Fix:** D2's precedent: the dart-sass oracle (84b15ea1; sass-parser for definitions, the compiler's `loadedUrls` for loads) is SCSS's L1 and L3 oracle. scss.json reads L1 good (no end line) and L3 excellent (import_resolution 1, file edges 1 and 1, 281), level_met L1 because L2 is not attempted.
- **Status:** open: LB-Q-scss-rest, trigger the owner's L2 rule for Sass
- **Impact:** SCSS is indexed at L1 good with its load graph exact; a level past L1 waits on the L2 ruling.
