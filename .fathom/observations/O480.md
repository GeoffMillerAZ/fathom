### O480 — JavaScript's L2 is gradable on a typed subject: webpack (checkJs) reads .9430 / .9968, and none of its 1,391 fathom-only pairs is a dialect error

- **Symptom:** JavaScript L2 read call_precision .6173 / call_recall .8897 over axios + express (unmet), with 422 of 1,441 pairs (29%) left out as oracle-blind (LB-F175) and the ceiling counted as "scip-typescript cannot type untyped CommonJS" (O442). Nothing in the reading showed whether fathom's JavaScript calls were good where the oracle could judge them.
- **Evidence:**
  - **Tool:** webpack/webpack v5.111.1 (5a106753, MIT) cloned beside the measured checkout, `yarn install --frozen-lockfile --ignore-scripts`, scip-typescript 0.4.0 through calibration/oracles/scip-typescript/run.sh under its own tsconfig.json (`checkJs`, `strict`; globs `declarations.d.ts`, `declarations/**/*.ts`, `lib/**/*.js`), then `indexbench lang-oracle -dialect javascript -scip -scip-defs -only 'lib/**'` (746 files) and the O440 classifier (`go build -overlay`, scratch).
  - **Actual:** webpack call_precision .9430 (23,066 of 24,457) and call_recall .9968 (23,066 of 23,140); 477 of its 24,934 pairs are oracle-blind (1.9%; axios 21.8%, express 39.4%). The reading, three subjects: .9301 / .9936, L2 excellent, level L3 (L1 good: sym_recall .9442; L3 good: file_edge_recall .4025; L4 unmet: def_mapping .3591, typed_recall .3347). Fathom-only, classified: webpack 1,391 = 987 caller the oracle defines only as a `local` + 400 caller it has no symbol for + 3 import aliases + 1 receiver; axios 110 = 81 + 23 + 3 + 2 + 1; express 280 = 65 + 206 + 4 + 3 + 2. Every one of the 1,781 pairs has the callee written as a call in its file (0 without call syntax). Oracle-only 74 / 70 / 8: attribution to another caller, references that are no call.
  - **Repro:** calibration/oracles/scip-typescript/README.md (the webpack recipe), then the lang-oracle line above with `-unmatched`.
- **Root cause:** the two untyped subjects were the whole sample, so the oracle's type-checker blindness read as fathom's error. On a JSDoc-typed subject the same oracle and options leave only the callers it defines as locals (a class expression assigned to a member, `X.Template = class XTemplate extends ...`; a nested function) and callers it has no symbol for.
- **Fix:** no extractor change (no query moved; ExtractorEpoch stays). The grader is the subject (LB-F205); the cap is a harness rule (LB-F203). O442's trigger ("a typed JavaScript subject") fired.
- **Status:** fixed (JavaScript L2 graded: excellent on the three-subject reading); L4 stays open (def_mapping, typed_recall: O115)
- **Impact:** JavaScript's L2 is now a measurement of the extractor on typed code; see O482 for what the sum hides about untyped code.
