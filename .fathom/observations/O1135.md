### O1135 — `obligations` serves platform-engineering 6 rules from `CLAUDE.md` files that no longer exist

- **Symptom:** a root-scope `obligations` call for service `platform-engineering` returns 6 rules whose `src` is `CLAUDE.md` or `capstan/CLAUDE.md`; both files were deleted at that repository's commit `444640c` ("AGENTS.md is the only instruction file"). The rules are flagged `contradicted` and counted in `stale_count: 6`, but they are still the rules served, and the summary line leads with one of them.
- **Evidence:**
  - **Tool:** MCP `obligations` (`renderObligationReceipt`, `staleRuleTest`, `internal/mcp/semantic_tools.go`)
  - **Expected:** a rule whose source file is gone at the indexed commit is withheld and counted, with a remedy, the way a rule from a changed section is (I38, O1122); it is never served as governing.
  - **Actual:** the stale-section test judges a rule by its section's coverage; a deleted file has no section in the coverage (`layer_coverage` shows 54 sections, all `corpus_grew`, 0 compiled), so nothing withholds it. `index_stale: true`, remedy `fathom compile --layer obligations --service platform-engineering` (model spend, held).
  - **Repro:** `obligations {service: platform-engineering}` on the shared daemon, 2026-10-17; `ls CLAUDE.md capstan/CLAUDE.md` in that checkout: no such file.
- **Root cause:** staleness is measured per section of a file that exists; deletion of the file itself is not a staleness signal the receipt reads.
- **Fix (proposed shape):** test first: a compiled rule whose `src` file is absent at the indexed commit is withheld, counted in `layer_coverage`, and the remedy names the recompile. `docs/plans/intent-v2.md` IV-7, ADR-074 decision 7.
- **Status:** fixed (iv2-serve, IV-7): a compiled rule whose source file is absent from the layer's live corpus is withheld, counted in `layer_coverage.stale_withheld`, named in `layer_coverage.missing_sources`, and `remedy` names the recompile; tests `TestObligationsTool_RuleFromDeletedSourceFileWithheldAndCounted` (`internal/mcp/stale_withheld_layer_test.go`), `TestLiveLayerCoverage_NamesSourceFilesGoneFromTheCorpus`.
