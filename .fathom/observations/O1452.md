### O1452 — Root-scope obligations never get a raw fallback, so while the root guide is uncompiled the root call serves another document's old rules as root guidance

- **Symptom:** `obligations {service}` with no file is supposed to return the repository's root rules. On app-kit it returns six component rules from `docs/design/*.md`, each summarized as a "root-scope governing rule". The root `AGENTS.md`, which `layer_coverage` reports as uncompiled, contributes nothing. Adopters filed 2 reports, on 2026-10-01 and 2026-10-15 (theme T08 in docs/bench/readings/feedback/adopter-triage-2026-10-20.md). The September stale-rule reports are J2's (O88, closed).
- **Evidence:**
  - **Reports:** app-kit O63 ("six unrelated profile/application-shell rules returned … four root sections uncompiled") and O87 ("Root obligations omit current AGENTS section and serve unrelated application-shell rules from an old compiled watermark").
  - **Probe, 2026-10-20, deployed binary 909ea5c2e:** `obligations {service: app-kit, max_rules: 6}` returned `compiled_at_watermark: dc77e660…`, `displaced: 43`, and `layer_coverage: {sections_total: 4, sections_compiled: 2, uncompiled_scopes: ["AGENTS.md"], uncompiled_reasons: {"AGENTS.md#app-kit-agent-guidance": "corpus_grew", "AGENTS.md#maintainer-only-workflow-this-app-kit-checkout": "stale"}}`. All six rules cited `docs/design/profile-drawer-adapter.md` or `docs/design/application-shell.md`. The note said "Root-scope obligations only (repo-root AGENTS.md/CLAUDE.md-level rules)".
  - **Code:** `semantic.RawFallbackRules` (internal/semantic/rawfallback.go) "Returns (nil, nil) when file is empty". The raw fallback, which serves an uncompiled or stale section's own text in place of a compiled rule (wave O1, O1125), never runs for a root call.
- **Root cause:** the deterministic fallback for uncompiled sections is file-scoped only. At root scope, an uncompiled root guide leaves just the compiled rules from the last compile, which here are design-doc rules with no narrower scope. Under the budget hold nothing recompiles, so this lasts until someone pays for a compile. The summary also calls a design-doc rule "root-scope".
- **Fix:** proposed, not built (small). At root scope, when `uncompiled_scopes` names a root guide (AGENTS.md, CLAUDE.md), serve `RawFallbackRules` over that guide's sections, with the root as their implied scope, ranked above compiled rules from non-guide documents. Make the summary name the cited document's kind instead of "root-scope" for a rule from `docs/design`.
- **Status:** fixed (666a2cc55)
- **Answers:** app-kit O63 and O87.
- **Impact:** an agent that asks for the repository's rules at session start gets an unrelated component's rules and never sees the current root guidance, without paying for a compile.
