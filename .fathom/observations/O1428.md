### O1428 — the pre-edit hook's tech-pack and generated-line step adds 6 ms p95 with one discovered pack; the project `.fathom/` load is most of the fixed cost

- **Symptom:** every file edit now reads the project's `generated` declarations and discovers packs before the guard match, so a repository without a pack pays it too.
- **Evidence:** `packExtras` over this repository's root, 100 runs on a warm cache: no pack (project load plus an empty `Discover`) p50 4.5 ms, p95 7.0 ms; one discovered pack (two guards, one generated pair, fixtures passing) p50 10.1 ms, p95 13.3 ms. Added p95 for the pack: about 6.3 ms.
- **Root cause:** `projectdir.Load` evaluates the CUE under `.fathom/` on each hook process; `Discover`, `RunFixtures` and `hashDir` read the pack from disk each time. No cache exists (TABLE FREEZE).
- **Fix:** none yet. A cheaper first step is to skip `projectdir.Load` unless a `.fathom/*.cue` text mentions `generated:`.
- **Status:** open
- **Impact:** well inside the 2 s pre-edit budget; every guard-less edit pays about 7 ms p95.
