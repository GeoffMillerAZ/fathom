### O881: RF-M1's bars grade a repository-wide role against a root-configured collection, and a subject under 35 tests cannot pass the Wilson bar

- **Symptom:** RF-M1 (docs/bench/readings/repository-facts/roles.md) read CUT with recall 1.000 on every measured subject. Every disagreement is a file the convention calls a test that the runner, run from the root under the repository's own configuration, does not collect: flask's `examples/*/tests/test_*.py` and fastapi's `docs_src/**/test_main.py` (outside the root `testpaths`), react-router's `__tests__/` helpers (its `testMatch` narrows jest's default), build-tagged Go tests (`go list` without `-tags`), Maven's `*IT` classes (Failsafe's, not Surefire's)
- **Evidence:** precision react-router 0.720, flask 0.815, apache/maven 0.785; cobra 17 of 17 reads a Wilson lower bound of 0.816 and guzzle 27 of 27 (mapped by declaration) 0.875: at perfect precision the 95% lower bound reaches 0.90 only at n >= 35 (n / (n + 3.84))
- **Expected:** a re-reading that (a) states which collection the role claims (a file the repository's runners would run under any of its configurations, or the root configuration's), (b) grades a subject under 35 convention tests on its point estimate or pools an ecosystem's subjects for the interval, and (c) either reads the runner's own configuration (`testpaths`, `testMatch`, `include`) as dialect-pack input or stops claiming the root collection
- **Root cause:** the row's bars were written before a subject was read; the convention reads a path, the oracle reads a configuration
- **Status:** open (the owner-architect's to rule; RF-4 is refused until a reading reads KEEP)
