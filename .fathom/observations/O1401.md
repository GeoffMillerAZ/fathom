### O1401 — RO-33's brief named the FD-4 keyed loader, which reads CUE only; `.fathom/readouts.toml` needs a zone-table entry, not a `#Project` key

- **Symptom:** the row says repository files read through the one keyed loader (ADR-061, FD-4). `projectdir.Load` parses `.fathom/*.cue` per key; `readouts.toml` is TOML in the user rule-file format, as `config.toml` is.
- **Evidence:**
  - **Tool:** `internal/projectdir/load.go` `knownFiles` lists CUE files only; `config.toml` is read by `internal/config`
- **Root cause:** the premise conflated "one keyed loader" (no second reader of a CUE key) with every `.fathom/` file.
- **Fix:** `projectdir.Readouts` names the file (Z1 in `docs/design/fathom-dir.md` section 4); `internal/readout.loadRepoRules` reads it with the user-file parser and validator, so no second schema or reader of the format exists.
- **Status:** fixed
