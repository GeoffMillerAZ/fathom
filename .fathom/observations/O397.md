### O397 — a `.hcl` the content sniff does not claim is counted ambiguous: Vault and Consul configuration, `.terraform.lock.hcl`, and any file that opens with more than a KiB of comments

- **Symptom:** an ingest report's AmbiguousUnclassified now counts every `.hcl` neither dialect claims; before, an unregistered `.hcl` was silently unextracted
- **Evidence:**
  - **Tool:** `TestIngest_TerragruntDialect`, `TestIngest_HCLToolsDialect`: vault.hcl, consul.hcl and .terraform.lock.hcl are ambiguous, never extracted
  - **Expected:** one extension two dialects claim by sniff (Terragrunt's blocks, a top-level `job`) and the rest unread
  - **Actual:** as expected; the sniff reads the first KiB only, so a Terragrunt file whose first block starts later is unclaimed
  - **Repro:** `connector.ClassifyDialect` on a file with a 2 KiB banner comment
- **Root cause:** `.hcl` is the extension of several unrelated tools; classification (design section 5) never guesses
- **Fix:** none; Vault and Consul are LB-Q-hcl-tools-rest; the sniff window is the connector's
- **Status:** open
- **Impact:** a comment-heavy Terragrunt include target is not read, so an include of it resolves to nothing
