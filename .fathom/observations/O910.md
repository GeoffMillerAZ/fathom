### O910 — clang-ast-defs' end-to-end tests read nothing when TMPDIR is a symlinked path

- **Symptom:** `go test` in calibration/oracles/clang-ast-defs fails TestClangEndToEnd with an empty definitions map, both at origin/main e7bbd99e and with this wave's change, whenever TMPDIR is macOS's default /var/folders/... . It passes with the wave's TMPDIR on the external volume.
- **Evidence:**
  - **Tool:** `env -u TMPDIR GOWORK=off go test ./...` in the oracle's module, with the test stashed back to e7bbd99e: `definitions = map[], want map[Color:[3 4] ...]`.
- **Root cause:** the test passes the compiler the unresolved temp path (/var/...), and clang reports the path it was given. The subject root is `filepath.EvalSymlinks(dir)` (/private/var/...), so `within` places every definition outside the subject.
- **Fix:** both end-to-end tests resolve the temp dir before writing their files (wave lf6, item cfam).
- **Status:** closed.
- **Impact:** the oracle's own output was unaffected, because a compilation database carries the paths the build used. Only the tests failed, and they failed on the default macOS TMPDIR, which is where a stranger runs them.
