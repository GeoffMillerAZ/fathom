### O751 — K25 ruling 3 read literally collapses Rust's file-edge truth: rust-analyzer's per-target copies of one symbol are narrowed, a refinement beyond the ruling's text, for the owner

- **Symptom:** with a symbol defined in more than one document resolving to every defining document (ruling 3), the Rust reading's file-edge truth grows from 2,311 to 14,331 pairs and file_edge_recall reads .0583 (precision .9976)
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect rust -scip -scip-defs` over ripgrep 14.1.1 and clap v4.6.1 (rust-analyzer 03fcb77246 indexes rebuilt 2026-10-10), with a scratch classifier of the pairs only a later definer draws (never committed)
  - **Expected:** O539's measurement: every definer for a non-module symbol, file_edge_precision .9963 and recall .2822
  - **Actual:** rust-analyzer names a definition by package and in-crate path, never by crate target, and prints a "Duplicate symbol" warning for each collision itself (712 on clap). `crate/` of package clap has 66 definers (src/lib.rs, every test, example and bench root): 11,770 of the 12,020 added pairs; clap's examples each declare a `struct Cli`, one symbol `Cli#` with 26 definers (625 pairs, each example's own reference to its own `Cli` drawn to the 25 others); O539's twin `utils/` and its items (about 70)
  - **Repro:** the calibration README's commands at this item's HEAD with `rustDuplicateDefiners` returning nil
- **Root cause:** the producer conflates per-target copies; "every defining document" is the right reading for a merged declaration (TypeScript's declaration merging) and the wrong one for a copy per crate target
- **Fix (done, LB-F387, counted as `scip_file_edges_duplicate_narrowed`, 12,075 pairs):** for rust-analyzer only, `internal/langbench/scip_rust.go` `rustDuplicateDefiners`: (1) `crate/` written as a crate name (`use clap::Parser;`, never `crate`) is the package's library root (its definers named lib.rs); (2) a reference inside a defining document is to that document's own copy; (3) any other item keeps every definer (ruling 3 as written: O539's `utils::FULL_TEMPLATE` from tests/builder/command.rs is an edge to both utils.rs); (4) any other module (K18's namespace) is the copy in the nearest directory above the reference (Cargo puts a target's modules under its root's directory), else the library root, else every definer. Measured each step: modules alone narrowed .4764 (truth 2,939; L3 good), modules and own copies .6206 (truth 2,256; L3 excellent). (1) and (4) read the source text and the document paths, Cargo's layout, never rust-analyzer's resolution
- **Status:** open (for the owner): the narrowing is disclosed in every Rust subject's notes and the reading's; if the owner reads ruling 3 as admitting no producer rule, step (2) reverts to every definer for items (L3 good, .4764) and step (4) to every definer for modules (.0583)
