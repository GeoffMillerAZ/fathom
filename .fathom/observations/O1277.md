### O1277 — RO-24's "edited 2 calls ago" cannot be counted: the session edit set holds a time stamp, not a call index

- **Symptom:** RO-24's example line ends "edited 2 calls ago", but the line can only say "edited this session".
- **Evidence:**
  - **Tool:** `cmd/fathom/editset.go` (`markFileEdited`, `fileRecentlyEdited`)
  - **Expected:** a per-session call index for each edited file
  - **Actual:** one stamp file per (session, file) holding an RFC 3339 time, inside a 10-minute TTL. No call index exists, and the table freeze rules out adding one.
  - **Repro:** `TestCompileErrorsGroupByRootAndEditSet` (cmd/fathom/readouthook_rich_test.go)
- **Root cause:** the edit set was built for instrument B's edit-set exclusion. It answers "edited recently", not "how many calls ago".
- **Fix:** the line says "edited this session". Counting calls would need the hook log's session rows (as RO-20 reads them), which is a later choice if RO-M4 shows the count matters.
- **Status:** open
