### O602 — C's and C++'s judged false file pairs, classified after LB-F294 and LB-F296

- **Symptom:** C keeps 22 judged false file pairs (file_edge_precision .9945) and C++ 12 (.9754)
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -unmatched` (fathom_only with via and by), wave lf1 item ccpp
  - **Expected:** a pair fathom draws is in the index's truth
  - **Actual (C):** 9 calls bind a header's macro stub on the branch the build discards (`#define Curl_cookie_cleanup(x) Curl_nop_stmt` in lib/cookie.h, netrc.h, vdns/hostip.h, vdns/asyn.h, ftplistparser.h), their guards reading feature macros from the generated build/lib/curl_config.h, which the lexical guard evaluator (O468) does not read; 10 calls bound through a header prototype to a .c the index names no reference to (curlx/warnless.c conversions, mprintf.c, parsedate.c, easyoptions.c, libuv darwin-proctitle.c); 3 type and macro references (curl_setup.h `timeval` and `CURL_DISABLE_HTTPSIG`, uv/win.h `addrinfo`)
  - **Actual (C++):** 3 calls bound to a test .cc that defines the callee (`read`, `write`: fmt's posix-mock-test.cc and os-test.cc to gtest-extra.cc and os-test.cc, where the build links the mock); 8 type references in spdlog written beside a parameter or member of the same name (`std::unique_ptr<formatter> formatter`, `std::shared_ptr<logger>`): the index writes an occurrence for the parameter's token only, so the blind rule (LB-F296) counts the pair as judged; 1 json reference, `value_t::discarded` through a dependent `BasicJsonType`, bound to the enumerator
  - **Repro:** the scip-clang README commands with -unmatched
- **Root cause:** the guard evaluator reads -D flags and the file's own #defines, not a generated config header; a call's lines are not carried to the resolver, so an inactive call site inside an active function binds like an active one
- **Fix:** open: read the compile database's generated config headers into the guard environment; carry call lines to the include-path resolver. O470 (a template parameter named like a class) accounts for none of these at this reading
- **Status:** open
- **Impact:** C L3 is excellent without them; the 8 spdlog pairs are the oracle's blindness the site rule cannot see (a type token beside a same-named parameter): with them judged blind C++ would read 62 of 542 (11.4%), over the cap
