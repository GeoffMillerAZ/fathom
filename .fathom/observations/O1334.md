### O1334 — F82's overlap count from git alone is a lower bound because callers are invisible

- **Symptom:** The F82 definition counts "the same symbol or its callers". A `git merge-tree` replay sees only symbols both sides edit, so it cannot see "line A changes `Open`, line B adds a caller".
- **Evidence:**
  - **Tool:** `docs/bench/readings/f82-overlap-replay.py`
  - **Expected:** caller-level overlaps counted
  - **Actual:** 63 of 523 merges (51 non-test) with a shared function or type, no caller overlaps counted
  - **Repro:** run the script and read `docs/bench/readings/f82-overlap-replay-2026-10-19.md`
- **Root cause:** git has no symbol graph. Only the index resolves callers.
- **Fix:** none needed for the Promote-when (the lower bound already clears 4 a month). A later replay can add `blast_radius` per side if a number for callers is wanted.
- **Status:** open
