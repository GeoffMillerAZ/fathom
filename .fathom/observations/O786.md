### O786 — `fathom tests select` names no JavaScript or TypeScript test: a test is a symbol named Test*, and a TS test file's describe/it calls belong to its module symbol

- **Symptom:** wave lf4's brief for D1 asked a fixture to prove that `fathom tests select` "still picks a TS test file through its module call rows when the function it calls changes". It picks none, before D1 and after: on a fixture with `src/price.ts` and `src/price.test.ts` (`describe`/`it` callbacks calling `total`), `tests select --safe --json` for a change to `src/price.ts` selects no test and lists `total` and the file's `<module>` under `test_gap`.
- **Evidence:**
  - **Tool:** `runTestsSelect` on that fixture, ingested with `fathom ingest` (cmd/fathom/selectts_module_test.go's fixture, wave lf4 branch lf4-tsjs).
  - **Code:** `callgraph.TestImpactDetail` (internal/analysis/callgraph/graph.go, the reach ranking) counts a caller as a test only when `strings.HasPrefix(node.Name, "Test")`; `selectCertifyingFirst` (cmd/fathom/tests_select_certifying.go) splits tests from the rest by the same prefix. A TS test file's calls are owned by `<module>` (K18, LB-F381), whose name is never Test*.
  - **The reach itself is there:** in the graph tests select builds (`callgraph.BuildBoth` over the stored symbols and typed edges), `src/price.test.<module>` reaches `src/price.total` and `src/other.spec.<module>` does not, with D1's lever on (TestTestsSelectGraphReachesTSTestFileThroughModuleCalls, LB-F412).
- **Root cause:** tests select's notion of a test is Go's (a Test* function); a JS/TS test unit is a test file (`*.test.ts`, `*.spec.ts`, `__tests__/`), whose module symbol owns its callbacks' calls.
- **Fix:** none here (tests select is h4's; the brief forbids editing it). Proposed: treat a test file's module symbol as a test unit (by the test-file conventions certify.isTestFile already reads) with a runner invocation per file.
- **Status:** open
- **Impact:** on a JS/TS change tests select reports every reached function as untested and selects nothing; the static reach a selection would walk is intact.
