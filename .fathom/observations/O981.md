### O981 — tree-sitter-vue reads a member component tag as a tag and a shorthand

- **Symptom:** `<Foo.Bar />` parses as the tag `Foo` with a `.Bar` v-bind shorthand attribute; the Vue compiler reads the tag `Foo.Bar`, a component.
- **Evidence:** `indexbench lang-probe -dialect vue internal/extractor/dialects/vue/testdata/both.vue`: `(self_closing_tag (tag_name "Foo") (directive_attribute (directive_value "Bar")))`.
- **Root cause:** the grammar's tag name stops at `.` (ce8011a4).
- **Fix:** the vue tags query names a call by the member when the tag's text continues with `.name` and skips the bare tag (owner ruling M2: a member tag calls its last segment).
- **Status:** fixed
- **Impact:** a member tag nested deeper (`<A.B.C>`) is read by its second segment; none is in the subjects' compiler pairs.
