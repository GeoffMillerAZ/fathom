### O784 — route_oracle.mjs `--env-file` fails on Node 26: the runtime reads the flag before the script

- **Symptom:** the react-router oracle README's bulletproof-react recipe (`--env-file .env.example`) exits `node: .env.example: not found` on Node v26.10.0, before the script runs
- **Root cause:** Node 26 scans the whole command line for `--env-file`, after the script name too, and loads the file relative to the working directory; the oracle's value is app-relative. The script's by-hand argv parse never sees a failure, the process dies first. (`node a.mjs --env-file f` with `f` in the cwd passes the flag through and loads nothing for the script; with a missing file it exits 9.) So an alias would still fail whenever the path is not cwd-relative, and none is kept
- **Fix:** the flag is `--app-env` (reader, usage comment, README recipe; calibration/oracles/react-router/)
- **Evidence:** re-ran alan2207/bulletproof-react `9506629e` `apps/react-vite` against its own react-router 7.0.2 (npm install under w-h4-gates, `--ignore-scripts`): 10 routes, 0 render failures, `to_route_oracle.mjs --group entry` gives 10 rows at 9 distinct paths, handlers LandingRoute, NotFoundRoute, AppRoot, DashboardRoute, DiscussionsRoute, '' (the discussion lazy route), ProfileRoute, UsersRoute, LoginRoute, RegisterRoute. The oracle files are regenerated, never committed (`docs/bench/readings/routes/react-router-consts.md`), so the comparison is to that reading's record: sha 9506629e, react-router 7.0.2, 10 routes at 9 distinct paths, oracle_routes 9. Same
- **Status:** fixed
