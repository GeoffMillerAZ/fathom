### O709 — the obligations edit hook asked the daemon about gitignored files

- **Symptom:** an edit under `workspace/` (gitignored scratch, logs, local DBs) made the PostToolUse, `--pre` and Bash-write paths run identity resolution and an obligations RPC for a file the index never holds
- **Evidence:** renderPostEdit, renderPreEdit and cmdEditHookBashWrite checked only the capability switch before daemon traffic; `git check-ignore -q` costs about 9 ms per call, in-process matching about 0.04 ms (BenchmarkGitIgnoreDecision)
- **Root cause:** no path predicate stood before the daemon calls
- **Fix:** `skipIgnoredEditTarget` (cmd/fathom/edithook_ignored.go) decides in process from the .gitignore files and .git/info/exclude and confirms a positive with `git check-ignore`; nothing is cached (EW-55)
- **Status:** fixed (wave h1)
- **Impact:** wasted daemon round trips and rule text injected for files nobody indexes
