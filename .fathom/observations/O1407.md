### O1407 — The custodian's four shipped packs ship no fixtures and carry only concerns, so `rules fixtures` reads them empty

- **Symptom:** `fathom rules fixtures` on claude-code, codex, lefthook and taskfile prints only the pack header and exits 0: no guards, generated or formats section is present, so none is withheld.
- **Evidence:** each `internal/custodian/packs/<name>.cue` copied to `<dir>/pack.cue` reads `pack <name>@1`, rc 0. `#Pack` (schema/techpack) declares no fixtures layout, so the harness defines it: `<dir>/fixtures/*.cue` with `guards`, `generated`, `formats` keys (docs/usage/rules.md). Concerns are gated by the repository's `packs:` list and have no fixtures section.
- **Root cause:** the design names fixtures for guards, generated and formats only; the custodian packs are concerns-only.
- **Fix:** none needed for these four. A kit pack with guards/generated/formats must ship `fixtures/`.
- **Status:** closed
- **Impact:** none for custodian packs; FD-14 serving will withhold any kit section lacking fixtures.
