- **Root cause:** the shims were removed in 2026-07; the detector was kept as a migration aid and never revisited.
- **Fix:** proposed, not made (a records wave edits no code): delete the `reconcile.go` detector branch and the `local_test.go` pin in a later wave. Observable only as a doctor/reconcile note that no repo triggers, so likely no CHANGELOG line.

- **Impact:** dead branch and a stale test to carry; no user effect.
