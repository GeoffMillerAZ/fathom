### O979 — A component's import of a TypeScript file draws no file edge

- **Symptom:** an ingest resolves `import { buttonProps } from './button'` in `Button.vue` to nothing, and a `.ts` file's `import Foo from './Foo.vue'` to nothing.
- **Evidence:** `fusion.FileResolveLangs` gives each file-resolve language its own extensions; the resolver's universe for `vue` is the `.vue` files and for `javascript` the `.js`/`.ts` family, so neither sees the other's files (`TestIngest_VueAndSvelteComponents` asserts only the component-to-component edges).
- **Root cause:** the file resolver keys a universe by language, and an injection host (F2) is its own language.
- **Fix:** none in this wave; the harness counts a `.ts` target as out of scope (design §1.8 W4 for Vue and Svelte).
- **Status:** open
- **Impact:** the component graph is read; the edges between components and their TypeScript modules are not (a trigger of LB-Q-vue-rest and LB-Q-svelte-rest).
