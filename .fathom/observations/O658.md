### O658 — tests select --safe selected nothing for an edit to an embedded skill, not even TestPluginTemplateDigestPinned

- **Symptom:** during the v0.10.0 release a `dist/agents/skills/**/SKILL.md` edit broke `TestPluginTemplateDigestPinned` (cmd/fathom/pluginrender_test.go L157), and `fathom tests select --safe` had not selected it (REL RESULT (a), 2026-10-09)
- **Evidence:** a file embedded by `//go:embed` (dist/agents/skills/dist.go L20) defines no symbol; selectCertifyingFirst (tests_select_certifying.go L45-132) and impact.TestGap seed only symbols defined in the changed files, and the index has no edge from a function to the package variable it reads (`symbol_context` on `skillsdist.FS`: no callers)
- **Root cause:** the selection mapped changed files to symbols by definition only; an embedded file's bytes reach code through the embedding variable, which is not a call target
- **Fix:** `embedChangedSymbols` finds the `//go:embed` variables whose patterns name a changed non-Go file (directory walks skip `.`/`_` names unless `all:`) and seeds the variable and every function that reads it (bare in its package, qualified where imported); `impact.TestGapSeeds` and `selectCertifyingFirstSeeds` take those keys (TQ-21, commit d861154a)
- **Status:** fixed (wave w2a)
- **Impact:** any repo whose tests pin embedded assets (templates, skills, schemas): `--safe` skipped the one test that guards them
