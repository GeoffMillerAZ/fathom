### O749 — the TypeScript reading measures .ts files only while its L4 counts every document of the index, and the module-level residue that remains

- **Symptom:** typed_recall reads .937 on nest + zod although every measured document's references read .9498.
- **Evidence:**
  - **Tool:** O746's classifier at b9d25f09, ScoreSCIPWith on zod's index cut to the documents the reading measures.
  - **Scope:** `lang-oracle` measures a dialect's `match.extensions` (`ownedSourceRefs`, Manifest.Owns), so the typescript reading never extracts its tsx variant's `.tsx` files, while def_mapping and typed_recall read every document of the index: zod's 29 `.tsx` documents (its docs app) add 334 definitions and 1,581 references fathom is never given the nodes for. Cut to the 375 measured documents, zod reads def_mapping .4604 (5,038 of 10,942) and typed_recall .94 (66,072 of 70,287); nest has no `.tsx` document. TypeScript overall would read .5219 and .9498.
  - **The residue under it (TypeScript, unmapped typed references 7,410):** 3,240 to a class or interface property the member patterns leave, 935 to an object-literal property (O747), 986 from a function or variable in a `.tsx` document, 608 to a namespace (`declare module`, `namespace X`), 572 from module-level code in a `.tsx` document, 540 from a constructor scip-typescript's enclosing range and fathom's lines disagree on, 229 to a constructor.
  - **JavaScript:** express's 468 and webpack's 294 module-level `var` and `let` bindings are no constant (LB-F382 names `const` only, canonical constant); express reads def_mapping .145 and typed_recall .365 for it.
- **Root cause:** the reading's file set is the dialect's extensions, not its variants'; ClangScope (LB-F292) scopes C's L4 to the measured documents, and no TypeScript rule does.
- **Fix:** proposed, harness (internal/langbench, not this item's): either measure the tsx variant's files in the typescript reading (Manifest.Owns reading variants), or scope L4 to the measured documents as LB-F292 does for C. Neither moves the level: def_mapping is O747's.
- **Status:** open
- **Impact:** TypeScript's typed_recall reads 1.3 points low; a `var`-style CommonJS codebase reads its module bindings as missing.
