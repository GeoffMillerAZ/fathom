### O1276 — RO-25's premise is false: a command guard's `command_scopes` says which commands it governs, never what a command must carry

- **Symptom:** RO-25 (docs/plans/readouts.md phase 2) asks for a line "when a command guard's `command_scopes` names what the gate requires and the command that ran lacks it (for example `go test` without `-race`)", and design §17 says "the guard matcher already knows `go test` without `-race` misses what the gate runs". It does not. No guard in `.fathom/guard.cue` names `go test`, and the guard vocabulary cannot say "requires".
- **Evidence:**
  - **Tool:** `.fathom/guard.cue`, `schema/guard/schema.cue` (`command_scopes`, `enforce`), `cmd/fathom/guard.go` (`matchingCommandGuard`, `commandMatches`), `cmd/fathom/edithook_pre.go` (`cmdEditHookPreCommand`)
  - **Expected:** a guard field the readout hook can read as "this command family must carry flag X"
  - **Actual:** `command_scopes` are shell globs, and a match is the trigger: the note is served on a match, and under `enforce: true` the match is denied (ADR-038). Nothing negates or requires a flag. Reading a pattern's literal flags as requirements inverts a danger guard: a `git push --force*` advisory guard would tell an agent its `git push origin main` "lacks --force".
  - **Repro:** `grep -n "race\|go test" .fathom/guard.cue` (no match); schema/guard/schema.cue lines 107-119
- **Root cause:** the row was written against a matcher capability that does not exist.
- **Fix:** RO-25: the owner-architect decided on 2026-10-19 that command guards gain an optional, additive `requires` list (schema/guard/schema.cue, internal/guardspec), project scope only (a user-scope guard setting it is refused), with no pre-tool meaning: the PreToolUse path never reads it. Rich mode's `guardLineForCommand` (cmd/fathom/readouthook_guard.go) matches each simple command of the parsed line against `command_scopes` and names a missing token, the guard's `.fathom/guard.cue:N`, its pattern and its note. This repository's `.fathom/guard.cue` guards no `go test` command, so no `requires` was added to it. Recorded in docs/design/readouts.md §18 and docs/design/guarded-edits.md §2.5.
- **Status:** resolved — RO-25
