### O919 — a .sh file whose shebang names zsh is read as bash

- **Symptom:** ohmyzsh 42a4ccb1's `tools/upgrade.sh`, `tools/changelog.sh`, `tools/theme_chooser.sh` and `plugins/wd/wd.sh` open with `#!/usr/bin/env zsh` and are extracted by the bash dialect.
- **Evidence:** the zsh grammar measurement (docs/bench/readings/lang/zsh-grammars.md, wave lf6): an extension decides before a shebang (D4 reads a shebang only for a file with no extension).
- **Root cause:** D4's rule, by design: the extension is the cheaper and usually right signal.
- **Fix:** none (disclosed): with no grammar under the 5% gate on zsh (LB-F454), a zsh-shebang .sh file gets the bash grammar's best effort, as before D4.
- **Status:** open. Trigger: a zsh route (LB-F454's trigger), then the shebang read for a `.sh` file too.
- **Impact:** a handful of zsh scripts named .sh per zsh-heavy repository, with ERROR nodes and partial symbols.
