### O1125 — a withheld adr-rules rule from a stale `docs/design` section gets no raw replacement: the raw fallback reads the obligations corpus only

- **Symptom:** since O1122 the `obligations` receipt withholds an adr-rules claim whose `docs/design/*.md` section the adr-rules layer reports stale, and counts it in `layer_coverage.stale_withheld`; but the section's current text is not served in its place, as it is for an obligations-layer section (O1105). The caller learns a rule was withheld, not what the section now says.
- **Evidence:**
  - **Tool:** MCP `obligations` (`renderObligationReceipt`, `internal/mcp/semantic_tools.go`; `Client.RawFallbackObligations`, `pkg/client/semantic.go`)
  - **Expected:** a rule withheld because its section changed is replaced by that section's current text, whichever layer compiled it (I38, O1105's fix shape).
  - **Actual:** `RawFallbackObligations` loads the obligations layer alone (`pkg/client/semantic.go:486`, `semantic.LayerObligations`) and ranks that layer's corpus, which has no `docs/design` file (`internal/semantic/layers/obligations/layer.cue:16`); its stale-only branch restricts to the obligations coverage's stale subjects. The receipt calls it once (`internal/mcp/semantic_tools.go:454`). The withhold itself is per layer (`staleRuleTest`, `:152`).
  - **Repro:** read from the code at fx1-obl HEAD, found while fixing O1122; `TestObligationsTool_AdrRulesDesignSectionStaleWithheld` (`internal/mcp/stale_withheld_layer_test.go`) shows the withhold with no raw row from the fake.
- **Root cause:** the raw fallback (ADR-037) was built for the obligations layer's coverage gaps, and the stale-section replacement (O1105) reused it, so it inherits the one-layer corpus.
- **Fix (proposed shape):** test first: a stale adr-rules `docs/design` section that governs the edited file is served raw after its claim is withheld. Then let the raw fallback take the layers whose rules were withheld and rank each one's stale sections from its own corpus, within the same `RawFallbackReserve`.
- **Status:** open
