### O1508 — Private scratch ingest degraded on Go 1.27 export data

- **Symptom:** Private scratch ingest degraded on Go 1.27 export data
- **Evidence:**
  - **Tool:** ingest
  - **Expected:** Typed Go loading accepts the repository-pinned Go 1.27.3 exports
  - **Actual:** 340 of 1266 packages failed typed loading: export data version 5 is greater than maximum supported version 4; source text facts were stored
  - **Repro:** GOWORK=off GOTOOLCHAIN=go1.27.3 GOMAXPROCS=2 GOFLAGS=-p=2 fathom ingest --path . --service iac-crossplane-r2 --store workspace/db/crossplane-r2.sqlite
- **Root cause:** The source-processing importer accepts export-data version 4, while the repository-pinned Go 1.27.3 tool emits version 5. Typed loading is incompatible with that export format.
- **Fix:** Open. Keep the lexical row proof separate from typed-load success; no product fix is included in this calibration branch.
- **Status:** open
- **Impact:** Full local scratch ingestion is degraded. The independent Crossplane grade and owner-tool probes do not use this typed index.
