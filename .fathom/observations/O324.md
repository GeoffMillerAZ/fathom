### O324 — a YAML file whose top-level `services:` is a list classifies as compose, and the docker-compose dialect gives it a ComposeFile symbol

- **Symptom:** a YAML file whose top-level `services:` is a list classifies as compose, and the docker-compose dialect gives it a ComposeFile symbol
- **Evidence:**
  - **Tool:** `fusion.Ingest` (classifyYAML's `servicesTopRe`, internal/fusion/classify.go; the docker-compose dialect dispatched by LB-F89)
  - **Expected:** a GitLab CI fragment under another name, or another CI file whose `services:` is a list of images, is not a Compose file and holds no compose symbol
  - **Actual:** `servicesTopRe` matches any top-level `services:` key, so such a file reaches `toolExts[ToolCompose]`; composeextract.go emitted nothing for it (counted in ClassifiedZero), the dialect emits its root entity, named by the file
  - **Repro:** the GitLab-shaped fixture `ci-config.yml` (`services:\n  - docker:dind\nstages:\n  - build\n`) that TestIngest_ClassifiedButZeroSymbolsCounted used before LB-F89: one `ComposeFile` symbol, ClassifiedZero 0
- **Root cause:** classification decides by a top-level key's presence, not its shape; the incumbent masked it by needing a mapping to emit anything, and the doc engine's `where` cannot say "services is a map, or include is present" for a root entity
- **Fix:** classifyYAML asks `composeServices` (internal/fusion/classify.go), not `servicesTopRe` alone: the first line after a top-level `services:` that is neither blank nor a comment must not be a block-sequence item, so a `services:` list is unclassified YAML (counted as Unclassified, no observation) and a mapping is Compose; any document of a multi-document file counts. Pinned by `TestClassify_ServicesList_NotCompose` and `TestIngest_ServicesListYAML_NoComposeSymbol` (the GitLab-shaped fixture), `TestIngest_ClassifiedButZeroSymbolsCounted` now uses a compose mapping that does not parse, and `TestClassify_GitLabCI` reads `docs/compose.yml` holding a list as unclassified. Rides ExtractorEpoch 44 (wave tl's bump, not yet shipped when fixed)
- **Status:** fixed — wave tl audit, 2026-10-01
- **Impact:** one spurious `ComposeFile` symbol per non-compose YAML with a top-level `services:` list; no service, reference or cross-file edge comes from it
