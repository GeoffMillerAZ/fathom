### O303 — a tag-only push re-runs the full pre-push gate

- **Symptom:** a tag-only push re-runs the full pre-push gate
- **Evidence:**
  - **Tool:** lefthook pre-push (lefthook.yml validate and verify)
  - **Expected:** a push that carries no commit new to the remote (a tag on a commit the remote holds, a delete) skips validate and verify
  - **Actual:** the full validate and the scratch-ingest verify ran for a tag push; lefthook 1.13.6 also deadlocks when two commands set use_stdin
  - **Repro:** git push origin <tag> after the commit was pushed: scripts/prepush-refs_test.sh
- **Root cause:** validate and verify ran whatever refs a push carried; a second `use_stdin: true` command deadlocks lefthook 1.13.6, so validate could not read the refs itself
- **Fix:** verify (the one stdin reader, `priority: 1`) runs `scripts/prepush-refs.sh decide` and leaves a marker naming HEAD, valid for an hour; validate asks `scripts/prepush-refs.sh skipped`. A push skips only when every ref is a delete or a tag whose commit a remote-tracking ref already holds; `scripts/prepush-refs_test.sh` runs in scripts-check
- **Status:** fixed (a1083d0f, no row)
- **Impact:** a full validate and scratch-ingest verify for a push that carries no new commit
