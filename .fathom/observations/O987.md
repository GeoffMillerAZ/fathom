### O987 — An injection host with no imports query of its own was no file-resolve language

- **Symptom:** with F2's `injection_host` on, an Astro page's frontmatter imports were in its file specs (`ExtractFileSpecs`) but ingest stored no file-resolved edge for any `.astro` file.
- **Evidence:** `extractor.FileResolveLangs` skipped a tags dialect whose manifest names no `queries.imports`, and an Astro template has no import syntax of its own, so astro never ran in the file-resolve pass; `TestIngest_AstroDialect` was red until the rule changed.
- **Root cause:** F2 requires a host's `imports` block (its ranges' specs resolve under its strategy) but FileResolveLangs still keyed on the query.
- **Fix:** LB-F545: a host is a file-resolve language by its strategy alone (internal/extractor/fileresolvelangs.go, one condition); `TestFileResolveLangsIncludesInjectionHost`.
- **Status:** fixed (wave lf7, item angularastro)
- **Impact:** Vue and Svelte hosts without an imports query of their own need the same; the condition covers every host.
