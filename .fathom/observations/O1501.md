### O1501 — A .fathom/modules.cue binding to a module the daemon does not mount produces no note when the daemon runs with no --module: obligations answers "no governing rule" with no module_notes

- **Symptom:** A .fathom/modules.cue binding to a module the daemon does not mount produces no note when the daemon runs with no --module: obligations answers "no governing rule" with no module_notes
- **Evidence:**
  - **Tool:** obligations (module bindings)
  - **Expected:** An unmounted binding is disclosed on every daemon, as docs/use-cases/platform-modules.md says it is
  - **Actual:** internal/mcp/semantic_tools.go:1143 runs the binding only when modules != nil, so the note fires only when at least one other module is mounted; only fathom doctor (binding_modules_mounted, cmd/fathom/doctor_phaseo.go:131-166) reports it
  - **Repro:** Add a modules.cue binding to a fixture repo, serve it with no --module, call obligations on a bound path, and compare with the same call on a daemon that mounts any one module
