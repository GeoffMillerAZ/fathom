### O735 — React Router routes the route seam cannot carry: imported path constants and lazy modules

- **Symptom:** bulletproof-react's router stores 1 of its 9 route paths (the splat) and binds none; a `lazy: () => import('./x')` route is named `Component` (React Router's convention), and a lazy module exporting `element` instead is unnamed
- **Evidence:** `docs/bench/readings/routes/react-router.json`: bulletproof-react route recall .1111, bound 0 of 10 (every path is `paths.app.users.path` from `@/config/paths`); ssr-data-router `GET /lazy Component` where React Router renders `LazyPage`; lazy-loading names a `React.lazy` element by its binding (About) where React Router renders the module's function (AboutPage)
- **Root cause:** a reader reads one file (`Reader.Read(path, src)`), so a constant or a component another file defines is unknown to it, and `Route` has a handler name but no handler file
- **Fix:** proposed (route seam, registry.go/compose.go, not this item's): a route's handler module (`Route.HandlerFile`, joined like a Mount target) and a cross-file string-constant pass Compose applies, the way it applies mounts
- **Status:** open
- **Impact:** apps that centralize route paths in a config module, and lazy routes, whose binding to code is by convention only
