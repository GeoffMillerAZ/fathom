### O1335 — line-pinned fixtures turn one line's text move into another line's red gate

- **Symptom:** Gate run 1 went red on `TestHomeCorpusTruthAtHead` or `TestGuardsCorpusDetectorsExist` three times in 10 days (`iv2r-1`, `rc1-2`, `rel16-1`) because ADR.md or AGENTS.md lines moved under bench corpora that cite lines.
- **Evidence:**
  - **Tool:** the wave gate logs `gate-ext/{iv2r-1,rc1-2,rel16-1}.log` (outside the repository)
  - **Expected:** an edit to a doc does not break a fixture authored by another line
  - **Actual:** `H1-T07: token "ADR.md#L723" must cite line 728` and `ADR.md line 576 is neither ... nor inside the ADR-014 section`
  - **Repro:** add 5 lines above ADR-018 and run the gate
- **Root cause:** fixtures pin absolute line numbers of a file many lines edit.
- **Fix:** `task fixtures:repin` after the move (known). Anchoring pins by heading would remove the class; not proposed here.
- **Status:** open
