### O1102 — every ingest of fathom itself printed ~130 "discovery gap" stderr lines and doctor WARNed, for files the repo's own .fathomignore excludes

- **Symptom:** after dist1 made third_party/agentic-kit and third_party/app-kit in-module packages, each ingest printed `fusion: typed-edge pass "fathom": discovery gap — third_party/...` once per file, and `fathom doctor`'s typed row WARNed `N discovery gap(s)`.
- **Evidence:**
  - **Tool:** internal/fusion/typedcalls.go (`resolveFileEdges` targetAllowed, the discoveryGapFiles loop), cmd/fathom/doctor_typed.go checkTypedEdges
  - **Expected:** a file excluded by a declared policy is an intended exclusion, silent
  - **Actual:** any dropped target that exists on disk was a gap; `.fathomignore:9` (`third_party/`) is the declared policy
- **Root cause:** DG-9's gap test was "excluded from allowed and exists on disk", blind to why it was excluded.
- **Fix:** `declaredExclusion` (skip-dir segment, default cache-dir segment, .fathomignore match) classifies the file; it counts in `TypedEdgeReport.PolicyExcluded`, prints nothing, and is not a `DiscoveryGaps`. `EdgesDroppedOutOfScope` still counts the drop. An exclusion with no declared reason stays a gap. No stored edge changes; doctor reads DiscoveryGaps, so it no longer WARNs.
- **Status:** fixed
