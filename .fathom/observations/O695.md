### O695 — the route seam stops short of three Node shapes: route: keys are not composed, Nest's exclude and default version, recursive directory mounts

- **Symptom:** (1) a route behind an Express `app.use('/api', router)` in another file, or a Nest global prefix, is composed for service_ref joins and inventory items but keyed at its local path as a `route:` provides row; (2) `app.setGlobalPrefix('api', { exclude: [...] })` and `app.enableVersioning({ defaultVersion: '1' })` in `main.ts` cannot be written as a `Mount`; (3) `@fastify/autoload` mounts a routes directory recursively, with each folder as a prefix, while a directory `Mount` target names only the files directly inside it
- **Evidence:** `internal/syslink/route.go` `routeProvides` keys `routes.Extract` per file (no `Compose`); `TestServiceRefs_NoMountRowLeaks` asserts only that no MOUNT row leaks into a key. `routes.Mount{Prefix, Target, File, Line}` has no exclusion or condition; `compose.go` `resolvePath` matches `stdpath.Dir(f) == p`. Wave c2 item node works around (3) in its own reader (a route plugin under `routes/` reads its folders as its prefix, LB-F327) and leaves (2) unread (no corpus uses it: nestjs/nest's 29 samples have one global prefix, no exclude, no versioning)
- **Root cause:** the seam composes at read time for joins (`RoutesFromRows`) and inventory, but syslink's key sources are per-file by contract; Mount carries a prefix only
- **Fix:** seam change requests to item java and the integrator, none made here (seam files are not this item's): compose a service's route rows before keying `route:` provides (or key from `RoutesFromRows`); a `Mount` that skips listed paths (`Exclude`) and a default-version mount that applies only to routes no version claims; an optional recursive directory target that joins each folder name to the prefix
- **Status:** open (requests)
- **Impact:** a Node service's mounted routes join client calls (BuildFromStore) but its `route:` keys still name local paths, so a contract join on `route:` misses them; Nest apps that exclude routes from the global prefix or rely on a default version read wrong paths for those routes
