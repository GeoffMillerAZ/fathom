### O980 — A bare use of an imported component bound the one definition its script held

- **Symptom:** `import ElButton from './components/Button.vue'` with `<ElButton />` drew App.vue's module symbol to `Button.vue.props`, the one top-level definition of Button.vue's `<script setup>`.
- **Evidence:** `TestIngest_VueAndSvelteComponents`, first run: `web::src/App.vue.<module> -> web::src/components/Button.vue.props`.
- **Root cause:** the file resolver binds a whole-module import used bare to the target's default export, then its definition of the bound name, then its sole definition; a component file had no default export, and its module symbol is no name of its scope (K18).
- **Fix:** F2d (`c6dc5ee4`): an injection host's default export is its module symbol (`hostDefaultExport`), which the export index binds through the resolver's module symbols (`moduleOf`).
- **Status:** fixed
- **Impact:** an Astro component (angularastro) gets the same binding through the same patch.
