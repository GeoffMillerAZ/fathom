### O792 — a zsh script is not read as bash: tree-sitter-bash leaves an ERROR node in 54% of zsh files

- **Symptom:** D4 (O756) sends an extensionless script to the dialect whose manifest names its `#!` interpreter; `#!/bin/zsh` and `#!/usr/bin/env zsh` scripts are common (dotfile installers, git hooks), and the brief asked whether zsh joins bash's `match.shebangs`
- **Evidence:** ohmyzsh/ohmyzsh 42a4ccb1 (MIT), every `.zsh` and `.zsh-theme` file and every extensionless file whose shebang names zsh: 541 files, 291 with an ERROR node under the bash dialect's grammar (tree-sitter-bash v0.25.1, the reading's own `filesWithError` probe), 53.8%; the kill line for a dialect's files is 5% (§14.2)
- **Root cause:** zsh is not Bash: parameter-expansion flags (`${(j:,:)arr}`, `${(%):-%n}`), glob qualifiers (`*(.N)`), `always` blocks and anonymous functions are no Bash syntax, and the grammar recovers with an ERROR node
- **Fix:** none here. zsh is NOT added to the bash manifest's shebangs: a zsh script stays unextracted, exactly as before D4, and is disclosed (docs/languages.md, F.56)
- **Re-measured (wave lf6, LB-F454, docs/bench/readings/lang/zsh-grammars.md):** every maintained zsh-capable tree-sitter grammar with an OSI licence read at its pin, on ohmyzsh 42a4ccb1's 388 `.zsh` and 8 zsh-shebang files (tree-sitter CLI 0.27.0; tree-sitter-bash reproduces this entry's 291 over its set): tree-sitter-bash v0.25.1 66.4%, georgeharker/tree-sitter-zsh v0.63.5 15.9%, zchee/tree-sitter-zsh 895890f6 16.7%, jasonyukr/tree-sitter-zsh 00f0e37e 40.9%; on an alternative set pinned before its reading (zsh-autosuggestions, zsh-syntax-highlighting, powerlevel10k, prezto; 371 files) 21.3%, 10.5%, 10.5%, 92.7%. None passes 5%, so nothing routes `.zsh`, `.ksh` or their shebangs; LB-F454 is `[-]`.
- **Status:** closed (measured ceiling). Trigger: a zsh grammar (or a tree-sitter-bash release parsing zsh's expansion flags) under 5% ERROR on the same corpus, then a zsh dialect or `"zsh"` in bash's shebangs, an ExtractorEpoch bump
- **Impact:** a repository's zsh scripts (with or without `.zsh`) are not in the index; perl, tcl and other interpreters no manifest declares are not either
