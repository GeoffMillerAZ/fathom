### O1453 — A bare plan anchor that two packages define passes symbol_present naming one of them, then fails test_reaches with "no Test* statically reaches it" and never says it is ambiguous

- **Symptom:** a plan row anchored at a bare symbol (`symbol: RunConformance`, no `package:`) verifies until another package adds a symbol with the same name. Then `symbol_present` passes and names whichever match came first, and `test_reaches` fails `no Test* statically reaches it` (label `present-but-untested`) on a function six tests reach. Adopters filed 3 reports between 2026-08-13 and 2026-09-29 (theme T10 in docs/bench/readings/feedback/adopter-triage-2026-10-20.md).
- **Evidence:**
  - **Reports:** agentic-kit O5 (the RunConformance case above; the root cause it suspects matches the code). Adopter repository B O6 ("A method name collision silently leaves reachable_from unwired") and O9 ("a package-level symbol added anywhere in the fleet silently voids a reachable_from edge"; B's fifth occurrence of the class).
  - **Code:** in `verifyTask` (internal/verify/verify.go), `querySym` is replaced by the canonical key only when exactly one distinct key remains after the `package:` filter. Otherwise the bare name stays, and "ambiguity resolves to nothing downstream". `symbol_present` then passes with `matches[0]`'s file and line, and `test_reaches` runs `TestReachesDetail(querySym)` on the bare name and finds nothing. The `package:` filter (9a07d1236, 2026-07-15; exact-directory since PC-32) fixes a row that names its package. A bare row gets no ambiguity signal.
- **Root cause:** the ambiguity is resolved silently in two different ways, first-match for presence and nothing for reach. The failure then reads as a missing test, not as a missing `package:`.
- **Fix:** proposed, not built (small). When a bare anchor matches more than one distinct code key and the row has no `package:`, fail `symbol_present` with `ambiguous: N definitions (pkg1, pkg2, …); add package:` under its own label, and mark `test_reaches` and `edge_wired` n/a. A row that passes today is unaffected, because an ambiguous bare row already fails `test_reaches`.
- **Status:** fixed (1dc59cfc7). Answers agentic-kit O5 and adopter repository B O6, O9.
- **Impact:** a proven row turns into a false "untested" whenever any package adds a same-named symbol. Authors chase a test gap that does not exist.
