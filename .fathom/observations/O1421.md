### O1421 — calibration/clone.sh dies on a malformed shard it does not own

- **Symptom:** `bash calibration/clone.sh prisma` exits `bad file '.../calibration/corpus.d/html.yaml': yaml: line 40, column 15: mapping values are not allowed in this context` before it reads the prisma shard, so one broken shard blocks every item's clone.
- **Evidence:**
  - **Tool:** `bash calibration/clone.sh prisma` at 801476ad
  - **Tool:** `calibration/corpus.d/html.yaml` line 40, a plain scalar list item containing `: ` inside a folded `idioms` entry
- **Root cause:** the script parses every shard, not only the filtered one.
- **Fix:** worked around with `CALIBRATION_SHARDS=<dir holding only prisma.yaml>`. The html shard is another item's file and was not touched. Parsing only the filtered shard would also stop one item's typo from stalling the rest.
- **Status:** open
