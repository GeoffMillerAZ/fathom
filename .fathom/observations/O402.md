### O402 — the doc-xref pass joins doc-engine files only, so a Serverless handler, a CDK app's entry program and a Pulumi project's main cannot be stored edges

- **Symptom:** serverless, aws-cdk and pulumi-yaml stop at L2: their L3 references name source files (src/handler.main, bin/app.ts, a program directory)
- **Evidence:**
  - **Tool:** `indexbench lang-oracle` for serverless (serverless print 3.40.0), aws-cdk (cdk context 2.1144.0), pulumi-yaml (reference parse)
  - **Expected:** a manifest's cross_file reference to a program file draws a file-level edge
  - **Actual:** ResolveDocXrefs only joins a target that is itself a doc-engine document
  - **Repro:** TestIngest_AppFrameworkRepo: the handler and cdk entry appear as references, never as file-resolved edges
- **Root cause:** docxref.go keys its join on doc-engine nodes; a non-doc file has none to bind
- **Fix:** none here (docxref.go is outside wave iac); LB-Q-serverless-rest, LB-Q-aws-cdk-rest and LB-Q-pulumi-yaml-rest carry the trigger
- **Status:** open
- **Impact:** three app-framework dialects cannot reach L3
