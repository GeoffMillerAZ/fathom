### O468 — C file-edge precision .9368 leaves 259 false file pairs: 86 end in a platform header the build does not include and 143 in a .c a prototype binding chose

- **Symptom:** after scoping file edges to callers on active lines (LB-F194) and drawing reference edges (LB-F196), libuv and curl pooled file_edge_precision reads .9368 (3,837 of 4,096 edges agree; 259 false file pairs); the false pairs are not noise but two mechanisms
- **Evidence:**
  - **Tool:** `indexbench lang-oracle -dialect c -scip -scip-defs -tool-oracle <preproc>` on libuv v1.53.0 and curl 8.22.0 (scip-clang 0.4.0, compile databases at `<subject>/build`), fathom branch ld-xfile; every fathom edge pair absent from the index's truth listed with its caller, target file and target kind in a scratch dump (not committed)
  - **Expected:** a header the build's preprocessor never enters (an `#if defined(__VMS)` branch) draws no edge
  - **Actual:** 116 pairs end in a header, 143 in a .c file; of the 116, 86 end in a platform header: lib/setup-vms.h 36, lib/config-os400.h 17, lib/config-win32.h 10, lib/setup-win32.h 8, lib/setup-os400.h 7, include/uv/win.h 5, lib/config-mac.h 3 (a macro such as `SSIZE_MAX`, `SIGKILL` or `getenv` the header defines for its own platform, referenced from a file that includes it only under `#ifdef`); the other 30 are scattered (include/curl/system.h 6: `curl_off_t`, a typedef the build selects from another branch)
  - **Repro:** the commands in calibration/oracles/scip-clang/README.md with a dump of the pairs `ScoreFileEdges` does not find in the truth
- **Root cause:** the include graph is built from every `#include` line, conditional or not (`includeClosure`), so a name defined in a header reached only under an inactive `#if` binds; the 143 .c pairs are call edges through a header prototype (LB-Q-c-rest O281) whose index edge ends in another file, not isolated per edge
- **Fix:** open: follow an `#include` only when the build's preprocessor kept its line (the oracle's active_lines are the harness's, not the resolver's: it would need the compile database's -D flags evaluated against `#if` conditions)
- **Status:** open
- **Impact:** bounds C file_edge_precision at about .94 on these subjects; L3 stays good (.90 bar for good), not excellent (.95)
