### O591 — scip-dotnet cannot judge 17.7% of fathom's C# call pairs; the C# compiler's semantic model judges all but 2

- **Symptom:** C# L2 claimed no level: 6,441 of 36,400 fathom call pairs (17.7%) sat at sites scip-dotnet 0.2.14 writes no occurrence for, over LB-F203's 10% cap (wave lh, O464)
- **Evidence:**
  - **Tool:** `calibration/oracles/roslyn` calls mode (Microsoft.CodeAnalysis 5.9.0, MSBuildWorkspace over every target framework of the restored projects) beside the scip-dotnet index in `indexbench lang-oracle -dialect csharp`, on Polly 8.8.0 (53 project configurations) and Newtonsoft.Json 13.0.4 (21), wave lf1
  - **Expected:** an oracle that binds every written call: a generic method called with type arguments, a delegate invoked, a local function, an extension method, a construction
  - **Actual:** scip-dotnet writes no occurrence for a generic method called with explicit type arguments (`Policy.Handle<T>()`, O271), references the variable where a delegate is invoked (`callback(x)`), and indexes one target framework; the compiler binds 78,427 call sites: static 21,920, member 16,470, new 14,091, extension 13,193, generic 6,133, bare 5,413, delegate 1,050, local_function 108, event 20, unresolved 29; 8,879 inside a lambda (each the call of the definition around it, D5), and 219 LINQ query clauses that write no invocation
  - **Repro:** `docs/bench/readings/lang/csharp.json` (`csharp_compiler_*` counts and the subject notes); calibration/oracles/roslyn/README.md
- **Root cause:** an index that resolves one configuration and names a construction by its type is not a call-site oracle for C#
- **Fix:** LB-F287: a call the compiler binds is in the truth with or without an index reference (7,238 pairs added, 1,598 constructions); a fathom pair written only where the compiler binds nothing in any configuration (23) or only in `#if` branches none keeps (69) is left out of both counts; the compiler judges before the oracle-blind rule, which then holds 2 pairs (Polly 1, Newtonsoft.Json 1)
- **Status:** fixed (wave lf1)
- **Impact:** call_recall .9448 to .997 and call_precision .794 to .9997. The 143 truth pairs fathom misses: 99 index references at no compiler site (a method group passed as a value), member 12, extension 10, bare 7, new 5, static 5, other 5; the 14 fathom-only pairs: `new T()` of a type parameter (12, `TException`, `T`), 2 others
