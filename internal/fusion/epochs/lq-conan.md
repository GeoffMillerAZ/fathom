Lane conan (LB-Q-conan, L3; renumber at integration). The conan dialect names the global-name import strategy (scope service, defines recipe) and an `imports.scm`: every requirement a recipe writes (a class attribute in any spelling, `self.requires` and its siblings) is an import spec whose name is the reference cut at its `/`, and ingest stores a file-resolved edge from the recipe to the one recipe of the service that declares that name. Every `conanfile.py` fingerprinted before holds no import specs and draws none of these edges.
