Lane cuda (LB-Q-cuda; renumber at integration). CUDA files (`.cu`, `.cuh`) read through the new cuda tree-sitter dialect, C++'s queries over tree-sitter-cuda with the `cuda-macros` pre-parse step (`__align__(N)` and explicit instantiations blanked, `typeid` read as `sizeof`, then the C++ step, at equal byte length and only for a file that does not parse as written); `#include` resolves by include-path. Before, both extensions were an unsupported language and held no symbols, so every such file fingerprinted before holds the old extraction.
