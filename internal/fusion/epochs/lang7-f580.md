Wave lang7, item f580 (LB-F580, LB-Q-graphql, LB-Q-prisma). The file resolver gains the global-name import strategy: a GraphQL type reference binds the one file of the service defining a type of that name, a Prisma field's type the one file of its schema folder defining that model, view, composite type or enum. GraphQL and Prisma files now carry their type references as import specs (one per distinct name per file) in their file_imports rows and get file-resolved edges, so a store that read them before re-reads them once.
