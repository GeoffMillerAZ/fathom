A Prometheus rules file and an Alertmanager configuration, read alone or embedded in a Kubernetes object, now store the facts their dialects' doc specs declare as `EntityFact` observations of the entity's own file (WAE-4, ADR-069): a rule's labels, a route's receiver and continue, named `<entity>#<key>` and signed with the value as written, at the fact's line, in the entity's package. The bump re-extracts every file once; only Prometheus rule and Alertmanager files, standalone or embedded in a Kubernetes object, gain rows.
