Wave lang6, item objc (LB-Q-objective-c). The tags engine can name a definition or a call by a run of `@name.part` captures joined with a colon (an Objective-C selector `initWithFrame:style:`), keeping the longest match over one node, and a manifest can name the `objc-macros` pre-parse step; neither changes a dialect that does not use them. The header router gains an Objective-C leg, so a `.h` with an `@interface`, `@protocol`, `@implementation` or `#import` (and, for a bare `#import`, no C++ signal) is read by the Objective-C dialect instead of C or C++, and the file resolver reads `.m` and `.h` files of that dialect: a `.h` fingerprinted before under C or C++ is re-read, and `.m` files MATLAB's sniff did not claim are now Objective-C symbols.
