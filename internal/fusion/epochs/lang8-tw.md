Wave lang8, item tailwind (LB-Q-tailwind). A `.css` file that carries a Tailwind CSS v4 at-rule (`@theme`, `@utility`, `@custom-variant`, `@variant`, `@apply`, `@source`, `@plugin` or `@config`) is read by the css dialect's Tailwind variant: an `@theme` variable is a TailwindTheme symbol (it was a CSSCustomProperty), `@utility` and `@custom-variant` names are TailwindUtility and TailwindVariant symbols, an `@apply` candidate is a call of the utility it names (variants and `!` stripped), and the v4 spellings the grammar rejects are blanked before the parse so the rule after an `@custom-variant name (selector);` is no longer swallowed into an ERROR node. A plain stylesheet is read as before. Every `.css` file fingerprinted before that holds an at-rule named above holds the old symbols and calls.
