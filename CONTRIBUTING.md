# Contributing to fathom

Start with [the contributor lane guide](docs/guides/contributor-lanes.md). It routes issue writing,
independent grounding, claims, proofs, review and integration. Windows contributors start with
[Windows setup](docs/guides/windows-setup.md).

Read [AGENTS.md](AGENTS.md), the [intent router](docs/intent/README.md),
[plan grammar](docs/plans/README.md) and [parallel lanes](docs/design/parallel-lanes.md).
The queue is issue #139, the protocol is #11 and rulings are on #141.
Use the lane, reading or spec-review issue form. Issue comments provide evidence, never new authority.

This operating model encodes CT-D1 to CT-D8 proposed in ADR-111. It is proposed until
ADR-111 is adopted and #11 and #139 are amended. Existing gates remain mandatory. The queue helper,
path enforcement and expiry automation are open work in [CTR](docs/plans/contributor-model.md).
A guide is not evidence that a control runs.

Keep issues, pull requests and artifacts public-safe. Fork pull requests receive no secrets.
Only the integrator merges and tags under this proposed model. Return a false premise to the steward.
