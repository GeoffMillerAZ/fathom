The headline mechanism: one ranked query returns the code, its callers, and the governing design-doc section together. This is the cost that used to be paid repeatedly — by the architect and again by every worker.

Both M18 waves were planned entirely from index queries (M18.1: 6 calls + 3 targeted reads; M18.2: 2 calls + 4 reads). The Explore tier didn’t shrink — it disappeared. Caveat in our favor: Explore-agent token usage was never recorded in transcripts, so “before” bars elsewhere understate the true baseline.

Workers given pre-packed briefs (architect recon shipped verbatim in the prompt) act instead of wandering: fewer, larger, better-aimed tool calls at similar total token size.

Dispatch-to-verified-commit time roughly halved. Same rigor on both sides: adversarial architect review, both-edition builds, full validate gate, live browser verification.

Honesty chart: per-wave worker totals drop ~35–50% (incl. estimated Explore overhead), not 10×. Reading files you’re about to edit and writing code are irreducible. The 10×–100× wins live in the discovery layer (chart 1) and in architect-side recon.

Context only — the eras differ in scope (the “before” period includes large audit/review agents). Shown because the totals are real; not claimed as a controlled comparison.

Dogfooding found 8 sextant defects on day one (dead MCP queries, always-empty cross-repo callers, 6 KB staleness bloat per query, index pollution, missing Templ extractor…). All fixed and committed same day — owning the tool is itself a measured advantage.
