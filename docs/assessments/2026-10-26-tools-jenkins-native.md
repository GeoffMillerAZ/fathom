# Jenkins has an available native model; full L1/L2 comparison remains unmeasured

**Measured:** Jenkins's own Declarative Converter accepts all 23 existing
canonical L1/L2 inputs in a pinned private controller. The earlier assertion
that there is no offline evaluator is false. Its positioned ModelAST is an
available route. This audit does not equate model nodes with dialect definitions
or grant a tier from an unbuilt comparator. The canonical
[reading](../bench/readings/lang/jenkinsfile.json) remains unchanged, including
163/163 definitions and 133/133 local pairs under the existing tier-C walk.
L3 remains held for D19; no ENGINE, epoch or corpus change is made.

**Measured population:** the existing examples pin contributes 22 declarative
sources / 16,994 bytes, the library pin one / 407. Criteria and pins are in
[native-protocol-r1.json](../../calibration/oracles/jenkinsfile/native-protocol-r1.json),
fixed before native measurement. No holdout, new canonical subject or
extractor-selected subset enters this audit.

**Measured:** core 2.568.3, Declarative 2.2293.v6e7193cec599 (MIT at source
6e7193cec599b402ee79ee9afc5b8a417eb43967), Temurin 21.0.13+9 and 50 plugin
archives are hash-pinned in the [bundle](../../calibration/oracles/jenkinsfile/native-bundle-r1.json).
The minimum dependency set accepted 16/23; adding Docker-agent and timestamp
parser descriptors accepted 21/23. Declaring the three tool names Jenkins's own
remaining errors requested accepted 23/23. These are private declaration-only
slots, not installed build tools. No subject job/pipeline or Docker command ran;
the HTTP and HTTPS listeners were disabled. No global installation was made.

**Measured:** all six unpositioned nodes are ModelASTKey. Three
ModelASTScriptBlock nodes are opaque bodies in the direct Declarative model.
Native nodes include arguments, keys and default branches; they are not the
canonical declaration/caller ownership units. **Unmeasured:** a complete mapping
from every native node and canonical definition/pair, including full ranges,
opaque script calls and written-versus-default sections. This is available
remaining work, not an absent-tool ceiling or a new tier-A recall denominator.
The full target remains open in LB-Q-jenkinsfile-rest.

**Measured controls:** four authored sources yield two parsed models, one syntax
refusal and one no_pipeline. The non-pipeline source's top-level write marker
was absent after the run. Changing one authored stage name changes the owner
model; replacing only that name makes the remaining trees equal. Fathom output
is never an instrument input. Ten unit tests have zero skips; three mutants
ignore plugin drift, discard an unknown native field or truncate cap+1 inputs,
and each focused test fails before the restored GREEN run. Input 128+1 and
node 100,000+1 refuse whole receipts. Other declared caps (1 MiB per source,
8 MiB total, 32 MiB raw result, 180 seconds and 768 MiB heap) are not separately
claimed as measured cap+1 controls. Throughput is unmeasured.

**Measured provenance:** the exact design section 13.3.1 before/after manifest
recipe reports unchanged hashes, zero symlinks/gitlinks and no untracked
subject changes. The examples' 25 tracked files / 18,490 bytes include three
metadata files / 1,496 bytes outside source discovery, reconciling to 22 /
16,994. The library reports one / 407. The counts/hashes-only
[measurement](../../calibration/oracles/jenkinsfile/native-measurement-r1.json)
records both subjects and trial populations. Raw models, subject file lists,
tool names and logs remain private. Measured SDKs, builds and subject clones
were deleted after measurement.

**Measured search:** [candidate-audit-r1.json](../../calibration/oracles/jenkinsfile/candidate-audit-r1.json)
records all five X-R4 source groups, query/access gaps, twelve named candidates,
versions/pins, licenses and dispositions. Jenkins's direct model is the measured
route. gvy really emits SCIP/LSIF, contrary to the earlier absence premise;
source at 91612342ad9d4dbb7681c9c99afad2edf680837a only exports class/method
definitions and explicitly leaves body visitation unimplemented. That is a
source-audited scope limit, not an executed indexer failure. Ordinary independent
Groovy servers/parsers stay C under P-T1. Runtime FlowGraphWalker/interceptor
and mock traces cover exercised paths, not the complete written pair population;
no subject execution or mocked trace is promoted to owner truth.

**Reproduction:** [NATIVE.md](../../calibration/oracles/jenkinsfile/NATIVE.md)
contains committed commands for pinned SDK preparation, unchanged-byte subject
staging, owner model runs, declaration-only slots, exact before/after manifests
and controls. The owner runs and identity checks were executed. The convenience
SDK downloader was written afterward and not independently redownloaded end to
end; the receipt discloses this limitation rather than asserting a second run.

Decisions applied: ADR-048/054/067, P-T1, T-R4 and X-R1 through X-R5; the new
LB-Q-jenkinsfile-rest records unbuilt mapping work. No new design decision or
model invocation applies. No plan box, canonical reading, tier or L3 result is
changed by this assessment.
