# Angular: R-R4 is spent, support remains refused

**Measured 2026-10-26.** The bounded R-R4 experiment did not establish independent excellent Angular support. Its canonical cohort reached 2/72 files with ERROR or MISSING, but the new ng-alain subject deferred all 55/55 owned templates on namespaced SVG selector context. There is no pooled accuracy or median-three throughput grade. The controller sustained the refusal and requested this ceiling-only branch. The experimental engine, grammar and dispatch remain unpublished in the local `refused/angular-r1` record.

This change updates the assessment and `LB-Q-angular-rest`; it ships no Angular implementation. [Aggregate evidence](data/angular-ceiling-2026-10-26.json) contains counts and hashes. The [candidate ledger](../bench/readings/lang/angular-grammar.md) names the measured routes and the required source searches. These are historical experiment results, not a reading of the implementation on this branch.

Angular Electron is pinned at `dcd546c8cf71da85e3d5869e351158207a677cc9` (Angular/LS 22.1.4, TypeScript 6.0.3); ng-alain at `58a5297f827fb15267ca9627059410d08363a714` (Angular/LS 22.2.0, TypeScript 6.0.3). ng-alain has no committed root lock, so its exact compiler toolchain and generated workspace dependency lock were disclosed before source access.

The general repairs covered literal ampersands in text, optional keyed reads and optional calls. Each had a pinned Angular compiler citation, a negative test and positive AST controls. The production baseline and candidate rebuilt byte-identically. No grammar or product was tuned after the new holdout result. An earlier probe stopped before parsing any template because tsserver selected the wrong config; the retained pre-grade failure had zero templates or candidates scored. A generic exact-config loader was tested before the single grading attempt.

## Scope rulings and the ceiling

R-R2 fixes the intended scope to external `templateUrl`-owned HTML, file-keyed template modules, selector/pipe uses at L2 and compiler-attested in-repository target truth at L3. Inline and external SVG templates are excluded. R-R3 states that **Angular templates have no import statements: `import_resolution` measures compiler-attested selector and pipe binding resolution**, at the unchanged 95% excellent bar. The namespaced SVG **selector context** failure occurs in SDK metadata; it is distinct from the external SVG-template exclusion.

This is the measured ceiling of the **authorized experiment**, not a claim that every technical repair or oracle is exhausted. The candidate ledger records both working independent compiler routes and unrun alternatives. R-R4 is spent, both new subjects are now spent, no holdout entered the canonical corpus, and no further repair or regrade is authorized without a new ruling and a fresh holdout frozen before tuning. `LB-Q-angular` remains open; `LB-Q-angular-rest` remains refused. The implementation remains the base branch's implementation.
