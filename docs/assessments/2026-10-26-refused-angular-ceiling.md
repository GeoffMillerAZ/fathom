# Angular: R-R4 is spent, support remains refused

**Measured 2026-10-26.** The bounded R-R4 experiment did not establish independent excellent Angular support. Its canonical cohort reached 2/72 files with ERROR or MISSING, but the new ng-alain subject deferred all 55/55 owned templates on namespaced SVG selector context. There is no pooled accuracy or median-three throughput grade. The controller sustained the refusal and requested this ceiling-only branch. The experimental engine, grammar and dispatch remain unpublished in the local `refused/angular-r1` record.

This change updates the assessment and `LB-Q-angular-rest`; it ships no Angular implementation. [Aggregate evidence](data/angular-ceiling-2026-10-26.json) contains counts and hashes. The [candidate ledger](../bench/readings/lang/angular-grammar.md) names the measured routes and the required source searches. These are historical experiment results, not a reading of the implementation on this branch.

## Scope rulings and the ceiling

The following are public summaries of the controller's binding rulings, recorded here on 2026-10-26. They do not depend on unpublished issue comments or local commit access.

- **R-R3:** Angular templates have no import statements. Measure `import_resolution` as correctly resolved, compiler-attested selector and pipe bindings, at the existing 95% excellent bar. Both the reading and assessment must state this meaning plainly so the metric cannot be mistaken for file imports.
- **R-R4:** Exactly one bounded P-R1 grammar cycle was authorized. ng-matero became spent tuning data. Before any repair, the lane had to commit a selection rule based on a public metric, exclude every already seen subject, and select and pin at least two new subjects. Every repair had to be general Angular template syntax, cite the compiler or specification and include a negative test. The new pooled holdout could be graded once. READY required strictly under 5% pooled files in error, canonical accuracy still excellent and every ENGINE finding fixed. Otherwise the lane had to finish the review fixes, keep Angular refused and record every failing syntax class with its count. No further cycle was authorized without a new ruling.

R-R2 fixes the intended scope to external `templateUrl`-owned HTML, file-keyed template modules, selector/pipe uses at L2 and compiler-attested in-repository target truth at L3. Inline and external SVG templates are excluded. The namespaced SVG **selector context** failure occurs in SDK metadata; it is distinct from the external SVG-template exclusion.

The frozen selection-record and search-snapshot hashes are retained in the aggregate evidence: 151 search results existed, 100 were inspected and the selected applications ranked 34 and 48. The rule, pins and repair were local commits, not public preregistration.

This is the measured ceiling of the **authorized experiment**, not a claim that every technical repair or oracle is exhausted. The candidate ledger records both working independent compiler routes and unrun alternatives. R-R4 is spent, both new subjects are now spent, no holdout entered the canonical corpus, and no further repair or regrade is authorized without a new ruling and a fresh holdout frozen before tuning. An upstream grammar commit or release that handles the six named syntax classes while keeping both pinned canonical subjects under 5%, or an implemented product adapter using Angular selector semantics without the namespaced-SVG context refusal, is an observable prompt to request another ruling. Neither observation itself authorizes a new cycle. `LB-Q-angular` remains open; `LB-Q-angular-rest` remains refused. The implementation remains the base branch's implementation.
