# Terraform two-hop calibration — 2026-10-26

**Measured:** the repaired doc-xref resolver finds all 3,528 native cross-file
references in the two unchanged Terraform subjects. The exact baseline binary
finds 2,147. On these subjects, L3 moves from good (0.6086 recall) to excellent
(1.0 recall), with precision 0.9940 to 0.9963. L1 and L2 remain excellent.
This is evidence for [GAP1-32](../plans/language-breadth.gap1.md) and the
existing LB-Q-terraform-rest limit. The measured result does not establish a
general Terraform module-registry or cloud-execution capability.

## Population and independent truth

**Measured:** the native oracle uses OpenTofu 1.13.0, `init -backend=false
-get=false`, `show -json -config`, and `graph -type=plan`. It runs every `.tf`
directory as a root (19 per subject), with a private provider mirror and
preseeded registry modules from exact Git commits. The completed before-phase
proof ran native plain `init` on all 38 roots. Preparation checked the scratch
`.tf` path set and bytes, removed all cached local records, and seeded only
root and exact pinned registry records. OpenTofu installed every local record;
no authored local `Dir` was consumed. When installing a local ancestor
invalidated a registry descendant, bounded retries kept native local records
and restored only missing pinned registry records and verified checkout
symlinks. A failed partial install never fed the oracle. Every key, version,
and source matched; relative local source spelling was compared with POSIX
path normalization (for example, `../../` and `../..`). Subject-local
destinations matched lexically. A local child under a pinned registry module
could use its physical checkout path instead of its cache symlink alias, but
only an equal resolved target passed. Native `Dir` values were never
rewritten. The before run recorded 179 native local agreements, including 20
registry-child physical aliases, and a native manifest hash per root. The
oracle never runs plan or apply. Its
environment has a cache-owned home and temporary directory, an explicit
allowlist, and dead proxies; it inherits no cloud credentials or user config.
Every root succeeded and every definition was located. A provider-free smoke
case proved that deleting a required preseeded module entry makes native init
fail, so a missing module cannot silently reduce the truth population.

whole-manifest tests accept each cap and reject cap+1; they do not trim a
manifest or silently continue. These are calibration preparation limits,
not product admission limits. The before-phase proof stayed within them and
retained the 3,528-edge truth set. The separate installer retry bound is 17
plain-init attempts (16 ancestors plus one completion pass); a pure test forces
every retry to restore a missing pinned link and proves whole-root refusal

## Verification and reproduction

**Measured mutation:** a Go overlay replaced the oracle's explicit `tofuEnv`
allowlist with `os.Environ()` plus the two Terraform paths. The focused
`TestTofuEnvIsolated` failed with `inherited AWS_ACCESS_KEY_ID` because that
credential variable entered the native process environment. Restoring the allowlist made the
oracle's race tests pass. The previous provider-free smoke confirmed that
`init -get=false` rejects a required manifest entry removed from the fixture.
The revised smoke additionally plants a wrong local `Dir` and requires
preflight to remove it before native init and oracle evaluation. The latest rerun passed with the final preflight and path-comparison rules.
No provider ran in the smoke case.

**Measured population mutation:** replacing `checkCompleteness`'s refusal
condition in `calibration/oracles/terraform/main.go` with `false` through a Go
overlay makes `go test -race -run '^TestCheckCompleteness$' -count=1 ./...`
in that nested module fail for zero roots, a failed root and an unlocated
definition (`error = <nil>, wantError true`). The overlay is removed for the
full nested-module race command below, which passes. This kills a mutant that
would accept a reduced native population.

Run the nested test suites from the repository root (the scanner is a separate
Go module). The 18 pure Python tests cover cap/depth refusal, native manifest
population and destinations, registry aliases, scratch-copy identity, and the
17-attempt whole-root refusal:

**Measured cap tests:** `test_module_instance_cap_accepts_511_and_rejects_512`

manifest at 512 calls. `test_module_depth_cap_accepts_15_and_rejects_16`
accepts 15 nested edges (16 ancestors including root) and refuses the whole
