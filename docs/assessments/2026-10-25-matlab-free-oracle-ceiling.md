# MATLAB: free-oracle ceiling

Assessment date: 2026-10-25. The [committed reading](../bench/readings/lang/matlab.json) remains the authority for support levels and measurements. This survey records why the reviewed free tools do not yet provide call and resolution truth for the unchanged corpus; no new oracle run is claimed. Decision: `LB-Q-matlab-rest`.

## Free oracle survey

- MISS_HIT 0.9.44, already installed locally and used by the L1 adapter, deliberately leaves `identifier(arguments)` as an ambiguous `Reference`. Its `m_ast.py` documentation says it could be array indexing or a function call and leaves semantic rewriting as a TODO. `m_parser.py` constructs definite `Function_Call` nodes for command syntax and shell escape syntax. The existing adapter emits definitions only. Counting all references as calls would use indexing expressions as truth.
- Source inspection of the full [MISS_HIT 0.9.44 package](https://pypi.org/project/miss-hit/0.9.44/) adds `m_sem.py`, but its `Semantic_Analysis_Pass_1` builds package and class scopes without resolving `Reference` into calls or indexing. That additional pass does not supply the missing oracle.
- The [tree-sitter-matlab v1.3.1 grammar](https://docs.rs/crate/tree-sitter-matlab/1.3.1) explicitly states that its `function_call` node includes matrix and cell indexing. A second tags query over those nodes does not resolve this ambiguity or independently prove call edges.
- [McLab Tamer](https://www.sable.mcgill.ca/mclab/projects/tamer/) is free Apache-2.0 source. Its typed analysis needs input descriptions, but a narrower input-type-free route exists: [SimpleFunctionCollection](https://github.com/Sable/mclab-core/blob/beeea16c1c79b3005f3c46363b8c49d1928a937b/languages/Natlab/src/natlab/tame/callgraph/SimpleFunctionCollection.java#L84-L97) constructs an entry-point-rooted graph from a file environment. At that exact source pin, `collect` [explicitly declines scripts and classdef](https://github.com/Sable/mclab-core/blob/beeea16c1c79b3005f3c46363b8c49d1928a937b/languages/Natlab/src/natlab/tame/callgraph/SimpleFunctionCollection.java#L148-L177), and [throws on unresolved function references](https://github.com/Sable/mclab-core/blob/beeea16c1c79b3005f3c46363b8c49d1928a937b/languages/Natlab/src/natlab/tame/callgraph/SimpleFunctionCollection.java#L205-L231). [StaticFunction](https://github.com/Sable/mclab-core/blob/beeea16c1c79b3005f3c46363b8c49d1928a937b/languages/Natlab/src/natlab/tame/callgraph/StaticFunction.java#L108-L126) uses variable-or-function analysis to map candidate callee names to references. This could grade a restricted function-only corpus, but the existing subjects include classdef and scripts. Dropping them would change the proof population. No McLab build, run, class crash reproduction, coverage percentage or call-pair reading is claimed.
- MATLAB's [requiredFilesAndProducts](https://www.mathworks.com/help/matlab/ref/matlab.codetools.requiredfilesandproducts.html) is a licensed dependency analyzer. Hosted MATLAB is a separate unapproved owner decision. Its file dependencies would still need to be graded as the L3 metric they actually report.
- MathWorks' [MATLAB-language-server](https://github.com/mathworks/MATLAB-language-server) is MIT-licensed, but its README requires MATLAB R2021b or later (read 2026-10-25). It does not remove that licensed dependency.
- GNU Octave is a free GPL interpreter, usable only as a separate process here. Its documented [profiler](https://docs.octave.org/latest/Profiling.html) reports executed calls rather than a static whole-corpus call dump; no suitable static oracle interface was identified in this survey (read 2026-10-25).

## Ceiling and retry

No free L2/L3 oracle has been run that distinguishes function calls from indexing over the unchanged corpus. Do not raise the reading, lower the target thresholds, or fabricate input types to produce call truth.

Retry on a free analyzer that covers classes, scripts and function resolution over the pinned subjects with an independent call dump, or approval and availability of MATLAB's own analyzer. McLab's restricted graph does not meet that condition. No oracle throughput or coverage is asserted here.
