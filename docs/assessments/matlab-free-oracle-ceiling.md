# MATLAB: evidence ceiling beyond L1

Assessment date: 2026-10-25. The existing reading is unchanged: L1 excellent, tier B, measured against MISS_HIT on three pinned subjects. L2 and L3 remain unattempted.

## Free oracle survey

- MISS_HIT 0.9.44, already installed locally and used by the L1 adapter, deliberately leaves `identifier(arguments)` as an ambiguous `Reference`. Its `m_ast.py` documentation says it could be array indexing or a function call and leaves semantic rewriting as a TODO. `m_parser.py` constructs definite `Function_Call` nodes for command syntax and shell escape syntax. The existing adapter emits definitions only. Counting all references as calls would use indexing expressions as truth.
- The [tree-sitter-matlab grammar](https://docs.rs/crate/tree-sitter-matlab/latest) explicitly states that its `function_call` node includes matrix and cell indexing. A second tags query over those nodes does not resolve this ambiguity or independently prove call edges.
- [McLab Tamer](https://www.sable.mcgill.ca/mclab/projects/tamer/) is free Apache-2.0 source. Its typed analysis needs input descriptions, but a narrower input-type-free route exists: [SimpleFunctionCollection](https://github.com/Sable/mclab-core/blob/beeea16c1c79b3005f3c46363b8c49d1928a937b/languages/Natlab/src/natlab/tame/callgraph/SimpleFunctionCollection.java#L84-L97) constructs a graph from a file environment. At that exact source pin, `collect` [explicitly declines scripts and classdef](https://github.com/Sable/mclab-core/blob/beeea16c1c79b3005f3c46363b8c49d1928a937b/languages/Natlab/src/natlab/tame/callgraph/SimpleFunctionCollection.java#L148-L177), and [throws on unresolved function references](https://github.com/Sable/mclab-core/blob/beeea16c1c79b3005f3c46363b8c49d1928a937b/languages/Natlab/src/natlab/tame/callgraph/SimpleFunctionCollection.java#L205-L231). [StaticFunction](https://github.com/Sable/mclab-core/blob/beeea16c1c79b3005f3c46363b8c49d1928a937b/languages/Natlab/src/natlab/tame/callgraph/StaticFunction.java#L108-L126) uses variable-or-function analysis to map candidate callee names to references. This could grade a restricted function-only corpus, but the existing subjects include classdef and scripts. Dropping them would change the proof population. No McLab build, run, class crash reproduction, coverage percentage or call-pair reading is claimed.
- MATLAB's [requiredFilesAndProducts](https://www.mathworks.com/help/matlab/ref/matlab.codetools.requiredfilesandproducts.html) is a licensed dependency analyzer. Hosted MATLAB is a separate unapproved owner decision. Its file dependencies would still need to be graded as the L3 metric they actually report.

## Ceiling and retry

Highest proven free level today: L1 excellent. No free L2/L3 oracle has been run that distinguishes function calls from indexing over the unchanged corpus. Do not raise the reading, lower the target thresholds, or fabricate input types to produce call truth.

Retry on a free analyzer that covers classes, scripts and function resolution over the pinned subjects with an independent call dump, or approval and availability of MATLAB's own analyzer. McLab's restricted graph does not meet that condition. No oracle throughput or coverage is asserted here.
