### Added

- `iac.ImportCatalog(iac.ImportRequest{...})` builds a provider contract catalog from a local `tofu providers schema -json` export or a CloudFormation registry schema zip and installs it in a directory, with the builder `fathom iac import` uses, so a library consumer needs no `fathom` binary. A catalog built from exports carries attributes, required, sensitive, deprecated and upgrade-impact facts and no replacement facts, and says so in its manifest (`replacement: "absent"`). An import into a directory that holds the same provider line merges, and a release with different content is refused unless `Replace` is set. `fathom-lang catalog import -dir DIR [-version V | -region R] INPUT...` prints the installed catalog as JSON. `Catalog.Contract` now reads a CloudFormation catalog: each property with required, read-only (`computed`), write-only and deprecated flags and a `Replacement` from the schema's `createOnlyProperties` and `conditionalCreateOnlyProperties`. A read-only property is `computed` and not `optional`. A nested create-only entry (`Tags[*].Key`) reads `required` or `optional` from its object's required list when the importer resolved that object, and states neither when it could not. Every nested entry, resolved or not, reads `write_only`, `deprecated` and `computed` from the schema's `writeOnlyProperties`, `deprecatedProperties` and `readOnlyProperties`: a flag on a property covers its members, and a `computed` entry is never `optional`.
