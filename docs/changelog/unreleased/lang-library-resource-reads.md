### Added

- `pkg/lang/iac` reads what Terraform and OpenTofu (`.tf`, `.tofu`, a directory as a module), CloudFormation and SAM templates (YAML or JSON) and Pulumi YAML declare: `iac.ReadFile(ctx, path, src)` and `iac.ReadModule(ctx, fsys, dir)` return each resource, data source or module call with its attributes, each attribute with a path, one of five classes (`literal`, `defaulted`, `reference`, `expression`, `unknown`), the references it reads and a span. `Value` is empty unless `iac.WithValues()` is passed, and the reader still withholds a sensitive, ephemeral, `NoEcho` or secret value. Both reads take a context and return by `iac.DefaultReadDeadline` (30 seconds, lowered by `iac.WithDeadline`, never raised) with `iac.ErrDeadline`, return `iac.ErrBusy` while `GOMAXPROCS` abandoned reads are running, and refuse a file over 2 MiB with `iac.ErrLimit`. A file no reader reads returns `*iac.NoReaderError`. The package links no store, fusion, connector, MCP server, `net/http` or CUE, and `TestIacClosure` and `TestLangNeverDialsOrWrites` hold that.
- `fathom-lang resources [-root DIR] [-module DIR] [-values] [-deadline D] [-max-memory SIZE] [-in-process] PATH...` prints `{"schema_version":1,"files":[{"path":...,"error":...,"result":...}]}` with the field names of `iac.ResourceSet`, reading in the supervised child `extract` uses: a file that hangs, overflows the stack or allocates without bound has an error that says why and a null result, the batch goes on, and the run exits 1. `-module DIR` reads a Terraform directory as a module. A value is printed only under `-values`, and never one the source marks secret.
- `iac.OpenCatalog(path)` validates a provider contract catalog an operator built (`fathom iac import` or `fathom iac add` made it), and `Catalog.Contract(source, version, type)` returns the type's attributes with type, required, optional, computed, sensitive and deprecated flags and any replacement fact with its provenance; `Catalog.Versions` lists the releases. Each lookup opens the zip, reads one version index and one blob, and closes it. `fathom-lang contract -catalog PATH [-source S] [-version V] [-kind K] [TYPE [ATTR]]` prints the same as JSON. A catalog carries no replacement facts until the Go source scan (IF-13) lands, and says so (`replacement_facts: "absent"`).
