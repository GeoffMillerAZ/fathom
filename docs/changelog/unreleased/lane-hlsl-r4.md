### Added

- HLSL (`.hlsl`, `.hlsli`, `.fxh`, and `.fx` files that look like shaders) extraction on tree-sitter-hlsl (the head of upstream pull request 82): functions, structs, cbuffers and tbuffers, typedefs, file-scope variables and macros, the calls a definition makes (intrinsics and member calls included; vector constructors and attributes are not calls) and `#include` imports. A cbuffer header's register clause, a file-scope binding macro with no semicolon and a statement split across `#if`/`#else` are read through an equal-length pre-parse step, so 18 of the 644 calibration files still hold a parse error. Measured against DXC's AST (tier B): L1 excellent, L2 good; L3 is not met, because file edges follow references rather than include statements. These extensions are no longer listed as unsupported languages.
