### Added

- With an IaC catalog installed (`fathom iac add|import`), `symbol_context` on a Terraform or OpenTofu resource or data source carries an `iac` block: the binding (`locked`, `constraint-matched`, `ambiguous` or `unbound`, with the provider source, the version, the lockfile roots and what to add when unbound), the required arguments the block leaves unset, the attributes it wrote with their flags (required, optional, computed, sensitive, deprecated) and the unknown or deprecated ones. `review_diff` carries an `iac` section for the changed `.tf` and `.tofu` files: an unknown attribute, a required argument unset, a deprecated attribute, and a sensitive value in an unmarked output, each citing its catalog, version, blob digest and JSON path, under the existing 16,000 byte response cap. An attribute of list or set of objects type written as blocks, static or `dynamic`, is accepted as OpenTofu accepts it (attributes as blocks); its members are not checked. A block whose provider is bound to no catalog version carries no facts and a disclosure, never a nearest version. A level that holds an attribute the reader gave class unknown is not checked for required arguments, and says so. With no catalog installed neither answer changes, and nothing is downloaded (ADR-091, IF-7 to IF-10).
