### Changed

- `Symbol.Signature` follows one fail-closed rule in the language library. In a code dialect every quoted literal reads `***`, whatever its name or its place and in the spelling of its language (a C# `@"..."`, a C++ `R"(...)"`, a Rust `r#"..."#`, a JS template with an escaped backtick, a Ruby `%(...)`). In any other dialect it is empty unless the symbol's `Kind` is one whose `Signature` is a keyword or a declared name, and then its literals read `***` too, so the text of a script, a default, a version and an image are not returned there (an image stays in `Reference.To`). A `Fact` value under a key that looks like a credential reads `***`, the userinfo of a URL is dropped with or without its scheme, and a `Note` carries a reason and a line, never the file's text. The library is not a secret scanner.
