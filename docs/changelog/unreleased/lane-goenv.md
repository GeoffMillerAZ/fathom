### Security

- The go commands fathom runs on its own (the typed pass at ingest and in the daemon, the daemon's toolchain shim, ask's module loads and the layer-rules import graph) now run offline with `GOPROXY=off`, `GOSUMDB=off`, `GOTELEMETRY=off` and `GOTOOLCHAIN=local`, and an inherited `-mod=mod` is dropped so `go list` never rewrites a repository's `go.mod` or `go.sum`. A dependency missing from the module cache now fails the typed pass with the module named and `run go mod download in <module dir>`, and the next ingest retries it.
- Migration: on a machine whose module cache lacks a repository's dependencies, run `go mod download` in each of its Go modules before ingest, or set `[ingest] go_network = true` in `~/.fathom/config.toml` (user scope only; a repository cannot set it) to let the typed pass download as before.
