### Added

- `Reader.Extract` returns by a deadline: `lang.DefaultReadDeadline` (30 seconds), which `WithLimits(Limits{ReadDeadline: d})` may lower and nothing raises. A read that overruns it returns `Incomplete` with one note naming the deadline and none of its facts. The parser is abandoned, not stopped, since Go cannot interrupt a goroutine: it keeps its CPU until it returns, and its result is discarded. Once `GOMAXPROCS` abandoned reads are still running, `Extract` starts nothing and returns `Skipped` `lang.SkipBusy` (`busy`) until they finish. `Close` does not wait for an abandoned parser. The deadline, the engine's own parse deadline and a grammar module's memory limit are the exceptions to byte-equal output.
- `fathom-lang extract` reads in a supervised child process by default. A file whose read passes the deadline and a margin, ends the child (a fatal stack overflow included) or takes it past `-max-memory` (4 GiB by default) reads `Incomplete` with a `read-killed:` note, and the batch goes on with the next file in a new child. `-deadline` lowers the read deadline and `-in-process` turns supervision off. A batch that faults nowhere prints the same JSON in both modes. `pkg/lang` itself starts no process.
- One HCL guard, `internal/hclbound`, serves the extractors and the stand-alone IaC reads, and its refusal names the bound that fired (tokens, nesting, template melding or a function name's segments). A template that holds a literal either side of an invalid `%{` directive, and a template that follows a `[*` splat whose close is a quote or a heredoc, are priced as the parser melds them, so they refuse as the plain shapes do.
