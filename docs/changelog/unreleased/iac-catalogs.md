### Added

- `fathom iac add|import|list|remove` manages IaC provider catalogs under `$FATHOM_HOME/iac`. `add` takes a local file only, verifies the whole catalog (every bound, every blob against its address, no duplicate or unknown entry) and prints its sha256; `import` builds a catalog from one provider's `tofu providers schema -json` export that you ran yourself, one major line per catalog, and merges into the catalog already installed for that line instead of replacing it (it lists what it added, kept, unchanged and replaced, and refuses a release with different content unless `--replace`). Nothing is downloaded and no provider is run (ADR-091, IF-1 to IF-5). A catalog holds every release of one provider major line and carries no replacement facts yet. No answer surface reads a catalog until the later rows land, so no existing answer changes.
