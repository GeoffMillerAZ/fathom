### Fixed
- `fathom doctor` judges the pre-push hook git actually runs, including in linked worktrees and submodules. When a project-owned hook is installed and `lefthook.yml` is not, the `lefthook_gates` row reads the hook (following `.tools/bin/task validate`) instead of failing on the unused `lefthook.yml`, and fails with `lefthook install` as the remedy when the installed hook reaches neither gate. If the strict verify step sits in a non-shell script such as Python, or the read budget runs out first, the row is `unknown` and says why. A hook that hands off with `lefthook run` still counts `lefthook.yml`.
