### Fixed
- The Go typed pass names every package and directory it does not resolve. Each skipped package gets one reason (test main, test-only, connector scope, build constraints, outside ./...), and the counts add up to the packages seen. Discovered Go directories that no module load covers are named with why (no go.mod, outside ./..., or a nested module not loaded, by its go.mod), also when the repository has no module at all. `fathom ingest` counts the skips on its typed-edges line and names those that lose typed edges on one more line; `--json` and the MCP `ingest` tool's `typed_edges` gain `packages_skipped`, `skipped` and `not_loaded` (the MCP tool when a typed pass ran: a tree with no module records no status). A "0 processed" failure now names its real reason counts instead of always blaming the connector scope filter.
- A Go package whose every file imports "C" is now resolved from its source and keeps its typed edges. TypedEdgeEpoch 8 re-runs the typed pass once for every stored Go service.
