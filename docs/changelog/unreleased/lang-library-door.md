### Added

- `pkg/lang` reads a file into symbols, references, refused references and declared facts without the rest of fathom: `lang.New`, `Reader.Extract` (a skipped file says why: binary, oversize, generated, ambiguous, unclassified or not-linked) and `Reader.Dialects`, each dialect with the level its reading measured. `Result.Incomplete` is true, with a one-line reason in `Notes`, when an engine could not fully read the file (a decode failure, or the memory or time budget a very large file spent). `Reference` has `To` (the target as the dialect names it), `ToKey` (the `Key` of the one same-file symbol it names), the edge the dialect declared and the line; `Symbol.Canonical` is set for every kind an extractor emits (Go, JSON and TOML included). `Reader.Dialects` lists only the dialects `Extract` reads, and the JSON and TOML files no dialect claims read as `generic-json` and `generic-toml`. `Extract` checks its context between a file's stages, and the engine's 10 second deadline is the one wall-clock input to a `Result`. `lang.EnableCompilationCache(dir)` is the one opt-in disk write. `fathom-lang extract|dialects` prints the same as JSON, with a `schema_version`, for tools not written in Go; PATH may be absolute, a file that cannot be read is a result of its own and the batch goes on, and misuse exits 2 (ADR-092, LL-10 to LL-12, LL-17).
- `Result.Incomplete` also covers the nginx, Caddy, HAProxy, Rego and go.mod and go.work readers (a repair or a rejected line), a Kubernetes manifest's embedded documents, and an injected `<script>` range that failed; a trailing empty YAML document is not an unread one. `Reference.Edge` reads `call` only for the Go, tree-sitter, templ, Rego and notebook readers and `reference` for every other engine's same-file edge. `Symbol.Canonical` reads `type` for a Go defined type (`type N int`), added to the closed vocabulary beside `type_alias` (`type A = B`). templ files read as dialect `templ`. A pack's kind table applies only to the files a pack read. `lang.EnableCompilationCache` also refuses a directory another user owns on unix.
