### Added

- `lang.WithDialects(fsys)` adds a dialect pack to a `Reader`: tags dialects over a grammar the library embeds, and doc dialects, as `dialects/<id>/dialect.json` with their queries and doc specs. A pack is merged with the built-in dialects, held to the same manifest and cross-dialect rules, compiled at `New` and refused whole as a `*lang.PackError` with a reason (`empty`, `manifest`, `conflict`, `engine`, `injections`, `grammar`, `query`, `container`, `claims`, `route`). A pack dialect is tried after the specific built-in dialects and before an extension's generic reader, in id order, and cannot take a file whose extension a built-in dialect owns, whatever its glob or basename claims. A pack is also refused whole for a glob that is not a pattern, an empty tags query, a tags capture of a kind the manifest does not declare, an extension variant whose own tags query does not compile or has no id, and any file in a dialect directory the manifest does not name. A pack or extractor dialect always reads `unmeasured`. `fathom-lang extract|dialects -pack DIR` reaches the same packs from tools not written in Go (ADR-092, LL-13).
- `lang.WithExtractor(match, e)` registers a Go extractor under the same routing and refusal rules. `pkg/lang/langtest.CheckPack` runs a pack's validation, goldens and required kinds. `pkg/lang/cue` (`cue.Option()`) links CUE and Timoni extraction, so `pkg/lang` itself links no `cuelang.org/go`: without it a `.cue` file reads `Skipped: not-linked` and `Reader.Dialects` leaves the CUE-family dialects out (LL-14 to LL-16).
