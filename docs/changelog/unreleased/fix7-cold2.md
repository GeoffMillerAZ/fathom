### Fixed
- `symbol_context` answers a name with more than one definition, or with none, at once instead of waiting for the call graph its answer never reads. After a daemon start, a service with no measured build answers the partial (`not computed (cold graph)`) at once while its build keeps running for the next call.
- `search` lets ripgrep read files in parallel instead of in path order, so a search over files no longer in the page cache answers about four times faster (2.3 s to 0.6 s on a 9,000-file repository); hits keep their path-then-line order, and a search stopped at the output cap still reads in path order.
