### Added

- Simulink models (`.slx`, `.mdl`) extraction at L2 (good), measured against an independent zipfile and expat walk (tier C) on WEC-Sim, Thermodynamics, LADAC, FMT-Model and etherlab-examples and cross-checked by data-explorer-core and miss-hit-core: every block by its full path, signal lines as references, model references to the model of that name (L3 deferred: the corpus holds too few resolvable model references). A `.slx` is read in memory under caps enforced while it reads (entries, inflated bytes, the real compression ratio, start-tag size and attributes, nesting depth, elements, blocks, value length, block-path length, and the bytes of block paths, signal endpoints and emitted calls per model), the one NUL-sniffed format a dialect may claim (ADR-021, amended); a malformed or hostile model reads as nothing, never a crash; a text-package `.mdl` is disclosed, not read.
