### Added

- `fathom iac import --region REGION <schemas.zip>` builds a CloudFormation catalog from a registry schema zip you fetched yourself (source `aws/cloudformation`, one catalog per region, keyed by a digest over the zip's entry names and bodies, which ignores the zip's embedded build time; the manifest keeps that build day as its date). The catalog carries each type's required, create-only, conditional create-only, read-only, write-only and deprecated properties, each from the schema field that states it, and no description prose. For a nested create-only property it also records whether its parent object requires it, when the schema resolves that object through definitions and `$ref`. A region holds one snapshot, so a new zip replaces the region's catalog and the result says whether the content changed. Nothing is downloaded and nothing derived from the schemas is shipped (ADR-091 amendment, IF-C1). `fathom iac list` and `add` read the new kind. `symbol_context` and `review_diff` read it for a CloudFormation template (see the CloudFormation answers note); with no catalog installed no answer changes.
