### Added

- `fathom iac import --region REGION <schemas.zip>` builds a CloudFormation catalog from a registry schema zip you fetched yourself (source `aws/cloudformation`, one catalog per region, keyed by a digest over the zip's entry names and bodies, which ignores the zip's embedded build time; the manifest keeps that build day as its date). The catalog carries each type's required, create-only, conditional create-only, read-only, write-only and deprecated properties, each from the schema field that states it, and no description prose. A region holds one snapshot, so a new zip replaces the region's catalog and the result says whether the content changed. Nothing is downloaded and nothing derived from the schemas is shipped (ADR-091 amendment, IF-C1). `fathom iac list` and `add` read the new kind. No answer surface reads it yet, so no existing answer changes.
