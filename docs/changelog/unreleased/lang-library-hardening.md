### Fixed

- The language library refuses a file inside the 2 MiB limit before a parser it cannot interrupt would overflow the stack or run in quadratic time, and the file reads `Incomplete` with the reason. Each guard counts what its parser is known to recurse on or spend time on: in HCL a run of `!`, `-`, `?` or `*` (also in a `{for ...}` expression, where the parser ignores newlines), the template directives a body leaves open, and more than 20,000 literal pieces in one template; in proto brackets, `-` and comments where a literal is expected, and more than 10,000 tokens in a row that no statement ends; in CUE the attribute scanner's own recursion and more than 10,000 lexical errors; in nginx and Caddyfile the parsers' own depth; and a dotted key or a four-quote string end in TOML. A shape no guard counts is not promised refused. A panic in a built-in extractor is now one file's `Incomplete` reading. A TOML document of more than 40,000 keys, a YAML mapping that repeats a key, an anchor that does, and a very wide YAML or document-engine mapping no longer cost quadratic time or memory, and a manifest of 40,000 TOML keys reads in seconds, not half a minute.
- A Helm template whose if/else branches repeat a key, and a notebook cell the Python reader cannot read within its budget, no longer vanish without a note: the first reads its workload, and both say what they could not read in `Notes`.
- A `Result` withholds the places a credential is found: the userinfo of a URL (never moving its host: an `@` after `?`, `#` or `/` is not userinfo, and the image of a `docker://` reference stays), every string literal bound to a name or a key in a parameter default, a rule value or a fact value, and a script's text, of which only the program is returned. A credential in any other place is returned as written.
- `DialectInfo.Engine` names what reads the dialect: CMake and proto read as `native`, not `tags`, and the `Result` documentation no longer calls SQL a line scanner.

### Changed

- `Symbol.Signature` of a symbol whose `Canonical` is `task` (a `package.json` or `composer.json` script) is the program the script runs, not its text. A string literal bound to a name in a parameter default or a rule is masked whatever the name is, where it was masked only for a credential-like name.
