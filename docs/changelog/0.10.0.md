# 0.10.0 — 2026-10-03 — the release that readied fathom for its first outside testers

The narrative record for `CHANGELOG.md`'s `[0.10.0]` block. Not normative;
plans, ADRs and observations are.

## What this release is for

Two things had to be true before fathom could be handed to someone who did
not build it. **One:** a stranger has to be able to install it, wire it and
know what to expect on the machine they have. `docs/early-testers.md` says
what to install, what works per language and tool format, and what does not
yet; cloud sessions (CS-1..CS-8) run fathom inside the VM of Claude Code on
the web and of Codex cloud, from one committed `scripts/cloud-setup.sh` and
one stdio front (`serve-mcp --url`), and `task test` passes on Linux as root.
**Two:** the index has to answer for more than calls. Reference edges (F-D)
make a type's or an identifier's consumers reach the file that defines it;
route, policy and Docker image edges make a Service, a policed object and a
Dockerfile reach what names them in `blast_radius`; and the generated
excellence board in `docs/languages.md` names, per tier, the level every
language and tool format meets against an independent oracle and the next gap.

Around those: the language breadth program (ADR-048) added CUE, Timoni,
Rego, Kyverno, Gatekeeper, the policy documents, Terragrunt and HCL tool
configs, the cloud templates, the GitOps and Ansible formats, the proxy
configurations, OpenAPI, Gradle, Meson, vcpkg, Conan and fathom's own config
and plan rows, and moved C, PHP and C# onto tree-sitter dialects. The
stewardship verbs (ADR-060: `plans lines`, `report used`, `gc` strays and
binaries, `plans status` archivable) show what a repository carries.
`fathom ingest` names each pass's wall and CPU time (EW-48) and costs a
fraction of the instructions it did (EW-49..EW-53, LB-F208..LB-F210), and a
compile no longer loses its work to one section's deadline (EW-33..EW-36).
Two contracts were renamed to say what they measure: the decision kind
`predicate` and the rule-outcome events `top_changed` and `still_served`
(JF-1, JF-2).

What is not claimed: the cloud-session readings in a real VM (CS-M1..CS-M3)
are owner actions not yet taken; the language levels are committed readings
against named oracles, not coverage; and nothing here licenses a savings
claim.

## Breaking

- `decisions.jsonl` and the assess ledger (and `fathom assess --json`) name the yes/no decision kind `predicate` at `schema_version` 2, where version 1 rows say `noul`; `fathom decide log` and the console read both as `predicate`, and no provider request changes ([migration](../upgrades/0.10.0-decision-kind-predicate.md)).
- **The edit hook's rule-outcome events `complied` and `violated` are renamed `top_changed` and `still_served`, and `violated` is dropped as an event (JF-1, JF-2; ADR-056, ADR-057).** The tracker evaluates no check, so a repeat edit says only that the same rule still topped the file's served set. Old ledger rows are read under the new names, never dropped; `fathom obligations`, `/explain`, `/rules` and `fathom claim effectiveness --json` carry the renamed fields. Migration: `docs/upgrades/0.10.0-rule-outcome-events.md`.

## Fixed

- **The pre-push `verify` step runs under dash (CS-8).** lefthook runs every `run:` body with `sh -c`, which is dash on Debian and Ubuntu (a Linux cloud session VM among them), and the step's bash arrays and `shopt` failed every push there; the body is POSIX sh now, as are the copies in the adoption guides.
- A held port names its holder on Linux without lsof: serve-http's `exit{port_held}` row and `fathom daemon stop`'s listener fallback read the listening pid from procfs's socket tables when lsof is missing or silent (CS-8).
- The cached git toplevel misses when the .git nearest the cwd carries the recorded identity but `<top>/.git` does not: a Linux file system can hand a removed .git's inode to a nested `git init`, which the cache read as the old repository for up to 10 minutes (CS-8).
- A C++ test macro's name is no type reference (LB-F238): the last argument of `TEST(suite, name) { ... }` bound a header's class of that name, so `TEST(xchar_test, ostream)` drew an edge to fmt::ostream. Every C++ file re-extracts at `ExtractorEpoch` 51.
- A one-file refresh no longer drops the refreshed package's Go typed edges from the cached call graph until the next ingest: a package patch with no new typed edges keeps the ones it had, so the patched graph answers as a fresh build (LB-F202).
- **A compile no longer dies on one section's deadline, and no exit path drops compiled sections (EW-33, O297).** The claude-cli subprocess's own per-call deadline counts that section failed (named in `section_errors`) and the loop continues; only the caller's context aborts, and an abort stores the claims compiled so far and records the run before it returns.
- **A long `compile_layer` over /rpc answers its result and not an empty body (EW-36, O299).** The daemon's logging response writer hid the connection from the ingest-class detach hook, so the 150 s write deadline was never lifted.
- `layer_coverage` serves `uncompiled_reasons` (section to failed, prefiltered, refused, budget, cancelled, corpus_grew or stale), and a failed section now appears in `uncompiled_scopes` (EW-35, O298); `compile_layer` answers the same map. One added `compile_runs` column.
- A claude-cli profile takes `timeout` (a Go duration; `FATHOM_CLAUDE_TIMEOUT` on the env lane) for one model call, default 5 minutes (EW-34).
- **`fathom ingest -scip` stores typed edges for an index whose producer sets no enclosing_range (scip-php, scip-clang, scip-dotnet; LB-F54), and stops counting references to local variables as unmapped (LB-F55).** A mapped definition without an enclosing range takes its fathom symbol's own lines, so the references in its body are attributed: Polly's scip-dotnet index went from 0 edges (every reference skipped) to 36,831 direct edges. A reference inside a local variable's initializer is attributed to the function the local lives in. - **A refusal names the ladder's cause (EW-37).** At the refuse rung the daemon's refusal, the refresh gate and the abandoned-by-governor outcome say `swap volume free X < Y` (or the host-pressure trigger) when that fired, and keep "over its memory budget" for a footprint mark.
- `fathom tests select` no longer names a package under a nested `go.mod` (`calibration/oracles/*`), which cannot run from the repository root (EW-38).

## Compatibility review

Every `Changed` and `Fixed` entry above was read against the compatibility
surface (`docs/intent/scope.md`, "Compatibility surface"). One moved to
`Breaking` (EW-32, above). The others that touch a listed item, and why each
is not breaking:

- **EW-39, `fathom ingest` exits 1 when the typed pass loads 0 packages.**
  The rule that a failed typed pass exits 1 shipped in 0.9.0 (wave P3, O82:
  `cmd/fathom/ingest.go` returns 1 on `TypedFailed`, held by
  `TestCmdIngest_TypedEdgesFailureExitsNonZero`). EW-39 classes one more way
  of failing under that rule, a load of 0 packages where the connector found
  Go files, through the same `TypedFailed` flag; the `--json` envelope gains
  and loses no field, and a repository with no loadable Go files is
  unchanged.
- **JF-7, `route` off by default.** The `[decide] sites` key, its type and
  every value it accepts are unchanged; only the default list drops an
  egress site that failed calibration, and the entry names the restore (a
  `sites` list naming `"route"`). The deterministic precheck still answers.
- **LB-F199 and LB-F200, Go callers and type references.** `symbol_context`
  and `blast_radius` keep every field name and type; `referenced_by`,
  `references` and `edge_kind` are additive. Which edges count as callers is
  extraction precision, which every `ExtractorEpoch` moves.
- **LB-F239 (`parameter-target`) and LB-F54 and LB-F55 (`EnclosingFallback`,
  `local-target`).** The SCIP import report keeps its types; the new map keys
  and the new count are additive.
- **EW-37, a refusal names its cause.** The admission wire format keeps its
  refusal codes, the `-32050` data fields and the `abandoned-by-governor`
  outcome (`errors.Is` still matches it); only the free-text reason words
  change.
- **EW-35, `uncompiled_reasons` and one `compile_runs` column.** Additive
  within Governed Store Format v0 and the tools' schemas.
- **The vendored agentic-kit pin.** Its observable effect is the `predicate`
  rename, which is `Breaking` with its migration note.
