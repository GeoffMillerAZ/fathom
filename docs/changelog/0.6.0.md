# 0.6.0 — 2026-08-27 — the evidence plane: intent audited, ceilings measured

The narrative record for `CHANGELOG.md`'s `[0.6.0]` block: what was built, what the
reviewers caught, and the evidence each claim rests on. Not normative; plans, ADRs, and
observations are. Row ids named here are what `fathom plans archive` checks against.

## The question this release asks

A long-lived repository accumulates statements about itself — invariants, decisions with
reopening conditions, non-goals, sensitive surfaces and the evidence a change there needs.
Written down, they are load-bearing: an agent reads them and treats them as true. Nothing
checked whether they still were.

ADR-026 answers narrowly: **read what a repo already declares, check what an instrument
can show, and list what nothing shows.** Never write intent, never resolve a conflict,
never score a repository, and never turn an honest "nobody enforces this" into debt.

## Honesty fixes first (HF-1..HF-8) — commits f090e49, 2c21658

The evidence-plane review forced these; each has a named consumer and shipped on its own.

- **HF-1** `fathom plans archive` reads the git history of commits that touched non-plan
  paths (`gitHistoryCorpus`), so a plan's own bookkeeping commits cannot absolve it while
  code commits that absorbed its row ids finally can. Range and slash-list ids expand.
  36 proven plans were unarchivable before this. Measured 16–44 ms.
- **HF-2** `fathom post-commit-hook` routes the refresh through the daemon; a shell
  `ingest` against the shared store happens only when the daemon is unreachable. INC-3
  closes.
- **HF-5** the four MCP group surfaces retired (ADR-014 amendment 2, on law 4); the eight
  tests that pinned them were rewritten to assert the group taxonomy, which survives.
- **HF-6/HF-7** one dispatch table renders `fathom help` and is parsed by a test, so a
  dispatched verb cannot be hidden from help again, and every `## Maintained` line names
  a real tool or verb.
- **HF-3** the ADR-016 obligation ceiling, **measured before being enforced**: 1,918
  post-edit and 370 pre-edit payloads over 28 days. The 150-token cap is missed on 47%
  and 83% of them, p95 ≈ 329 — about 2.2× the limit. Enforcing it would silently withhold
  a median of two rules from a typical over-budget payload, on roughly half of all edits.
  The precision half is **not computable and the record says so**: the beat log stores
  bytes and rule counts, never payload text. `docs/measurements/2026-08-27-obligation-ceiling.md`,
  posed as Q21.
- **HF-4** accordingly **deferred, not built** — the measurement turned it from an
  implementation task into an owner decision.

## Wave 1: the corpus, the audit, the ledger (EP-1..EP-15, EP-35..EP-37) — commits 0dbde8e, 8bf4938

`internal/intent` loads a corpus at three tiers (router, decisions-only, none) and
`RunAudit` joins it against the index and the gates.

- **The ledger is SEPARATE** (`~/.fathom/intent-ledger.jsonl`, EP-6/EP-12). The verify
  ledger's readers count every row as a gate run; an intent row there would corrupt the
  "PROVEN 180/436" headline.
- **U1–U6, U11** (EP-7/EP-8): plan rows the gate proved failing or claimed without a
  contract, invariants at `VIOLATED`, invariants naming a test or gate step that does not
  resolve, fired-undecided conditions, stale incidents, and records citing paths that
  moved. `stated` and `reviewed` are listed as UNENFORCED and **not counted as debt** —
  turning an honest rung into debt is how rungs get faked upward.
- **The index probe is one call** (EP-9): a synthesized in-memory plan through
  `verify_plan`, cached per HEAD in the ledger. 6.6 s cold → 84 ms warm.
- **The capability switches something** (EP-10): `intent-corpus` off silences the two
  doctor rows, never the verb.
- **Neither doctor row can FAIL** (EP-11). Not adopting the practice is a choice; honest
  debt is not a broken repo.
- **EP-14** custodian kind `adr_references_resolve` — INC-14's outcome, the check that
  would have caught a design declaring itself adopted under a record nobody had written.
  Scoped to this repo's id shape, so a sibling repo's `ADR-0070` is named rather than
  reported missing. It fired 52 false positives before relative resolution, home-path
  skipping and superseded-record spans brought it to 2 true findings.
- **EP-37** the trust boundary: an annotation is untrusted repo content, so its paths are
  root-confined and its services local.

## Wave 2: delivery, and two narrowings that were the finding (EP-19..EP-24, EP-38, EP-45, EP-46) — commits 6fa0ef5, 9bef3bf, 2c21658

- **EP-19** ONE attention line, not a second: `⚠️ attention: config N · unproven M (+k) ·
  fired F — fathom doctor`. It reads ledger rows only — no audit, no index, no RPC — and
  goes silent past 14 days, because a stale count nags without being evidence about the
  working tree. `unproven` and `fired` are disjoint so the numbers add up.
- **EP-20** the whole primer capped at 3,200 B with the cut named and post-cut bytes
  stamped. The parts' own budgets sum below it, so the cap is a **backstop** — and
  `TestPrimerPartBudgetsSumUnderCap` fails the moment that stops being true, rather than
  leaving an unreachable number to read as enforcement.
- **EP-38 U12, narrowed, and the narrowing is the finding.** The spec asked for rows whose
  `reachable_from` is not one of the surface's Done-needs tests; run against this repo that
  fired 50+ times, because Done needs is what a change there needs IN ADDITION to the row's
  own proof. A check that fires on every healthy row is not a check. What survives: a row
  CLAIMING done inside a sensitive surface that pins no named test, so the surface's guard
  can be renamed and the row stays green. 62 here.
- **EP-21** `intent export --guard` proposes guard entries stamped with **per-row**
  provenance, not the spec's router blob sha: a whole-file sha marks every entry stale on
  any router edit, the same false-alarm channel EP-19 refuses. U13 reports a stamp no router
  row matches, and a sensitive surface no guard covers.
- **EP-22** the stanza's obligations paragraph has two wordings of the same three physical
  lines, and the intent one renders only where the channel is wired. This repo is the
  unwired case (14 surfaces, 0 covered) and a test pins that its own stanza stays plain —
  leaving it unwired is deliberate, because HF-3 measured that channel at 83% over budget.
- **EP-24/EP-45/EP-46** the kill instruments: `intent_line` as K5's cohort and
  `intent_acted` derived from a BEAT rather than from anything the transcript says (law 14);
  K1's pre-clock baseline measured over `ADR.md`'s git history because `docs/intent/` is
  two days old — 2 records answered, median 78 days over 24 commits; and the attention
  line's bytes as a **component** of the primer's payload-cost beat, inside the total rather
  than added to it.
- **EP-23** `fathom fleet report` `schema_version` 1 → 2 with an `unproven` column read
  from the ledger; no recorded audit renders `n/a: no audit recorded`, never a `0`.

## What is deliberately not built

- **The oracle runtime (EP-16/17/18)** is gated on K0: three hand-written `{oracle: …}`
  annotations across two repositories. There are zero. Writing them ourselves would fake
  the demand signal the gate exists to measure — EP-43 refused exactly that. The question
  of whether the practice accepts the annotation at all is now FILED where its answer
  belongs: agentic-kit `docs/intent/decisions/0001` (`Status: proposed`, 72ff8b9), whose
  own revisit condition is the gate — three annotations accepts it, thirty days with
  fewer REJECTS it.
- **The observatory panel (EP-44)** — its host panel, SD-2, is unbuilt.
- **Anything leaving the machine.** Honesty-debt counts stay in local artifacts; nothing
  reaches the research bundle until Q16 is answered (law 13).
- **Wave 3 (change records, EP-25..EP-33, EP-39..EP-43)** stays deferred by design.

## What the reviewers caught

The design panel found four blocking flaws in the draft before adoption: it claimed
"adopted (ADR-026)" before the record existed (→ INC-14, and EP-14 is the check that
would have caught it); it promoted F9 on an unfired trigger (→ restored to `futures.md`);
"decided" was not computable (→ the first-seen ledger); and K5 used narrated story rows,
which law 14 forbids (→ session stamp plus beat join).

The verify gate caught the author over-claiming eight rows whose named symbols did not
exist, and later caught EP-24 bundling three instruments under one contract. Each was
re-anchored or split rather than argued with — which is the gate doing its job on the
release that shipped the audit.
