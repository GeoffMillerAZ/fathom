# Readouts: a command's output as a compact, enriched or raw readout, with a receipt (RO-)

Design: `docs/design/readouts.md`. Decision: ADR-071 (amends ADR-042 by the opt-in site `readout_mode`). Goal: G39.
Roadmap: `docs/vision/38-proof-layer-roadmap.md` §9.6, the next priority program after the RT-M1 reading; the Claude
Code mods program follows. Futures: F75 (the index hint, still future), F76, F77, F78. Readings live under
`docs/bench/readings/readouts/`; each bar is fixed here before any run (K19: never moved after the data); every reading
before phase 4 is $0 in model spend and prints aggregates only, never transcript text.

Phase 0 is buildable now under the table freeze and the budget hold: no store table, no cache, no background job, no
model spend; evidence rides the existing hook log, and the corpus is read by an explicit verb. Rows inside a phase run
in value order from the corpus (design §1, §17): long source reads (10.6% of Bash bytes, ceiling 8.5%), then `ls`
(6.8%, unsized), grep (16.5%, grouping 0.6%, the cap unsized), git output (5.3%, unsized), test runs (ceiling 1.2%),
then the base stages (0.2%); RO-M0 sizes what is unsized and may reorder phase 1. Symbols are provisional until
grounded with `find_symbol` at row start. Owner questions Q-RO-1 to Q-RO-4: ADR-071, `docs/intent/questions.md` Q35.
