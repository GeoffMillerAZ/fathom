# Feature tuning

Status: Proposed 2026-11-14 (architect ruling on owner direction).
Grammar: v2. Prefix: FTU-. Design: `docs/design/feature-tuning.md` (FT-D1 to FT-D5). Decision draft: ADR-110.

Goal: one purpose metric and a falsifiable reading for maps, semantic layers, freshness, resource envelope and edit obligations.
All rows are open. Every row fits one lane-day including its tests or one bounded reading session.
