## Handed contract and proof convention

The integrator hands each row frozen valid and invalid fixtures and a red acceptance test before
dispatch. Every test command below is a proposed command, not an existing capability. Readings
under `docs/bench/readings/contributor-model/` are attestations naming the base, tested head,
command, exit, fixtures and observed failures. A PASS line is allowed only after the full stated
bar holds. The lexical oracle proves the receipt was filed, not that its assertions are true.
A critic inspects the underlying logs. A worker cannot make the test green by changing its bar.
All rows fit one lane-day. If grounding disproves that size, the steward splits before readiness.

REC-1. CTR-4 is a main-thread surface lane, and must land before automated fan-out. CTR-5
serializes edits to the queue helper after CTR-2. CTR-6 and CTR-7 have distinct owned files.

## Decision models

None applies. These checks compare deterministic records, paths and clocks. Provider `none`
needs no substitute. Opt-out is manual review without claiming automation. The fixture bars
above measure correctness. No runtime model judgment or new decision-port site is proposed.
