# Repository facts: the plan (ADR-067)

Grammar v2 (`docs/plans/README.md`). A row flips to `[x]` only when
`fathom verify --service fathom --plan docs/plans/repository-facts.md` proves it. Vision:
`docs/vision/42-every-file-accounted-for.md` (section numbers below are its). Decision: ADR-067. Goal G36.
Invariants I8 (amended), I57 (extended), I65. Futures F37 (amended), F68, F69.

Every reading here is $0: tool oracles and replays on the operator's machine, no provider or agent spend. No row adds
a table, a column, a cache or a background job (ADR-049 decision 2). A facet's serving lands in the same wave as its
reading, and only if the reading reads KEEP. A reading's pattern accepts either verdict, and the change that records a
CUT marks the rows it gated `[-]` refused. Every `runs` and `configures` link carries the existing resolution tier
`heuristic`, is labelled, and never gates from its first row (I57 as extended by ADR-067, RF-6 and RF-12). The guard
over every other heuristic call edge in the fleet (RF-5) lands only after RF-M6 publishes its count, whatever it
reads (the owner-architect's ruling of 2026-10-10). The oracles run in the measuring harness only:
fathom's automatic passes never run a command a repository names (K22, I64). No adherence claim rests on the owner's
wave traffic alone: a delivery reading reports the general case (one repository edited in place, git worktrees) as
its own stratum, and claims it only at 100 first touches or more.
