# Wiring proof

Status: Proposed 2026-11-14 (architect ruling on owner direction).
Grammar: v2. Prefix: WPF-. Design: `docs/design/wiring-proof.md` (WP-D1 to WP-D6). Decision draft: ADR-110.

Goal: a scripted W0-W3/W6 environment preflight decides validity before either agent acts.
Preserve correction 1 (docs/design/bench-prep.md:371) and docs/plans/bench-prep.md#BX-40.
W4 use and W5 action never exclude cells. Every admitted cell retains its actual assigned-arm outcome for the headline.
A use-conditioned secondary is labelled biased toward the product and supports neither a headline nor a ruling.
All rows are open specifications, not completion claims. Each row is bounded to one lane-day, including its tests.
Named symbols are proposed new functions. Tests must reach the function through the named product or bench entry.
Artifacts and raw transcripts stay under `workspace/`. Public fixtures contain synthetic or public inputs only.
L-S rows belong to the architect. Other rows begin only after their input contract is frozen.

Reuse: WR-4/5 own stamps and joins, WR-12 owns firing diagnosis, WIR-1 owns their integration, WIR-2 owns gate parity,
WIR-3 owns Linux service installation, WIR-5 owns the harness matrix. LAB-7/9/11/12 own decode/eligibility/funnel/ledger.
BEN-2 owns the readiness suite and BEN-4 owns the delivery log. No row below reimplements those contracts.
The first four rows extend these owners. A deferred dependency remains blocked under grammar v2.
This plan authorizes no spend, install, global config change or default change.
