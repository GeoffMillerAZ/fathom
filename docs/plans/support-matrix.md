# The support matrix — the plan (a projection, never a kept list)

Grammar v2 (`docs/plans/README.md`). A row flips to `[x]` only when
`fathom verify --service fathom --plan docs/plans/support-matrix.md` proves it.
Design: `docs/design/support-matrix.md` (section numbers below are its). Schema:
`schema/support/`. Row ids are stable: `SM-<n>` work rows, `SM-M<n>` measurements.

The rule every row serves: a cell shows a level only when a committed reading computed it;
without a reading it is `tolerated` (registered) or `declared` (planned), never a claimed
level (ADR-048 decision 2, I54, extended to every kind).
