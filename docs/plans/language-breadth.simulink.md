## Foundation

- [x] A Simulink model reader and the binary gate's one exemption (ADR-021 decision (1), amended 2026-10-24). `extractor.ReadSimulinkModel` reads a `.slx` OPC zip in memory under three caps (4,096 entries, 32 MiB inflated across the parts read, 200:1 per part, a declared size never trusted) and every layout era: blocks inline in `simulink/blockdiagram.xml` before R2020a (the diagram's System only, never the BlockDefaults or BlockParameterDefaults templates), one `simulink/systems/system_<n>.xml` part per system from R2020a with each `<System Ref>` stub spliced in place (`system_root` first, each part walked once, a part no part names read at the model's root), model references from `graphicalInterface.json` from R2024b (wrapped until R2026a, flat in R2026b), else `graphicalInterface.xml`, else the diagram's inline interface (`$bdroot/Child|model` split at the last bar); R2026b's `blockDiagram.json` holds no block and is not read. A classic `.mdl` is read as its brace tree (`Model|Library { System { Block { System … } } }`, quoted values concatenated across continuation lines); a text-package `.mdl` (R2027a's `# MathWorks OPC Text Package` or `# Simulink Text Package`) is disclosed as `ErrSimulinkTextPackage`, never read. A block is named by its full path from the model (Simulink's getfullname: a `/` in a name doubled, a line break read as one space), keyed SID to path, and carries its block type and the lines of its element in the part that holds it. `fusion.binaryExcluded` is the one binary rule every fusion read path asks (ingest's extract sink, the one-file refresh, the harness's ExtractForBench, the file resolver, every cross-file pass): NUL-sniffed content is excluded unless its extension is a manifest's `match.container` (`opc-zip`, one of its own extensions) and its bytes open with the zip signature.
