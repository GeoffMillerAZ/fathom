## L0 findings — index precision (2026-09-12)

The first `task bench-l0-self` run at HEAD (10,651 symbols, 100 Go packages, 0 with type
errors) measured what the nav tools actually return on this repository: `find_callers`
precision 0.607 (295/486) recall 0.899, `references` precision 0.158 (352/2,226) recall
1.000, `blast_radius` precision 0.086 (871/10,158) recall 0.805 at ~10.9 s a query. High
recall with low precision is the signature of the syntax pass's tolerant bare-name
matching, and ADR-032 holds L4 closed while L0 is under 0.95. Before/after numbers:
`docs/bench/README.md`.

## What the run found (O31, O32) — the bar for the next spend

The 2026-09-13 run is the baseline: fathom passes more (31 vs 28, p=0.042,
CI −0.06..+0.24) and costs more (payload 1.90×, cost 1.46×, tokens 1.44× of
which ~11% is the harness loading fathom's schemas). The wins are the
index-native tasks (H1-T07 3/3 vs 1/3 at 0.21× payload); the losses are
greppable lookups where the arm kept exploring after the index had answered.
Nothing below is claimed until a targeted L3 run over the losing tasks shows
it; the next L4 borrows every grep and none cell by key and re-runs only the
39 fathom cells.
