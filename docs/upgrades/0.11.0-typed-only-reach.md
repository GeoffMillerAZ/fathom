# 0.11.0: verify's reach passes only over typed call edges

**Breaking:** `fathom verify`'s `reachable_from` (the `edge_wired` criterion) and
`wired` pass only through typed call edges (RF-5, I57). A row reached only through
a heuristic edge now fails, and the failure names that edge and its tier. The
heuristic edges are a syntax-only call, a reference to a type or a constant, and a
file-resolved import match. Every edge is still served with its tier named
(`symbol_context`, `blast_radius`, `find_callers` with `include_heuristic`); only
verify stops passing on it.

| Before | From 0.11.0 |
|---|---|
| `reachable_from` passed when any call edge reached the symbol | it passes only when typed call edges reach it; the first heuristic edge on the path is named in the failure |
| `wired` judged a bare name, which could resolve to a same-named type | `wired` judges the function the row names, and links a package into a binary by its directory |
| a non-Go row's `reachable_from` could pass over syntax-only edges | it cannot pass until its language gains a typed pass; its `test_reaches` criterion still reads every edge |

## What to do

Run `fathom verify --strict` over your plans after upgrading. Each row that now
fails names the heuristic edge it rested on. Then, by the kind of row:

- **The `reachable_from` test never reaches the symbol through typed edges.** Name
  a test that does: one that calls the function, or calls a function that calls it.
- **The row's symbol is a type or a constant.** No typed call edge reaches a type or
  a constant, so `reachable_from` cannot pass on it. Anchor the row on the function
  that does the work, or uncheck the row with a reason until it does.
- **`wired` passed through a name the syntax pass bound to the wrong function.** If
  no product entry point calls the symbol, call it from one, or declare
  `library: true` with a reason that predates the claim.
- **A non-Go row with a `reachable_from`.** It cannot pass `edge_wired` today. Keep
  the claim on `test_reaches`, or uncheck the row with a reason naming RF-5.

`library: true` and `skip_test` are not migrations: adding either in the same range
as the claim to get past this check is refused as self-declared (`verify --since`).

## How many rows this moves

RF-M6 counted the proven rows that rested on a heuristic edge across the services
on the measuring workstation before the change shipped: 9 of 2,737 claimed rows,
each named with its edge and its fix in
`docs/bench/readings/repository-facts/reach-guard-flips.md`.

## Why

A heuristic edge is a guess about which function a name means. A plan row checked
as proven on a guess is the failure "done means proven" exists to prevent.
ADR-067 records the decision and its non-Go consequence.
