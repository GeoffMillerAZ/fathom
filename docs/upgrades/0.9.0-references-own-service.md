# 0.9.0 — `references` searches your own service by default

**Breaking:** the `references` MCP tool no longer scans every indexed service
when `services` is omitted (RT-86, RT-159, `docs/design/responsible-tenant.md`
§4.5). A fleet-wide text scan per call read every repository whole; it was
one of the request-path readers behind the 2026-09-26 incident.

| Call | Before | From 0.9.0 |
|---|---|---|
| no `services`, caller's cwd inside an indexed root (hooks, the CLI, `serve-mcp`) | every service | the service whose root holds the cwd (`scope: "caller-service"`) |
| no `services`, no caller identity (an agent on `/rpc/agent` over HTTP sends no cwd) | every service | `-32602`: `references: name the services to search — indexed: …; or pass services: ["*"] for the fleet` (with `data.indexed_services`) |
| `services: ["a", "b"]` | those services | unchanged (`scope: "services"`) |
| `services: ["*"]` | a service literally named `*` | the whole fleet (`scope: "fleet"`, admitted in the `fleet` cost class) |

The text scan is also bounded: at most 64 MiB of source and 5 s per call
across the services it searches, stopping once more than `max` occurrences
are kept. A scan that stopped says so in `partial`
(`≥ 26 occurrences (scanned 812/2236 files: budget bytes)`), and the
occurrence count is then a lower bound.

## What to do

- **An HTTP agent** (`claude mcp add --transport http …/rpc/agent`): pass
  `services` — your own service's id, or `["*"]` when you mean the fleet.
  The refusal lists the indexed ids.
- **A script** that relied on the fleet default: add `"services": ["*"]`.
- Hooks, the CLI and `serve-mcp` need nothing: `X-Fathom-Caller` now carries
  `cwd=` (percent-encoded), and `serve-mcp` uses its own working directory.

## Why

A fleet default cost every call the whole fleet's text, whatever the caller
meant. Naming the scope keeps the cost to the question, and a refusal that
lists the choices is never mistaken for "no references".
