# 0.9.0 — admission, the busy wire format, and call-log schema 3

**Breaking** (ADR-047 §3; RT-53..RT-65): serve-http admits every tool call in
its cost class, `/rpc` work follows its request, and the call log's `outcome`
changes meaning.

| Before | From 0.9.0 |
|---|---|
| `/rpc` work ran under `context.Background()`: a client that disconnected left its call running | read work runs under the request's context, the class deadline (`point` 10 s, `index` 30 s, `tree` 60 s, `fleet` 120 s) and `X-Fathom-Deadline`; a call whose context ended answers `-32603` with `data.outcome: "abandoned"` instead of its result. Ingest-class calls still run detached |
| `batch` took any number of calls | at most 16 (`-32602` names the cap); each sub-call is admitted in its own class, and a sub-call refusal is that entry's `error` |
| any `Host` reached every route | every route requires a loopback `Host` (`127.0.0.1`, `localhost`, `[::1]`) and, when sent, a same-origin `Origin` (403 otherwise); a `--modules-token-env` deployment keeps its bearer gate instead |
| a test binary could reach the managed daemon | the managed daemon answers `X-Fathom-Caller … test=1` with 409 `{reason: "test binary reached the operator daemon"}` |
| — | under `[tenancy].admission = "enforce"`: HTTP 503, `Retry-After`, JSON-RPC `-32050` `fathom busy: <reason>` with `data {reason, class, level, retry_after_ms, in_flight}`. The default `observe` refuses nothing |
| call log `schema_version: 2`; `outcome` only on an `abandoned-by-governor` row | `schema_version: 3`; `outcome` on every row (`ok`, `partial`, `refused`, `abandoned`, `abandoned-by-governor`, `error`), plus `class`, `queued_ms`, `bytes_read`, `caller` |

## What to do

- **A reader of the call log that treated a present `outcome` as "abandoned":**
  compare its value; a v3 row always carries one. Rows with `schema_version` 2
  or less keep the old meaning.
- **A client that talks to the daemon by a non-loopback host name** (a
  `/etc/hosts` alias, a container bridge): use `127.0.0.1:<port>`, or run the
  daemon hosted with `--modules-token-env`.
- **A client of `-32050` / 503:** back off for `Retry-After` seconds; the
  hooks already do (their breaker opens on a 503 with `Retry-After`).
- **Admission off entirely:** `FATHOM_TENANCY_ADMISSION=off` (a loud startup
  line).

## Why

INC-23: the daemon reached ~30 GB with nothing bounding concurrency and every
abandoned request still computing. Vision 36 and ADR-047 §3 make every call
declare its cost and pass one gate.
