# Upgrading past 0.9.0 — the surface reckoning

The surface reckoning (docs/plans/surface-reckoning.md, docs/design/surface-reckoning.md,
ADR-053) deletes zero-call MCP tools, CLI verbs and canned prompts and merges several
others into a composed verb. This note is the tool/verb/prompt → replacement table,
appended one row per removal row as it lands (SR-36 is the row that completes this table
and its `### Breaking` block in `CHANGELOG.md`).

| Removed | Kind | Row | Replacement |
|---|---|---|---|
| `investigate_incident` | MCP prompt | SR-20 | Call `entrypoints`, `find_callers`, `community`, `staleness_report` directly |
| `review_change` | MCP prompt | SR-20 | Call `review_diff` directly |
| `onboard_service` | MCP prompt | SR-20 | Call `entrypoints`, `list_sources`, `god_object` directly |
| `plan_requirement` | MCP prompt | SR-20 | Call `entrypoints`, `complexity`, `dead_code` directly |
| `brief` | MCP tool | SR-15 | Call `find_symbol` + `query_symbols` (or `pack_context`) directly and assemble the context yourself; the console's `/brief` page covers the human-facing value brief |
| `fathom brief` | CLI verb | SR-14 | Open the console's `/brief` page (same `renderBriefMD` content); nothing replaces the `--json`/`--out` machine paths |
| `fathom narrate` | CLI verb | SR-14 | None — the story-mode capture feature (story rows, the narrate capability) is retired outright, not replaced |
| `dep_drift` | MCP tool | SR-10 | None — superseded by the system graph (ADR-050): `pkg:` contract-key reads plus `system_impact`/`contract_drift`, not a revived tool pair |
| `cross_repo_blast_radius` | MCP tool | SR-10 | Call `cross_repo_callers` for the symbol's cross-service callers, then `blast_radius`/`find_callers` in each caller's own service |
| `find_callees` | MCP tool | SR-21 | Call `symbol_context` — its `callees` field already answers this |
| `diff_impact` | MCP tool | SR-25 | Call `blast_radius` with `max_depth: 0, max_symbols: 0` for the same unbounded walk, or `review_diff` for the composed diff/PR verdict |
| `api_diff` | MCP tool | SR-26 | Call `review_diff` with `since` for its `conservation` dimension's `surface` plane, or `fathom conserve --since <ref>` store-direct (base→head on one service, not two independently-ingested snapshots) |
