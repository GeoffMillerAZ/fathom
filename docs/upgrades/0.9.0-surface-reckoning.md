# Upgrading past 0.9.0 — the surface reckoning

The surface reckoning (docs/plans/surface-reckoning.md, docs/design/surface-reckoning.md,
ADR-053) deletes zero-call MCP tools, CLI verbs and canned prompts and merges several
others into a composed verb. This note is the tool/verb/prompt → replacement table,
one row per removal. It is complete for wave 2 (SR-10..SR-32): every removed MCP tool,
CLI verb, flag, surface and prompt, plus the verbs that only left `fathom help` (hidden,
still callable). Each removal also has its line under `### Breaking` in `CHANGELOG.md`
(SR-36). Replacements name only tools that are still registered.
