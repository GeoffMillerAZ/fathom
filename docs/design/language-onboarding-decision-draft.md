# Decision draft: retain the onboarding method, reject new tooling for now

Status: **draft, no record ID allocated**. This records controller ruling LH-R2's
research disposition; the controller owns any later promotion into ADR.md.
Design: [language-onboarding](language-onboarding.md).
Evidence: [dated assessment](../assessments/2026-10-25-language-onboarding.md).

## Context

The current harness already supports pinned query reuse, draft/probe iteration, measurement
and tracking. The measured rounds chiefly expose oracle truth, reading-contract, test and
resource evidence gaps. A pre-oracle reorder has too few eligible historical cases. The
proposed staged predicates are held-in examples, not an independent efficacy experiment.
Cheap tree screens settle their known shape prevalence without another scorer or framework.

## Draft disposition

Reject **new onboarding preflight tooling** for now. Do not build the proposed replay scorer,
freeze protocol or runtime predicates. Improve the existing worker checklist and reuse the
owning foundation lane's tests. Separately authorized ordinary hygiene fixes belong in the
existing ignore/debris and hygiene-scanner seams, not a language preflight subsystem.

Reject **a general starter-query importer** for now. Retain grammar/Aider/Neovim search and
`lang-draft`/`lang-probe`, with pinned licensing, fixtures and independent measurement.

## Wins if

- Preflight: with ordinary hygiene fixes in place, tracked in the
  [controller-owned #16 follow-up](../plans/language-onboarding.md#controller-owned-hygiene-follow-up),
  at least three addition-specific mechanical escapes across at least two additions remain
  uncaught by existing checks, with public bad/fixed pairs and an independent held-out
  evaluation that can change the decision. The controller owns filing/assigning the hygiene
  brief and checking it has landed before evaluating this trigger.
- Importer: at least three additions across at least two waves each need hand conversion
  of five or more query patterns beyond `lang-draft`/`lang-probe` support, counted from saved
  draft-versus-committed `tags.scm` diffs in provenance (patterns, not lines). Require pinned,
  permissively licensed sources and an independent held-out comparison showing fewer
  hands-on conversion minutes per addition, with baseline/importer minutes recorded for
  each and no weaker extraction or provenance. Source availability alone is insufficient.

## Consequences and limits

Ship guidance only: search-and-scope receipts before ceilings, reproducible measurement
checks and explicit READY evidence. No new support claim or measured time saving follows.
Rejected experiment tasks are retired; no plan box is claimed and no record ID is created.

## Decision models

None applies. The evidence and checklist are deterministic and require no provider or model.
