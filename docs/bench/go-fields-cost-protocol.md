The field extractor is b9a23a7dd, built on main 5b84aa5b4; the anchor-corrected candidate is 68ef5163780197afde9346bddad720b6076677d9. The measured candidate also
excludes fields from bare plan-anchor matching while retaining exact Owner.Field lookup. Interface-method definitions and native
field read/write/reference edges are unchanged. I54 governs level claims, I23 call truth,
and K17/K26 allow at most +15% wall time and +20% store bytes without another owner ruling.

Before measurements, freeze a source snapshot of main 5b84aa5b4, preserving every tracked file.
Keep it outside the checkout's gitignored workspace tree so ancestor gitignore rules cannot
silently suppress discovery. Both binaries ingest this same source tree and logical service,
into a new empty local SQLite store for every run. No daemon, SCIP index, paid API, toolchain
fetch, source exclusion, typed-pass disable or previous typed cache participates in self-ingest.

Build the baseline before editing the extractor. Build the candidate from the frozen field-only
commit. Run baseline and candidate alternately, three runs each, serially under nice 10. Check
uptime before every heavy run and wait while one-minute load exceeds 9. Use the same local
Go module/build caches, GOWORK=off, GOFLAGS=-p=2, GOMAXPROCS=2 and GOTOOLCHAIN=local. Record
source SHA, binary digests, all wall times and store bytes, discovery/extraction counts,
read failures, typed packages/edges and skipped/failed work. Store row counts use immutable read-only access only after the process exits and no
nonempty WAL remains. An initial collector failed its read-only WAL initialization after a
healthy baseline ingest; that interrupted sequence is excluded and all six measured runs
are repeated with fresh stores. A first complete sequence then exposed 25 lost plan-anchor
edges: fields competed with functions for bare anchors. Its +15.9% wall/+6.3% store result
is not accepted as equivalent work. After a failing regression test and the narrow anchor
repair, repeat all six controls again. Thresholds and source controls are unchanged.

Compare medians. A baseline that
skipped the changed work is invalid under K27. Any unavailable or mismatched work blocks a
passing cost claim until explained.

## Historical outcome corrected by independent review

One original equivalent-work sequence read +26.7% median wall (CPU +20.9%)
under asymmetric load; an independent rerun with the committed collector and same
commits/source read +6.9% wall (CPU +10.8%). An earlier non-equivalent sequence
read +15.9%. The wall result is within machine noise: neither passing nor failing
the lever is established. Store +6.3% passes reproducibly. The original sequence
included one baseline launch at 9.01 after hashing; it is not strict passing proof.
The interrupted repeat contributes no median; no unverifiable peak load is used.

C-R5 recorded the then-reported failure. Runtime reversion followed this protocol's
stop rule, not a separate owner instruction to revert. The original candidate's
golden/count tests were not regraded: four touched-package tests fail despite
focused regression tests passing. That historical candidate was not landable.

## Binding remeasurement

The controller now requires remeasurement under this preregistered protocol and
a receipt generated by the committed collector. Keep median-of-three, alternating
ABABAB order, all source/work controls and +15% wall/+20% store gates unchanged.
Do not substitute a CPU co-gate, minimum-of-three, or a quieter-looking subset.
Name all launch/end/peak sampled loads. Active runs may encounter other machine
work; report that limitation rather than treating a noisy result as settled.
First freeze a candidate whose touched-package race suite is fully green; test
expectation fixes must not alter production code or the fixed ingested snapshot.
Both binaries use the same toolchain/build flags. Preserve the raw collector
schema and computed result; keep historical/editorial notes under `annotations`.
If both gates pass, explicitly reopen Go L4 rather than retain a failed-cost claim.
No Gin or other holdout is consumed by this cost rerun. Any language grade remains
a separate independent-oracle measurement after acceptable cost is established.
