# C6 recount under D26 (historical D24 retained)

D26 is the owner ruling in design section 5, beside D24. Caller units are
product units only in every language. Exclude tests (including the defining
package's own tests), examples, benchmarks, samples, docs and tools, plus
support directories and test files, before counting sites and outside units.
Go uses import packages; Python and TypeScript use directories. A symbol needs
five product sites across three product units outside its defining unit, and
a candidate needs three qualifying symbols. Counts are sites, not functions.

`c6-r2.json` retains historical D24 counts and adds `product_only` for **every
one of the twenty candidates**, including all refusals. Each entry binds its
pin, resolved-input SHA-256, complete recount SHA-256, count and three witnesses
(or strongest failures) with surviving units/sites and excluded-site examples.
`c6-d24-sha256.json` separately binds all complete historical recount outputs.
Python AST resolution used pinned **CPython 3.12.15**; TypeScript used 5.9.3
and the project configuration for redux-toolkit. Dynamic Python dispatch and
TypeScript interface signatures remain omitted. These are static lower bounds,
not C4 graph certification. C4 is unrun.

```sh
python3 calibration/bench/tools/recount.py "$language" "$subject" "$resolved_rows" --policy D26 > "$BENCH_JOB/receipts/$subject_id-d26.json"
PYTHONDONTWRITEBYTECODE=1 python3 calibration/bench/tools/test_recount.py
python3 calibration/bench/tools/check_c6.py --receipts "$BENCH_JOB/receipts"
```

The committed filter in `recount.py` applies the same path rules across
languages, including `_examples`, `__tests__`, `typing_tests`, `testing`,
`testdata`, `.test-d.ts`, website/docs and tool/script directories. No unit
policy was widened to retain a candidate. Product source copies/build output
never enter the tracked-file call receipts.
