## Final GoReleaser setup attempt

Final setup: 121.17 seconds / exit 137, UID 1000. Setup fetched and SHA-256-verified pinned Node 25.9.0 darwin-arm64, linux-x64 and win-x64 targets, installed a makeself wrapper for Debian’s hardcoded header path, and ran go mod download all. The command also schedules both external test modules and their transitive warming; the cap killed the root download before those later commands could finish. It was the only resumed setup attempt. No offline warm-up or timed trial followed this failed setup.

The final monitor witness is “STOP: binding disk budget reached”. At that sample, persistent workspace use was 6,744,608,768 bytes (6.28 GiB), above the 6 GiB cap; free disk was 20,769,443,840 bytes, above the 16 GiB floor. The monitor killed the container; the build tree was then deleted. This sampled overrun is disclosed, not a claim that the workspace remained below its cap. No further preparation attempt was made.

Pinned upstream internal/nodedist/download.go states: “Each call hits the network — there is no on-disk cache.” Therefore the prefetched target bytes cannot satisfy its direct HTTP requests offline without changing the subject. The archive includes that source window, the exact setup receipt, all target hashes, module-cache failure history and budget monitor. The historical four-phase grader had 45 environment/fixture skip identities and seven network failure exclusions (52/3,723); those counts precede tool repair and do not prove a post-repair suite. The final interrupted attempt has unmeasured skips. GoReleaser is refused on C3; its runnable manifest is removed.
