## Implemented contract

W1-3: third-party grammars only. The existing `tsengine.ParseGrammarLock` parses
the inventory. Each cache entry is a previously populated upstream source archive
at `workspace/grammar-sources/<tarball_sha256>.tar.gz`. Its bytes must match the
lock digest, which binds the pinned source. No release-time download occurs.
The generated notice identifies every grammar, upstream URL, commit, SPDX id and
source digest. Licence files (including their attribution) and Apache NOTICE files
are copied verbatim from the authenticated sources. No fallback licence text is
stored in the generator. Absent sources or absent licence files fail closed.
The licence-file scope follows the existing grammar build: root, src, queries,
and locked grammar subdirectories. An Apache NOTICE is included when present in
that scope. Core and project licences are outside W1-3's notice scope.

Generation sorts grammar rows and source filenames. Canonical lock provenance
makes row reordering byte-identical while invalidating stale pins. Archive checks
require exactly one regular root notice matching the regenerated bytes, including
all grammar entries and complete licence/NOTICE text.

GoReleaser's before hook generates the notice outside its cleaned dist directory;
its archive manifest includes the root notice. The workflow uses
`release --clean --skip=publish`, checks local archives, attests, then uploads.
A failed generation or validation step reaches neither publication step.
