## Current trigger

`LB-Q-angular-rest` records all six known syntax classes: four one-file residuals across cohorts (canonical structural `let` and terminal `@for` semicolon; ng-alain concatenation before a pipe and a negative numeric literal in `@if`), plus the two additional one-control misses (negative identifier in a ternary consequence and whitespace before postfix `!`). The structural `let` and terminal-semicolon classes each also reject one compiler-valid control. One namespaced SVG selector-context class defers 55 templates. The canonical 2/72 is in-sample; ng-matero 6/77 is spent; the new pooled grade is unavailable. No threshold was relaxed and no template was dropped.

An upstream tree-sitter-angular commit or release that handles these six syntax classes and parses both pinned canonical subjects under 5%, or an implemented product adapter using Angular selector semantics without the namespaced-SVG context refusal, is an observable prompt to request another owner ruling. The work still requires that new ruling, a fresh holdout frozen before tuning and every existing syntax, accuracy, fault and median-three throughput bar. The unpushed prototype remains only the record of the spent attempt.
